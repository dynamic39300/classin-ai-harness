# Copilot API Context Review Lab

独立本机工具，已开放第一阶段 A2 / C2 / E2 / F1、第二阶段 A1 / A3 / A4 / B1 / C1 / E1，以及一个开放式提问入口。无需启动既有 Demo，无第三方运行依赖，Node 24 即可。

```sh
cd tools/copilot-api-review-lab
npm run dev
```

打开 `http://127.0.0.1:4186`。默认读取仓库 `.env` 的公司模型网关配置与本机 `~/.classin.token`；模型使用与当前 Demo 相同的 `deepseek-v4-flash`。`LAB_SOURCE_ROOT` 可指定已有证据目录的仓库根；`LAB_ENV_FILE`、`LAB_MODEL_BASE_URL`、`LAB_MODEL_API_KEY`、`LAB_MODEL`、`LAB_PORT`、`LAB_DATA_ROOT` 可独立配置，不要求既有 Demo 进程在线。

只读取固定已授权测试教师/班级/课程。工具目录 → 真实模型 function calls → 执行器只读路由 → 真实响应 → 上下文 → 真实回答 → 人工审阅。不是 MCP 服务；没有向模型提供 shell、任意请求 URL 或写业务接口。

默认点击“测试并生成回答”，依序完成模型规划、取数和回答。主页面直接评价是否答到点上、是否相关、是否好用，也可以只写备注。工具计划、真实响应、字段与输入保留在折叠的技术证据中，技术核验由工程侧负责；生成回答可独立重试。回放绑定历史业务时钟与选中对象，不会缺什么就偷偷重新取数。F1 优先使用重新采集并保留正文的普通 IM 私有快照，默认查询最近5天，有多少就总结多少；界面明确实际条数和范围，不宣称完整历史。AI 课堂报告、正式事实和教师笔记分别留证。

“还可以补充哪些信息”按本题场景展示工程盘点候选，排除当前已尝试（含失败/依赖/回放）的接口；用业务语言说明预计信息、价值、关键字段和接入条件。它不是模型生成的遗漏审计，也不是工具全集。每项可选建议补充/暂不需要/需要讨论并备注，保存不会追加 API 调用或修改模型输入。新反馈采用 answer-quality-v2，绑定回答和快照，过期提交拒绝，新回答重新待评，旧技术反馈保留历史。

运行、模型输入/输出与备注存到 `.runtime/private/copilot-api-review-lab/`，不会提交。界面 JSON 保留真实结构，票据与 URL 遮蔽。导出包含授权业务样本，仅用于本地审阅。人工修改备注不会改写原始响应。

```sh
npm run check
npm test
```

需求、范围与验收见 `docs/04-specs/features/classin-test-integration/review-lab/`。固定问题允许改写问法；开放式入口允许从授权课堂或作业中选择对象，也可不选。需要具体对象却未选择时，模型先澄清而不执行工具；它不是“任意问题均已覆盖”的声明。

审阅方式修正：回答下方可直接查看本次接口路径，点击 R 编号查看对应原始返回。A2 已取得的课名、时间、学生人数会单列，不能因为另一个详情接口未调用就建议重复读取。候选接口路径直接展示；目录更新保留问答评价和备注，过期候选意见留在历史或本机归档。

重新采集测试群正文：`node scripts/capture-im.mjs`（从独立工具目录运行）。依赖已登录测试教师的 ClassIn LMS 页面；调试地址可用 `LAB_CDP_ENDPOINT` 指定，仅允许本机。采集器短时监听并加载授权班群页面，验证客户端 auth 身份和返回群归属，保留原文；不保存鉴权帧。正文保存于受限 `im-original/`，可直接在审阅台查看并输入 DeepSeek。通用采集器的旧脱敏文件不覆盖，也不逆向猜测旧正文。
