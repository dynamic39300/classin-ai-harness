# NineClaw 页面与交互还原规格包

## 1. 这套规格解决什么问题

本目录是“产品研究”与“ClassIn WorkBuddy 详细设计”之间的中间层。它把录屏、截图和 Skill 源码中的事实转换为可检查的页面、状态、事件、字段和跳转规格，使产品、交互、视觉、前端和 Agent 工程可以基于同一份对象清单讨论，而不是依赖观看者记忆。

当前目标是高精度还原 **NineClaw 的产品结构与交互行为**，不是宣称已经得到 NineClaw 的内部代码、服务端协议或数据库设计，也不是把标杆产品的所有做法直接升级为 ClassIn 的锁定方案。

## 3. 事实标签与还原规则

| 标签 | 含义 | 在设计稿中的处理方式 |
|---|---|---|
| `UI-E1` | 录屏或截图中直接可见 | 可以按观察事实还原 |
| `SRC-E4` | 当前运行时 Skill 源码可静态佐证 | 可用于能力与流程解释，不能证明运行成功 |
| `OWNER-C1` | 产品实际操作者在规格审阅中明确确认 | 可修正交互事实；与视觉证据分别保留 |
| `INF` | 从多个事实得到的推断 | 必须显式标注，不作为像素或协议事实 |
| `UNKNOWN` | 现有证据无法确认 | 不虚构；进入待确认清单 |

所有页面规格遵循四条规则：

1. 动态录屏优先于单张截图；同一版本中的明确动态行为优先。
2. 截图用于确认字段、布局、文案和低频状态，不从截图反推未发生的操作。
3. 源码用于说明 Skill 的输入、处理和产物边界，不从 Skill 文件反推 UI 一定存在。
4. “未观察到”不等于“产品没有”；必须写为 `UNKNOWN`。

经产品审阅确认，`UNKNOWN` 不阻塞后续实施：产品与设计可以基于通用经验设置合理默认值和处理方式，但必须标记为 `DESIGN_COMPLETION`，不得反写成 NineClaw 已验证事实。涉及删除、覆盖、扣费、权限、外部发送、敏感数据或正式业务写回的高影响行为，仍需遵守项目既有确认、审批和回执规则，不能以经验默认值绕过。

## 4. 还原精度定义

本阶段的“100% 精细元素内容还原”定义为：**对现有证据中可见的元素与行为逐项建账，不遗漏、不混写、不伪造**。完成度分四层：

| 层级 | 完成标准 |
|---|---|
| L1 页面覆盖 | 所有已观察页面、弹窗、抽屉和分栏都有稳定 ID |
| L2 交互覆盖 | 所有已观察入口、动作、跳转、返回和跨模块回流都有记录 |
| L3 状态覆盖 | 核心、加载、空、执行、成功、失败、恢复和权限状态有状态定义 |
| L4 证据覆盖 | 关键规格能追溯到视频时间点、截图或源码；未知项显式登记 |

“100%”不包括：未录制页面的猜测、NineClaw 私有后端协议、服务真实可用性、最终 ClassIn 品牌视觉参数和未经确认的像素级尺寸。

## 5. 页面 ID 规范

| 前缀 | 模块 |
|---|---|
| `G` | 全局应用壳与通用覆盖层 |
| `T` | 新建任务、任务工作区与产物 |
| `S` | Skill 发现、详情和管理 |
| `M` | Tool/MCP 发现、配置和管理 |
| `C` | 内容广场、作品和发布 |
| `A` | 定时任务与运行历史 |
| `F` | 我的文件与目录选择 |
| `SET` | 设置 |
| `B` | 会员、积分和商业化 |

页面、覆盖层和组件分别使用 `P`、`O`、`C` 作为末级类型，例如 `T-P02` 为任务工作区页面，`T-O03` 为补参覆盖层，`T-C07` 为工具调用事件卡。

## 6. 与 ClassIn 最终方案的边界

NineClaw 还原规格保留标杆产品中可验证的行为，包括 Skill/模型选择器、原始工具调用和本地路径等；ClassIn 方案不得因此绕过现有锁定决策：

- 教师默认使用统一主 Agent，不要求选择内部 Agent、Skill、MCP 或模型；
- ClassIn 领域对象、正式状态和权限仍由 ClassIn 拥有；
- 业务写回必须经过 `ProposedAction → Approval → ExecutionReceipt`；
- 默认教师视图呈现任务进展和可行动信息，原始命令、路径、环境变量和大段 JSON 进入可控的诊断层；
- 标杆中的 marketplace、积分和自定义模型属于可选参考，不自动进入 ClassIn 第一版。

后续 ClassIn redesign 应以本规格为“行为素材库”，另行形成适配决策，不在本目录内静默改写标杆事实。

## 7. 审阅与完成门槛

本规格包达到可进入高保真设计的门槛是：

- 页面地图中的每个节点都有页面级规格或明确 `UNKNOWN`；
- 主任务链的每个事件都有触发、可见内容、动作、状态和失败恢复；
- 所有跨模块跳转都说明携带的上下文与返回位置；
- 关键帧图册覆盖主任务链、内容链、Skill/Tool 链、定时任务和设置；
- 待确认清单已由产品负责人选择“补充说明 / 补录素材 / 暂不进入范围”。

## 9. 阶段结论

NineClaw 页面与交互还原规格已完成产品审阅并作为后续设计输入冻结。证据仍为 `OPEN` 的项目不再构成产品决策阻塞：按已确认的 `DESIGN_COMPLETION` 实施，并继续与 NineClaw 一手事实分开标注。

本目录是标杆行为基线，不直接等于 ClassIn 最终设计。后续先完成九章爱学 AI 工具集合研究和 Linear Product DNA 研究，再通过明确的保留/适配/舍弃决策形成 ClassIn 教师 WorkBuddy 与 AI 工具集合的目标设计。
