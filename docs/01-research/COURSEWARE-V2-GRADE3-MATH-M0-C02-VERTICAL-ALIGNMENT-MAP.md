## 3. 纵向知识发展链

| 学习阶段 | 教材建立的核心经验 | 表征与学生动作 | 对下一阶段的作用 |
| --- | --- | --- | --- |
| 二下：平均分 | 离散总量可平均分；两类问题分别是已知份数求每份数、已知每份数求份数 | 分物、圈组、图示、口头说明、除法算式 | 提供“总量、份数、每份数”和“每份同样多”的前置经验 |
| 三上首课：几分之一 | 把一个整体平均分成若干份，其中一份可以用单位分数表示 | 折、分、涂、辨认、语言解释、读写 `1/n` | 首次把平均分经验转化为“部分相对于整体”的数值关系 |
| 三上本单元 | 从几分之一发展到几分之几、直观比较、简单计算与应用 | 多种图形/对象、数轴、比较、计算、问题解决 | 扩展“一份”为“几个这样的一份”，形成初步分数系统 |
| 五下：意义正式化 | 把一个物体、计量单位或一些物体看作单位“1”，正式定义分数意义与分数单位 | 多类整体、分数墙、语言与符号互译 | 将三上的直观经验一般化、概念化 |
| 五下：关系与性质 | 建立分数与除法、分数基本性质以及等值关系 | 分物、除法算式、等值图示、符号变换 | 支撑假分数、约分、通分和一般比较 |
| 五下：运算 | 相同分数单位可以直接计数；不同单位需先统一 | 同/异分母加减、解释算理、结果化简 | 把“一份/几个这样的一份”发展为运算基础 |

综合证据支持的依赖链为：

`离散物体平均分 → 一个整体等分 → 一份与整体的关系 → 几个这样的一份 → 单位“1”与分数单位 → 分数与除法/等值关系 → 一般比较与加减法`

该链是教材证据支持的项目概括，不是教材规定的唯一课堂流程。

## 4. 关键迁移与断点

### 4.1 可直接激活的前置经验

- 学生在二下教材中见过“每份同样多”，以及先操作、再看图、再用语言和符号表达的学习路径。
- 学生见过总量、份数和每份数三者的关系，也见过从图到算式、从算式返回图示的转换。
- 这些经验可作为三上入课诊断和语言起点，但不能仅凭教材教过就判定全班已经掌握。

### 4.2 必须显式搭桥的新关系

- 二下的核心对象主要是多个糖果、橘子、小棒等离散物体；三上首课需要把**一个连续整体**平均分成若干等份。
- 二下通常回答“每份有几个”或“能分几份”；三上首次回答“其中一份占整体的多少”。
- 因此，三上不能只复用“平均分”三个字，必须让学生指出整体、检查是否等分，并说明一份与整体的关系。
- 会列除法算式不是进入几分之一学习的硬性条件，除法也不应替代分数意义的操作与表征形成。

### 4.3 应留给后续的概念接口

- **整体先于部分**：每个核心表示都要说清“把什么看作一个整体”。
- **平均分是必要条件**：切成若干块不等于平均分，非等分图不能直接表示目标分数。
- **分母对应等分份数，分子对应所取份数**：首课可用学生语言解释，不提前形成高年级定义背诵。
- **同一分数可以有不同外观**：至少跨两种外形或分割方向，避免把分数绑定到固定图样。
- **比较依赖共同基准**：若首课保留单位分数比较，只在整体同样大小、图示充分的条件下解释。
- **运算是相同单位的计数**：首课只保留“其中一份/几个这样的一份”的语言接口，不教学加减规则。

## 5. 三上首课生成约束

以下 `PROJECT_DECISION_CANDIDATE` 已由用户于 2026-09-06 统一审阅通过；其中明确交由 M0-D/F/H 联合核验的项目仍保持 `PROVISIONAL`，不因审阅而伪装成教材事实：

| 类型 | 生成约束 | QA 可观察证据 |
| --- | --- | --- |
| 前置诊断 | 用一个轻量任务检查学生能否识别“每份同样多” | 任务能暴露非平均分判断，不默认全员熟练 |
| 模型迁移 | 从离散平均分短暂唤醒后，显式转向“一个连续整体的等分” | 页面或教师提问清楚比较两类对象的相同与不同 |
| 概念形成 | 核心例子必须同时明确整体、平均分、其中一份 | 学生能用图、动作或语言解释 `1/n`，而不只会读写 |
| 多重表征 | 至少包含两种外形或分割方向，并有一次表征转换 | 同一单位分数不固定为一种方向、颜色或图样 |
| 比较边界 | 只保留同样大小整体支持下的一次单位分数直观比较 | 必须给出图示或语言理由，不出现无条件口诀 |
| 术语边界 | 单位“1”、分数单位可作为教师侧纵向概念 | 不作为首课学生必须背诵或考核的正式术语 |
| 内容红线 | 不提前讲分数与除法公式、基本性质、约分、通分、真/假分数和加减法规则 | QA 对上述内容进行倒灌拦截 |
| 学情边界 | 对平均分基础不稳的学生提供补偿性操作 | 课堂方案包含可执行的补偿动作或分层反馈 |
