# 活跃上课课程：配套是否到位，学生是否使用，教师反馈是否被看到

**本轮最清楚的结论，是平台内配套覆盖、学生提交、教师反馈的查看分别存在落差。** 在可关联的 660,657 门活跃课程中，91.44% 没有观察到已发布、未删除、开始时间早于周末的非课堂 LMS 配套活动。对本周开始且已到期、通过逐活动对账的作业，当前学生记录的提交比例为 47.39%；已提交中 70.55% 已批阅；已批阅中 25.43% 有批阅后的查看记录。三个比例使用不同分母，不能相乘或直接解释为教学效果。

这些结果描述 **ClassIn 内可观测的使用链路**。没有平台配套不等于没有线下作业，也不能预设每门课程必须同时使用全部活动类型。机构是否达到教学要求，还需要其实际教学方案作为标准。

```mermaid
flowchart LR
 A[观察周实际上课的课程] --> B[是否配置配套活动]
 B --> C[学生是否使用或提交]
 C --> D[是否完成及是否到期]
 D --> E[学习表现]
 E --> F[批阅与具体反馈]
 F --> G[学生是否查看反馈]
```

## 1. 配套覆盖：多数活跃课程尚未观察到平台内配套

观察周内，课堂日表包含 43,811 家机构的 1,206,793 节已结束课堂。其中 1,171,172 节可关联到 31,982 家机构、660,657 门 LMS 课程分类；35,621 节没有满足当前关联条件。这里的“未关联”仅指未通过本轮快照中“课堂活动 → LMS 课程分类”的严格匹配，**不表示课堂没有所属班级**：课堂日表本身已有班级关联键。下文课程/机构覆盖率只使用这批**可关联总体**，不把其余 11,829 家机构判为“没有配套”，也不外推为平台所有机构的覆盖率。关联逻辑及待补查原因见 [课堂—课程关联复核](./CLASSIN-CLASSROOM-COURSE-RELATION-REVIEW-2026-09-14.md)。

班级和课程自身开结课状态均不作为筛选条件。课程以机构、班级和班级内课程键共同识别。先固定上课课程，再查配套，因此零配套课程保留在分母中。

| 配套活动 | 至少配有一项的活跃课程 / 660,657 | 课程覆盖率 | 时间与本周重叠的候选覆盖率 | 至少一门活跃课程有此配套的机构 / 31,982 |
| --- | ---: | ---: | ---: | ---: |
| 作业 | 45,467 | 6.88% | 4.96%（32,745 门） | 4,620 |
| 测验 | 5,756 | 0.87% | 0.51%（3,382 门） | 1,138 |
| 录播课 | 3,766 | 0.57% | 0.54%（3,595 门） | 799 |
| 学习资料 | 8,397 | 1.27% | 1.24%（8,172 门） | 1,546 |
| 讨论 | 847 | 0.13% | 0.11%（742 门） | 277 |

“配有”包含历史活动；“本周候选”要求活动开始早于周末、结束不早于周初或无结束时间。两者都不能证明该活动专门配套本周某一课次。候选覆盖只是时间条件，不是已验证的发布历史或课程层可见性。

覆盖全部非课堂类型（作业、测验、录播、资料、讨论、答题卡、打卡、SCORM、口语及五种学科活动）后，56,566 门课程至少有一种配套，604,091 门没有观察到配套；同时配有作业和测验的课程为 2,576 门。不同活动覆盖课程可能重叠，不能将各行相加。

**“机构用过作业”和“机构所有上课课程都有作业”相差明显。**

| 机构内活跃课程的配套情况 | 作业 | 测验 |
| --- | ---: | ---: |
| 所有活跃课程都有配套 | 1,715 家（5.36%） | 386 家（1.21%） |
| 只有部分活跃课程有配套 | 2,905 家（9.08%） | 752 家（2.35%） |
| 没有活跃课程配有此活动 | 27,362 家（85.55%） | 30,844 家（96.44%） |
| 合计 | 31,982 家 | 31,982 家 |

若再要求时间与本周重叠，“全部活跃课程均有候选配套”的机构降为作业 990 家、测验 183 家。因此，仅用“机构是否创建过一次作业”衡量覆盖完备度会明显高估。

## 2. 实际使用：谁参与了，哪些活动有消费记录

下表统计这些活跃课程下、仍发布且未删除的活动在观察周内发生的学生行为。活动可以早于本周布置；一名学生参加多个活动会产生多个“学生—活动组合”。

| 活动与观察行为 | 去重学生数 | 学生—活动组合数 | 有此行为的活动数 | 有此行为的机构数 |
| --- | ---: | ---: | ---: | ---: |
| 作业提交 | 90,925 | 149,304 | 31,511 | 2,038 |
| 测验交卷 | 17,789 | 36,323 | 6,145 | 345 |
| 录播活动查看 | 16,061 | 28,079 | 6,154 | 318 |
| 学习资料查看 | 26,377 | 48,541 | 10,509 | 621 |
| 讨论参与 | 1,229 | 3,277 | 245 | 26 |

这回答“本周有多少孩子实际参与过”，**不能拿这些人数除以当前班级人数作为完成率**。没有记录只表示未观察到该行为；后台行为表也不能代替完整页面曝光统计。录播“查看”不等于播放完成，资料“查看”不等于读懂，讨论查看和讨论参与分别计数。

对时间与本周重叠、能关联业务主表的 62,090 项资料，业务汇总显示配置 1,085,291 个学生—资料人次、累计已查看 322,295 人次，比例为 29.70%；其中 11,054 项显示全部配置学生已查看，14,667 项查看数为零。该比例是**当前业务汇总的累计查看比例**，没有完成学生明细对账，不能称为已核验阅读完成率。

## 3. 作业：没有都提交；到期后仍有提交缺口

为比较完成、到期和教师反馈，本节固定到更明确的一批对象：**活跃课程下，本周开始、时间与本周重叠、成功关联作业业务主表的 37,952 份作业**。这批作业当前非删除学生记录涉及 184,352 名不同学生；68,261 人至少提交过其中一份。学生“提交过一份”不意味着他完成了所有作业。

先看业务汇总的任务构成：

| 截止情况 | 作业数 | 当前配置人次 | 当前提交人次 | 当前已批阅人次 |
| --- | ---: | ---: | ---: | ---: |
| 已到期 | 13,963 | 108,673 | 52,000 | 36,649 |
| 尚未到期 | 17,186 | 171,167 | 37,195 | 23,087 |
| 无截止时间 | 6,803 | 57,554 | 15,078 | 8,448 |
| 合计 | 37,952 | 337,394 | 104,273 | 68,184 |

因此，不能把所有未提交都叫作逾期。已到期组中，2,454 份作业的汇总显示全部配置学生已提交，6,174 份显示零提交，其余为部分提交；这也直接否定了“是不是 100% 都提交了”的猜测。

**以下闭环比例使用对账通过的学生明细，不混用上表汇总。** 13,963 份已到期作业中，13,803 份通过配置人数、提交数、批阅数及重复记录核验；160 份不一致，剔除。通过核验的作业中，157 份配置人数为零，不进入学生比例分母。

| 对账通过的已到期作业 | 记录数 | 比例及分母 |
| --- | ---: | --- |
| 当前配置学生—作业组合 | 104,505（涉及 70,465 名学生） | 分母 |
| 当前已提交 | 49,524 | 47.39% / 当前配置 |
| 当前未提交 | 54,981 | 52.61% / 当前配置 |
| 最后提交时间不晚于截止 | 39,507 | 37.80% / 当前配置 |
| 最后提交时间晚于截止 | 9,701 | 9.28% / 当前配置 |
| 已提交但缺少有效最后提交时间 | 316 | 单列，不强行归入按时或迟交 |

这些是 **9 月 11 日日分区所记录的当前状态和最后提交时间**，不是发布时固定名单的完成率。最后提交晚于截止，可能包含按时首交后的修改，不能全部判为首次迟交；严格的首次按时率、截止瞬间未交率仍需要提交历史。8 条记录的更新时间晚于周末边界，因此也不把该日分区宣称为精确午夜快照。

来源：[逐作业对账](./classin-active-course-outcome-2026-09-12/v3/v3hw_due_reconcile.json)、[已验证作业闭环](./classin-active-course-outcome-2026-09-12/v3/v3hw_verified_chain.json)。

## 4. 教师反馈：批阅只是第一步，查看反馈还有明显落差

沿用上节同一批已核验作业：

| 教师反馈环节 | 记录数 | 业务解释 |
| --- | ---: | --- |
| 已提交 | 49,524 | 教师跟进的基数 |
| 已批阅 | 34,941（70.55% / 已提交） | 仍有 14,583 条提交尚未处于已批阅状态 |
| 批阅时间不早于最后提交 | 34,625 | 可以建立“最后提交→批阅”时间链 |
| 最后提交未晚于截止，且随后已批阅 | 28,434 / 39,507（71.97%） | 按最后提交时间定义的按期完成者，约七成观察到后续批阅 |
| 已批阅且有非空文字、语音或教师附件字段 | 34,197（97.87% / 已批阅） | 反馈载体存在性候选，不评价反馈质量 |
| 已批阅且有批阅后查看记录 | 8,885（25.43% / 已批阅） | 批阅完成后，反馈被学生查看的记录仍有限 |

反馈载体中，非空文字字段出现在 13,794 条已批阅记录中（39.48%），语音字段出现在 742 条（2.12%）；不同载体可重叠。仅有教师附件字段不等于针对错误的个性化解释，非空字段也可能包含模板或占位内容。本轮只在数仓端统计存在性，不读取评语、答案或附件内容。

对时间顺序有效的 34,625 条已批阅记录，从最后提交到批阅平均约 30.0 小时，其中 21,858 条在 24 小时内批阅。**这是已经批完部分的时延**；未批阅记录未进入平均值，不能据此判断所有教师都能在约一天内完成反馈。

这里能证明的是平台存在批阅和反馈载体记录，不能确定全部来自教师人工操作，也不能证明反馈针对具体错误、被理解或带来学习改进。“没有查看记录”也不能直接认定学生拒绝阅读。

测验目前可以验证的是**同周交卷后的批阅衔接**：36,323 个交卷学生—活动组合中，34,628 个在交卷后出现同周批阅事件（95.33%）。作业对应为 102,814 / 149,304（68.86%）。这是另一套本周事件观察窗，包含此前布置的活动，与本节“本周开始且已到期的作业状态”分母不同。周末交卷可能尚未来得及批阅，不能把剩余部分当成最终漏批；测验自动阅卷与人工反馈尚不能分开。

来源：[已验证作业闭环](./classin-active-course-outcome-2026-09-12/v3/v3hw_verified_chain.json)、[作业事件衔接](./classin-active-course-outcome-2026-09-12/v3/v3feedback_2.json)、[测验事件衔接](./classin-active-course-outcome-2026-09-12/v3/v3feedback_3.json)。

## 5. 学习表现：暂不能给出可信的总体正确率

这一环没有省略，而是查到了两项具体限制：

- 作业对错标记并非完整客观题作答清单。样本 H08 的 20 条已批阅记录中，只有 8 条存在对错计数，记录为 0 个“正确”和 14 个“错误”，不能解释为孩子整体正确率为零。
- 已到期作业的已批阅明细里，评分类型实际出现 4 和 5；知识库只解释了 1–4，类型 5 尚未定义。不评分类型 4 还存在少量非空得分率。即使数值落在 0–1，也不足以把它作为可比较的整体学习表现发布。

因此，本轮可以回答“有没有交、有没有批、反馈有没有被查看”，**还不能回答总体正确率多少、测验是否大部分过期未交、录播是否看完，以及反馈是否改善学习结果**。测验缺少可用并验证的应试及结果明细映射；录播需要已验证的播放进度/完成状态；成绩需要补齐评分类型 5、有效满分和客观题计数语义。具体字段和解锁条件见[质量与缺口说明](./classin-active-course-outcome-2026-09-12/v3/QUALITY.md)。

## 业务上应如何使用这份结论

先检查机构的课程是否有应有的配套，再看已配置活动是否被使用，随后检查到期未交和提交待批阅，最后检查反馈是否被看到。**当前不宜用一项总分给机构排名**：不同机构的教学方案、平台外教学行为和活动用途尚未纳入。

本轮最值得继续验证的两个业务机会，是让已上课课程更稳定地配置合适的配套，以及让已完成批阅的反馈更容易被学生看到。它们来自上述观测落差，属于待验证的产品方向，不是对原因或产品收益的因果结论。
