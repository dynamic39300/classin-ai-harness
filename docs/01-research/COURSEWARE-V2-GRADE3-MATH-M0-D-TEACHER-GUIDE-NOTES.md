## 4. 锁定的教学路径

以下是可由后续 `LessonFlow` 直接消费的 `PROJECT_DECISION`：

1. **先产生表达需要**：用公平分享或不足一个整体的情境，让学生发现整数不足以准确表示结果；不以讲定义开场。
2. **明确整体**：每个核心例子先回答“把什么看作一个整体”；更换整体时重新说明参照对象。
3. **验证平均分**：学生必须能检查各份是否同样大；“切成若干块”不等于平均分。
4. **命名其中一份**：从 `1/2` 形成“一份与整体”的关系，再迁移到 `1/3`、`1/4` 等少量单位分数。
5. **连接表征**：至少完成一次 `操作/图形 → 学生语言 → 1/n`，再从符号返回新图形。
6. **整理符号**：意义形成后再介绍分数线、分母、分子和读法；首课学生可用“平均分成 n 份，取其中一份”的语言，不要求背“分数单位”。
7. **用变式和反例稳固**：跨外形/方向表示同一单位分数，并加入一个非平均分反例。
8. **有条件比较**：只在同样大小整体和图示支持下比较一组单位分数，要求说理由；不输出脱离条件的口诀。
9. **用退出证据收束**：新图形判断、说明整体和平均分条件；正确选项但无理由只算部分证据。

## 5. 重难点与内容取舍

| 层级 | 锁定内容 | 处理原则 |
| --- | --- | --- |
| 核心目标 | 一个整体平均分成若干份，其中一份与 `1/n` 的联系 | 必须占用主要课堂时间并有学生可观察动作 |
| 关键难点 | “份数相同”不等于“每份同样大”；分数依赖整体 | 使用对比例、反例和学生自造表示，不只口头提醒 |
| 符号目标 | 读写简单单位分数，理解分母/分子在当前 `1/n` 中的作用 | 名称服务于意义，不单独堆叠术语 |
| 表征目标 | 面积/操作为主，跨外形；轻量连接线性表示 | 不把面积模型正确等同于全面掌握 |
| 比较目标 | 一次共同整体基准下的图示比较 | 可移出主流程；不讲通分、统一分数单位算法或一般规则 |
| 后续接口 | “几个这样的一个”、单位“1”、分数单位、集合整体 | 教师侧保留，但不列为首课学生考核术语 |

## 6. 教师回应协议

| 学生表现 | 教师先做什么 | 避免什么 |
| --- | --- | --- |
| 只说“分成两块” | 追问两人是否得到同样多，并要求验证 | 立即给出“平均分”定义让学生复述 |
| 折法不同 | 让学生说明每份是否相等、各份如何拼回整体 | 以外观不同判错 |
| 符号颠倒 | 先问“平均分成几份、取其中几份”再回到符号 | 只反复背“上面/下面” |
| 非等分图判断正确但无理由 | 追问哪一条件不满足 | 把猜对记录为稳固掌握 |
| 比较只看分母数字 | 固定同样大的整体，用图示或纸带说明每份大小 | 教另一个无条件口诀 |
