## 3. 单元级结构

### TF-01 第八单元的显式结构

- **标签**：`TEXTBOOK_FACT`
- **教材位置**：pp. 89-103。
- **页面结构**：
  1. “分数的初步认识”：几分之一、几分之几及练习二十；
  2. “分数的简单计算”：同分母分数加减、1 减几分之几及练习二十一；
  3. “分数的简单应用”：用分数表示集合中的部分、求一个数的几分之几及练习二十二；
  4. p. 103 以单元收获记录收束。
- **边界**：教材没有在这些页面标出每个例题对应多少课时。

### SI-01 单元内部知识推进

- **标签**：`SUPPORTED_INFERENCE`
- **关系**：`一个整体平均分后的一份 → 一个或多个这样的份 → 大小比较 → 以相同分数单位计数进行加减 → 把部分/整体关系迁移到一组对象 → 求一个数的几分之几`。
- **证据链**：pp. 90-93、96-97、100-101 的例题顺序及 pp. 94-95、98-99、102-103 的练习安排。
- **边界**：这是对教材序列功能的概括，不等于教材明示的认知理论，也不证明所有学生都必须沿唯一相同路径学习。

### 5.3 例题与练习功能判定

- **例 1，`SUPPORTED_INFERENCE`**：不是只教授 `1/2` 的单例，而是通过 2、4、3、5 等不同等分数提取“平均分成几份，其中一份就是几分之一”的共同结构。
- **例 2，`SUPPORTED_INFERENCE`**：把学生从识别教材给定图形推进到自己构造表示，同时暴露“形状不同但等份关系相同”的可能讨论点。
- **例 3，`TEXTBOOK_FACT`**：教材在“几分之一”紧接着安排单位分数大小比较，比较对象为 `1/2` 与 `1/4`、`1/4` 与 `1/6`，并询问发现。
- **“做一做”1，`SUPPORTED_INFERENCE`**：检查学生能否忽略外形差异，依据整体的等分份数识别一个单位分数。
- **“做一做”2，`SUPPORTED_INFERENCE`**：检查面积模型和线性模型中的表征转换与单位分数比较；它不是单纯口算比较题。

### 5.4 教材可以支持的目标课最小结构

以下项目决策候选已由用户完成 Review；其中课时容量与术语深度随后由 M0-D/F/H 最终锁定：

1. 目标课不可省略“一个整体被平均分”的条件；
2. 至少让学生经历一次 `情境/操作或图形 → 语言 → 分数符号` 的转换；
3. 至少跨两类外形或表征识别几分之一，避免把某种固定图形误当作分数本身；
4. 分子、分数线、分母名称与读法可在意义形成后作为符号整理内容；
5. 若纳入比较，应保留相同整体基准及图示解释，不把“只看分母数字”作为无条件口诀；
6. 40 分钟内是否同时完成折纸、跨表征练习和单位分数比较，不能仅凭两页教材决定。

**`TEXTBOOK_FACT`**：总复习不是按第八单元原页顺序简单重放，而是分别在概念整理、综合练习和跨单元问题中回扣分数。

**`SUPPORTED_INFERENCE`**：后续课件评价不应只检查学生能否读写一个单位分数，还应为跨表征、单位分数计数和现实数量应用保留后续发展接口；这些不是第一课时必须全部达成的目标。
