# 三年级数学课件生成 V2 M0 课程事实与资料来源登记

## 1. 研究问题

M0 核对并登记以下问题：

1. “三年级初步认识分数”是否符合现行国家课程标准的学段范围；
2. 人教版小学数学是否属于教育部教学用书目录中的正式教材体系；
3. 人教社公开资料如何描述分数初步认识的内容起点与教学方向；
4. 教师教学建议、学生认知、课例模式和评价题型分别有什么证据与适用边界；
5. 教材、平台、图片、题目、操作材料和代码分别允许怎样阅读、保存、改编、输入模型与再分发；
6. 进入 M1 前还缺少什么，哪些缺口被隔离、阻断或转交后续校准。

本文不替代教材、教师用书或教研人员审阅，不复制受版权保护的完整教学内容。

## 2. 已核验事实

### F-01 第二学段需要经历分数形成并初步认识分数

教育部《义务教育数学课程标准（2022年版）》把 3-4 年级划为第二学段，并要求学生经历小数和分数的形成过程、初步认识小数和分数，同时发展数感、运算能力与初步推理意识。

**对本项目的影响**：首课不能只教分数符号的读写，应让学生经历从具体情境或操作到分数表达的形成过程。

来源：[教育部课程标准通知](https://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)、[义务教育数学课程标准 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf)。

### F-02 第二学段强调操作、交流和现实问题

课程标准的第二学段学业质量描述包含从生活与数学情境发现和解决问题，以及通过操作、游戏等活动参与数学学习、独立思考和合作探究。

**对本项目的影响**：课堂课件必须表达学生动作、交流和反馈，不应退化为教师连续讲解的文字页。

来源：[义务教育数学课程标准 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf)。

### F-03 人教版小学数学属于正式教学用书体系

教育部 2024 年义务教育国家课程教学用书目录列出人民教育出版社编写、出版的小学一年级至六年级数学教材，并说明有配套教师用书。

**对本项目的影响**：人教版可以作为首条公立校正式课程样板，但目录事实不能替代具体印次和教材页面核验。

来源：[2024 年义务教育国家课程教学用书目录 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020240805496325238752.pdf)。

### F-04 人教社公开资料把本单元的认识起点放在几分之一

人教社公开的数字化教学材料以三年级上册“分数的初步认识”为例，说明学生的初步认识以“几分之一”为起点，并通过把一个物体或图形平均分成若干份开展交互操作。

**对本项目的影响**：M0 将“平均分一个整体，认识其中一份”作为第一课时工作范围；具体例题、术语顺序和页面编号仍待教材核验。

来源：[《中小学数字化教学》公开页面](https://zxxszhjx.pep.com.cn/ebook/202111/files/basic-html/page16.html)。

### F-05 分数学习需要螺旋递进和多重表征

人教社公开教研文章将小学分数学习描述为逐级递进、螺旋上升，并讨论从动作、表象到符号的表征转换，以及生活情境需要同时保持真实性和数学意义。

**对本项目的影响**：Knowledge Pack 需要记录前后知识关系；Courseware Skill 需要要求操作、图示、语言和符号之间建立明确连接。

来源：[逐级递进，螺旋上升——小学阶段分数教学策略初探](https://m.pep.com.cn/jyx/ydjx/201502/t20150203_1228906.shtml)、[小学数学教材与数学思想方法](https://www.pep.com.cn/kcs/yjcg/lw/lw2015/201808/t20180803_1927925.html)。

### F-06 新教材强调数学逻辑与学生认知逻辑

人教社的新教材介绍强调内容需要同时关注数学知识逻辑和学生学习的心理逻辑，采用螺旋上升、分层有序的编排，并通过核心概念和数学思想建立不同内容之间的一致性。

**对本项目的影响**：V2 不能只从本页文案生成课件，需要在 `KnowledgePointMap` 中表达前置、当前和后续知识位置。

来源：[人教版义务教育数学新教材简介](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995566.html)。

### F-07 用户提供的候选教材副本关闭了版本与章节结构缺口

用户提供的第三方 GitHub PDF 显示：教材为人民教育出版社《义务教育教科书 数学 三年级上册》，教育部审定 2022，2022 年 8 月第 2 版，ISBN `978-7-107-36924-7`。目录显示第八单元《分数的初步认识》自教材页 89 起；目标小节“几分之一”位于教材页 90-91，依次涉及平均分情境中的单位分数、分数各部分名称、折纸表示和简单单位分数比较。

**对本项目的影响**：M0 可以固定教材身份和目标页面范围；第一课时是否完整覆盖教材页 90-91，尤其单位分数比较的教学深度，仍需在 M0-D/F/H 使用教师用书、课例和课堂约束证据并经用户审阅后确认。

来源：[用户提供的 GitHub 文件页](https://github.com/TapXWorld/ChinaTextbook/blob/5a80345f2043ba6f8db8d7be9cf3db82725ff1f7/%E5%B0%8F%E5%AD%A6/%E6%95%B0%E5%AD%A6/%E4%BA%BA%E6%95%99%E7%89%88/%E4%B9%89%E5%8A%A1%E6%95%99%E8%82%B2%E6%95%99%E7%A7%91%E4%B9%A6%20%C2%B7%20%E6%95%B0%E5%AD%A6%E4%B8%89%E5%B9%B4%E7%BA%A7%E4%B8%8A%E5%86%8C.pdf)。核验副本 SHA-256：`117c0e0545218aadab20001250e937ce60b959681dda7006396f7db6eaf368b6`。该来源类别为 `USER_SUPPLIED_THIRD_PARTY_COPY`，不作为版权授权或再分发许可证明。

### F-08 二年级下册关闭了“平均分”前置教材位置缺口

用户确认的固定提交副本显示：二年级下册“表内除法（一）”从教材页 7 开始，依次建立平均分、两类分法、除法意义及操作/图/语言/算式之间的转换。该证据支持把“每份同样多”作为三上可诊断的前置经验，同时表明离散物体分组到一个连续整体等分仍需显式迁移。

## 5. M0 研究结论

现有一手公开证据、目标教材核验、同行评审研究与用户项目决策已经覆盖 M0-A 至 M0-J。用户于 2026-09-06 完成 M0-C-02 Review，并授权后续 M0 Review 默认通过；M0 状态为 `COMPLETE_USER_REVIEWED`，M1 已解锁但尚未启动。

仍保留的核心边界是：正式同版教师用书为 `LIMITED_SOURCE`，真实班级学情与执行时间未经试教，第三方教材和平台资源许可为 `UNKNOWN_BLOCKED`。这些边界均已指定隔离或后续关闭路径，不需要后续 Agent 从聊天补猜，也不得被解释为生产能力、授权或教学质量已经验证。
