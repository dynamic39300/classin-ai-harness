# 课堂到 LMS 课程分类关联复核

## 结论

此前“35,621 节课堂未关联”的表述容易被理解为“这些在线课堂没有班级或课程”。该理解不正确。

知识库确认：课节记录的 `course_id` 是**所属班级 ID**；LMS 活动的 `course_id` 也是**班级 ID**。课节的 `class_id` 与 LMS 课堂活动（`biz_type=1`）的 `biz_id` 相连。因此，观察到的已结束课堂已经具有班级归属，不能称为孤立课堂。

本轮未能取得的是该课堂到 **LMS 课程分类** 的可用映射。LMS 语境中的“课程”是班级下的课程分类：`lms_activity.category_id`。一个班级可以有多个课程分类，活动归属于其中一个分类。它不同于班级本身，也不同于班级的外部分类或课程体系。

## 原统计实际检验了什么

原查询从已结束课节出发，要求在 9 月 11 日活动快照中找到同一机构、同一班级、且课堂业务 ID 相同的课堂活动，再同时满足：

1. 活动类型为课堂；
2. 当前为已发布且未删除；
3. 课程分类 ID 有效；
4. 活动开始时间位于观察周。

1,206,793 节已结束课堂中，1,171,172 节满足这些条件；35,621 节未满足至少一项。这是“严格 LMS 课程分类映射未命中”，不是“课堂缺班级”。多课程分类映射数为 0，说明已命中课堂没有被错误地同时归入多个 LMS 课程分类。

## 仍需查明的原因

现有聚合不能区分 35,621 节课堂具体落在以下哪类：

| 待检原因 | 业务含义 |
| --- | --- |
| 无同一课堂业务 ID 的 LMS 活动行 | 课堂与 LMS 活动同步或关联键存在缺口 |
| 有活动行但课程分类 ID 为空/无效 | 课堂已属于班级，但未能定位到 LMS 课程分类 |
| 有课程分类但当前隐藏、草稿或已删除 | 课程关系可能曾存在，但 9 月 11 日当前快照不再可用 |
| 活动时间不落入观察周 | 课节与活动的时间字段或跨日分区需要进一步校准 |

这些只是待验证分类，不能在未运行分层查询前归因。

## 下一步只读诊断

以同一批 35,621 节课堂为总体，逐层统计：

1. 是否存在同一课堂业务 ID 的 LMS 课堂活动，不施加发布、删除、课程分类和时间过滤；
2. 存在活动时，按课程分类是否有效、发布状态、删除状态和活动时间与课节时间的关系分组；
3. 对每一类随机抽取少量脱敏样本，核对班级 ID、课节 ID 与课程分类映射；
4. 依据结果修正总体：若只是快照过滤造成的漏配套，恢复该映射；若课程分类确实为空，则把它单列为“仅班级课节”，不与“课程内活动”混算。

查询组件当前需要更新授权后才能执行上述分层诊断；在此之前，原报告的课程覆盖率继续限定为“可映射到 LMS 课程分类的课堂总体”。

## 依据

本次结论来自数仓知识库中的课堂/课节与业务术语定义：课节 `class_id` 对应 LMS 课堂活动的业务 ID；两处 `course_id` 都表示班级 ID；LMS `category_id` 才表示班级内课程分类。此前 v3 映射查询与结果仅用于量化严格映射命中，不用于证明课堂没有班级。
