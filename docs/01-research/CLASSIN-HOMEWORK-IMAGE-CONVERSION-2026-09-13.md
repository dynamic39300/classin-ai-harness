# 作业两图两文转换结果

## 最新结果：正式图片附件链路已跑通并批量完成

用户在新安装的 ClassIn 版本中通过原生图片按钮上传并保存成功，截图可见第 2 讲作业中的图片正常显示。随后用教师接口回读该成功样本，确认图片不写入 `homeworkDesc`，而是以 JSON 数组保存在 `image` 字段；样本同时包含云盘 `fileId`、LMS `lmsFileId`、文件名、KB 大小、UUID 和文件权限。

Apifox 与成功样本共同确认的正式链路为：

1. `/mix/app/getCosTempToken` 取得测试存储临时权限并上传 PNG；
2. `/cloudspace/api/user/uploadFileMix` 使用 `fileType=1`、COS 相对路径及新客户端参数 `appType=1`，返回 `userFileId` 和 `originId`；
3. `/lms/app/file/uploadByFile` 的 `files[].fileId` 传 **`originId`**，生成 `lmsFileId`；传 `userFileId` 虽可能返回成功，但附件回读为 `isCloudFile=false`，不能使用；
4. `/lms/app/file/getFiles` 回读确认 `isCloudFile=true`、`transitionState=2`、`moderationState=0` 且存在正式文件路径；
5. `/lms/app/activity/homework/update` 把两份附件对象写入 `image`，正文只保留第 3、4 两道文字题。

已按该链路完成第 2–14 讲共 13 份作业：26 张 PNG 全部上传并逐字节校验，生成 26 个唯一 LMS 附件关系；13 份作业逐项回读均为两张正式图片附件、两道文字题，没有 `<img>` 或外部图片直链。批量查询 26 份附件均为真实云盘文件、转换成功、审核正常；每份作业仍分配给原来的 3 名测试学员。原活动 ID、单元、时间、评分及发布配置沿用修改前载荷。

第 2 讲中用户手工上传的测试图片在批量更新前已保存于受控快照；当前活动附件列表按既定规则替换为该讲生成的两张题图，底层手工文件没有被删除。用户截图证明新客户端的原生图片能力可用；26 张批量题图的 API 契约和服务端回读已通过，整批客户端视觉抽查仍由用户验收。

受控回执为 `.runtime/private/classin-target-import-2026-09-11/homework-native-attachments-batch-2026-09-13.json`，状态 `COMPLETED_VERIFIED`，权限 0600，不提交；其中保留写前快照、ProposedAction、附件注册/绑定结果、逐份更新结果和学生集合指纹。

## 历史纠正：客户端显示失败，已撤回正文直链方案

用户随后提供第 12 讲的 ClassIn 编辑作业截图，两张正文图片均为断图。此前 API 正文保存、存储文件读取和普通浏览器显示通过，**不足以证明 ClassIn 客户端支持这种引用格式**。用户明确要求通过图片按钮对应的正式上传/附件方式添加；此前内嵌 COS 直链方案已否定。

已逐份撤回第 2–14 讲共 13 份作业中本次写入的断图正文，恢复原先四道完整文字题，活动 ID、单元、时间、评分和原名单配置保持不变。26 张题图仍保留，待正式链路跑通后再转换为两图两文；目前不能将这 13 份作业标为图片题已完成。

## 历史方案（已撤回）

已将测试课程中现有的第 2–14 讲共 13 份作业更新为每份四题：第 1、2 题各一张 PNG 图片，第 3、4 题保留文字。合计 26 道图片题、26 道文字题。图片从原题文字精确排版生成，包含主题和题号，不包含参考答案；它们是测试题图片，并非教师实拍照片。

当前图片以 `<img>` 嵌入作业正文 `homeworkDesc`，不是独立 LMS 图片附件。测试环境 `/lms/app/file/upload` 登记接口返回 `110140007 文件上传失败`，未产生有效 `lmsFileId`，所以没有向 `image` 字段填入虚构附件 ID。图片本身已通过测试账号取得的临时凭证上传至服务端指定的测试存储桶，并验证能够实际访问。

## 已验证的技术链路

1. Apifox 项目 345324 / 接口 3492000：`/mix/app/getCosTempToken`，`flag=7`，取得测试文件存储临时权限。
2. 使用腾讯 COS Node SDK，向返回的 `cloudfile14` 测试桶上传图片，并用标准存储端点回读校验。返回的自定义域名上传签名不匹配，且公开读取返回 403；同一授权测试桶的标准端点上传及读取成功，因此正文采用经过下载验证的标准端点图片 URL。
3. Apifox 项目 345129 / 接口 3490876：`/lms/app/file/upload` 尝试登记图片。相对对象路径、自定义域名 URL、已验证可读取的标准 COS URL 均返回 `110140007`，没有成功登记记录。
4. Apifox 项目 345129 / 接口 3471055：`/lms/app/activity/homework/update` 保存包含两张图片的 HTML 正文。
5. 逐份调用作业详情和学生列表接口，核对正文、配置及成员集合；普通浏览器加载 API 回读正文中的所有线上图片。

原始配置快照、ProposedAction、执行回执和学生名单保存在 Git 忽略的受控目录中。临时凭证不写入仓库或公开预览。独立附件登记和原生学生客户端显示仍是未验证/未完成项，不能用正文或普通浏览器验证代替。
