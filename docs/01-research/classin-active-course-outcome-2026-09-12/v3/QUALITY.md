# 口径、验证与未覆盖指标

执行版本：2026-09-13 / v3。业务主报告为 [活跃课程教学链路](../../CLASSIN-ACTIVE-COURSE-TEACHING-CHAIN-ANALYSIS-2026-09-13.md)。

## 统计合同

- 窗口固定为北京时间 2026-09-05 00:00 至 2026-09-12 00:00，左闭右开；Unix 秒为 1788537600、1789142400。
- 活动、作业及其学生日分区使用 2026-09-11。日分区中存在周末之后的更新时间，不宣称精确午夜历史状态。
- 活跃总体：课堂日表中计划开始位于窗口、状态 3 的课堂，按机构—班级—课堂去重；关联日快照中发布且未删除、开始位于窗口、类别键有效的课堂活动。
- 班级 course_id 与班级内课程 category_id 不混用；不使用班级或课程自身开结课条件。
- 配套：活跃课程下 biz_type 2–15、publish_flag=2、is_deleted=0、start_time<周末。候选配套再要求 end_time=0 或 end_time>=周初。未还原课程/单元层隐藏和历史发布状态。
- 没有配套的活跃课程继续进入 660,657 的分母。“历史已有配套”不是“本周每节课堂均有配套”。
- 使用事件：同样的机构—班级—班级内课程键，再与已发布活动核对。先按学生—活动—行为预聚合，再连接，保留事件数与去重组合数的区别。
- 作业详细闭环：本周开始且成功关联主表的作业，分已到期、未到期、无截止时间。最终比例只使用已到期且逐活动对账通过的部分，分母为当前非删除学生—作业记录，保留草稿学生在配置分母，草稿不计提交。
- 不把当前配置人数称为发布时分配人数；不把最后提交时间称为首次提交时间。

## 样本与全量验证

1. 沿用 v2 固定种子 20260912 的 10 份作业、10 份测验诊断样本，来源为 [抽样 SQL](../v2-sql/10-supplementary-sample.sql)。它们用于字段和关联语义，不是本轮机构总体的代表性概率样本。
2. 10 份作业的开始/截止时间与活动表 10/10 一致；配置数 9/10 一致。H02 活动配置 16、主表及学生明细配置 17，证明活动配置不能直接替代作业分母。均允许后加入学生获取作业。
3. 本轮补查 10 份作业的学生聚合；当前人数、提交数、批阅数均与主表一致。H08 的 29 次提交事件对应 22 个学生—作业组合、20 条已批阅记录，验证需去重重复提交。其批阅后查看记录 3 条；反馈字段存在性不能替代查看。脱敏结果见 sample-feedback-quality.json，原配置对照见 ../supplementary-sample-quality.csv。
4. 原计划的 12 所机构、24–36 门课程分层分析没有作为本轮抽样估计执行。采用上述诊断样本，并对已到期作业执行全量逐活动对账；课程覆盖直接扫描可关联总体，不由小样本外推。不得将旧分层样本或本轮诊断样本称为代表全部机构。
5. 课堂唯一映射复核：1,206,793 节去重已结束课堂；1,171,172 节成功映射，35,621 节未映射，多 category 映射为 0。后者只表示不满足本查询关联条件，没有逐项归因。
6. 37,952 个关联作业记录等于 37,952 个不同 homework_id。主表范围内 rnum>cnum、cnum>num 或 num<0 的活动数为 0；426 份（1.12%）活动配置人数与主表人数不同。
7. 全部本周开始作业的学生明细中，未到期组出现 1 个重复学生—作业组合；这批全范围明细只报告去重学生数与质量，不发布总体完成率。
8. 已到期 13,963 份作业逐项对账：13,803 份通过，160 份不通过。通过条件为记录数=去重学生数=主表配置数，且非草稿提交/批阅数分别等于主表汇总。未通过组主表提交 2,476、明细 2,271；主表批阅 1,708、明细 1,439。不猜测差异原因，不混用两套数。
9. 通过组配置 104,505、提交 49,524、批阅 34,941；其中 157 份配置为 0，故学生连接实际覆盖 13,646 份。49,524=39,507（最后提交不晚于截止）+9,701（晚于截止）+316（时间缺失），提交及时间分类闭合。
10. 反馈比例分母为 34,941 条已批阅记录；其中有效“最后提交→批阅”顺序为 34,625 条。平均批阅时延只含这些已批阅记录，存在未批阅观察截断，不是服务水平承诺。
11. 已验证作业组有 8 条更新时间在周末边界之后；使用“日分区记录状态”表述，不作精确 T 时点结果。
12. 资料汇总 62,090 项，查看数超配置或小于零的活动数为 0；未做资料学生明细对账，29.70% 仅为主表描述性累计查看比例。

## 教师反馈的边界

| 指标 | 证据 | 不能推断 |
| --- | --- | --- |
| 批阅状态 | 作业学生 status=2，且非草稿 | 人工批阅、批阅质量 |
| 批阅跟随提交 | th_time>=ref_time>0 | 首次提交后的首次反馈 |
| 非空文字候选 | comment 去空白后非空 | 个性化内容、有效建议；HTML/模板仍可能非空 |
| 语音/附件候选 | comment_audio、th_docs、th_image 排除空串、空数组、null 字面值 | 语音是否可播放、附件是否有针对性批注 |
| 批阅后查看 | rd_ch_time>=th_time>0 | 看完、读懂、反馈改善成绩 |
| 本周批阅事件 | student 侧 readover_homework_st / readover_exam_st | 学生主动查看反馈；人工与自动来源 |
| 时间衔接 | 同学生—活动，批阅时间不早于同周首次提交 | 周末尚无事件即最终漏批 |

反馈载体与查看是已批阅记录的两个分支，不能把查看数除以载体数冒充严格的顺序漏斗。没有导出学生身份、原始评语、答案、媒体链接或教师账号。

## 学习表现与其他缺口

| 尚未发布的业务结论 | 查证结果/原因 | 可复核的解锁条件 |
| --- | --- | --- |
| 作业总体正确率 | correct/wrong 是记录的对错标记，缺少完整题目分母；样本会只记录错误 | 验证每题作答与判定的完整性及主客观题规则 |
| 可比较的总体得分率 | 已批阅到期记录出现评分类型 5，KB 仅解释 1–4；类型 4（不评分）仍有 20 条非空比例 | 明确类型 5、历史改分与满分语义，再对分数与比例交叉校验 |
| 首次按时提交、截止瞬间逾期未交 | 当前名单与最后提交时间不还原历史分配及首次提交 | 活动分配历史、提交日志及截止历史 |
| 测验应试完成/到期未交/正确率 | 可访问视图列表未找到已验证的考试发布及学生结果直达视图；ADS 检索未给出可替代的同粒度合同 | 授权可读的应试、交卷、阅卷明细与活动映射；元数据不等于数据可访问 |
| 录播看完率 | looked_activity 只证明活动查看；未完成播放进度明细及 learnRate 的样本验证 | 播放进度和完成定义、配置学生分母及快照对齐 |
| 资料阅读完成/理解 | 当前资料表只有查看汇总 | 学生查看明细对账；理解需要其他学习证据 |
| 人工反馈比例、针对性与效果 | 批阅/附件存在性不区分自动与人工，不读取内容 | 评分来源及合规的反馈质量评价、后续学习结果 |
| 全平台覆盖率 | 日表观察框与活动映射有边界 | 更完整课堂总体和未映射原因验证 |

评分类型分布查询中，类型 5 的非空比例虽在 0–1，仍不将其均值写成业务学习结论；这些数只作为语义排查证据保存。

## 查询执行与失败处理

StarRocks 对部分多表查询超时；拆活动类型、先聚合事件后连接，再切换 Impala。学生明细全扫描曾超时；先在已确定作业集合中查询主键上下界 47758891–49111062，再对相同集合添加安全范围剪枝，成功完成全量。该范围只优化扫描，不更改总体；换窗口必须重算。

一次 Impala 查询返回资源不足，未调大超时或资源限制；后续串行执行并减少扫描。最终主报告均引用成功、未截断的聚合返回。失败 SQL 与已弃用草稿不属于发布指标；失败不解释为零结果。
