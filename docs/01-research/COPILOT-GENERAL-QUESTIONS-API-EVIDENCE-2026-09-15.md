# 班级 Copilot 通用提问：真实测试接口取数证据

## 1. 本轮范围与来源

用户要求用接口直接返回的内容推演老师问题，而不只依据原版物理模拟场景。本轮在原版项目内，通过 V2 已验证的只读服务读取已授权测试教师及目标数学课程。未启动或修改 V2 服务，未创建、修改课程或提交作业，未发送消息。

读取时间：2026-09-15 12:55 左右（北京时间）。取得 66 份业务 JSON 响应、2 次资料资源读取；活动目录完整性校验通过；对五类活动各抽查两项详情，共 10 项。目录覆盖不代表每项活动正文和全部学生历史均已读取。

**这是测试环境真实接口返回，不等于自然发生的真实教学样本。** 返回内容中包含明确写着“AI生成测试学习资料”“接口回归测试模拟作答”的文本。取数保留原值，不把这些内容转换成真实学生表现。另行进行的 DW 研究使用独立业务样本，两者不关联为同一教师或班级。

本机原始 JSON、请求操作索引、详情和提取文本保存在被 Git 忽略的 `.runtime/private/general-questions-2026-09-15/`；原始姓名、用户标识、报告访问凭据和资源地址不进入本文。文件目录为受限权限。这里的“学生甲/乙/丙”仅为审阅别名。

## 2. 实际取得的业务范围

| 业务对象 | 实际结果 | 对提问设计的影响 |
| --- | --- | --- |
| 当前教师班级列表 | 在“当前、正常、教师/班主任”的既有查询条件下返回 1 个班级 | 可说明当前列表内的班级；不能宣称覆盖该老师全部历史班级 |
| 班内课程目录 | 2 个目录项；只展开已授权的目标数学课程 | 能区分班级与班内课程；另一目录项未做完整详情读取 |
| 班级成员 | 3 名测试学生 | 可核对当前名单与活动分配；不能把测试小班规模当一般班级规模 |
| 目标课程单元 | 15 个单元 | 单元数量不是完成课次数，也不能直接当正式课程总讲数 |
| 教学活动 | 54 项：课堂 15、作业 14、测验 7、录播 4、学习资料 14 | 五组问题中应包含录播学习、资料内容和活动间关系 |
| 内容主题 | 有理数、数轴动点、整式、新定义运算、图形与方程等 | 示例应使用这些课题和实际文本，少用“课程xx”“查看报告” |

## 3. 代表性原文与问题推演

以下短摘录保留课程内容措辞，不包含账号、成员姓名、链接或访问凭据。问题是据此提出的设计假设，并非观察到教师真实输入的使用频次结论。

### A. 作业题目、提交与批阅

第 1 讲作业原文包含：

> 请按题号写出思路和关键步骤，预计用时 20–25 分钟

同时包含两张题目图片、两道文字题；其中一道文字题为：

> 已知有理数 a、b 满足 |a|=4，|b|=3，且 a+b<0。求 a、b 的所有可能取值，并分别计算 a−b

实际提交状态：3 人被分配，2 人已提交，1 人未提交。学生明细将两份提交标为“已提交待批阅”，但列表汇总的批阅计数为 2。**这是来源间差异，不是可直接宣布“全部批完”的证据。** 本轮仅记录，不猜测哪个接口必然正确。

一份提交的文字是“已按题号完成第1讲作业，计算过程见清晰答题纸”，并附有答题图片；另一份有详细文字解答，但自带“接口回归测试模拟作答；……不代表真实学情”的声明。

由此可推演：

- “第1讲作业还有谁没交？”
- “交上来的作业，哪些还需要我批阅？”
- “这位同学把过程写在图片里，帮我看看哪里需要反馈。”
- “把第4题的绝对值分类讨论讲得简单一点。”

回答边界：已提交、已批阅、评分和答题正确率分别表达；读到附件引用不代表已识别图片中的解题过程。本轮未做这些答题图片的视觉识别验收。

### B. 测验试题与学生结果

已读两份测验，每份 10 题，包含单选、多选、判断、填空、图片主观题，题目与答案解析可读。第 3 讲一题涉及两点在数轴上运动后相遇，另一题涉及追及前后距离为 5 的两个时刻。

两份测验的三名学生均未作答；逐题返回有 10 个位置，但均为“未参与”，没有可用实际成绩。部分图片主观题的纯文本题干为空，图片引用存在，不等于缺题。

由此可推演：

- “数轴动点这份测验主要考了哪些方法？”
- “把追及问题的解析换成学生容易理解的讲法。”
- “这份测验谁还没开始做？”
- “哪几题错得最多？”——当前样本没有作答，须明确暂无统计依据。

回答边界：能读题、能解释解法，不等于能统计学生错题。未参与不能算 0 分，也不能用于计算正确率。

### C. 课堂报告与笔记

第 1 讲课后报告返回授课时长 2713 秒（45 分 13 秒），应到 3 人、实到 0 人、迟到 0 人；还有 36 项课堂记录图片和 2 项板书图片。当前教师笔记包括“加减运算方法”“有理数综合题”“计算例题”“数轴概念”。

AI 教学分析状态为“已有记录”，本轮读取的是存在性状态，**没有取得分析全文**。课后报告也不是实时到课数据。应到 3、实到 0 必须保留，不能为了演示改成全勤。

由此可推演：

- “这节课有报告和板书吗？”
- “把我记的课堂笔记整理成回顾。”
- “这节课报告记录了哪些到课情况？”
- “帮我总结这节课的AI分析报告。”——需先读取全文，不能以存在性标志代替内容。

回答边界：笔记可以支撑有限回顾；板书数量不能证明已理解板书内容；课件计划内容也不能自动写成课堂实际发生的活动。

### D. 录播与学习资料

抽查两节录播的三名学生均为“未开始”，进度与时长均为 0；活动有视频附件及主题介绍。第 3 讲录播说明：

> 数轴上的动点问题。含8个讲解章节与课后自测

两份 PDF 学习资料的正文成功提取，均为一页，并有知识点、例题、分步解答和方法小结。第 1 讲原文包括：

> 看到绝对值先翻译成“距离”；看到混合运算先统一符号，再考虑简便计算

资料学生列表仅证明已分配；当前读取尚不能据此确认是否看完。

由此可推演：

- “这节录播大家学到哪了？”
- “帮我把第1讲资料里的学习方法整理成三点。”
- “这道绝对值题适合配哪份复习资料？”
- “资料都看完了吗？”——资料分配不是阅读完成，需要阅读记录。

## 4. 对设计的直接修正

1. 五组仍可沿用，但“课堂和参与”应覆盖录播学习，“报告和沟通”应覆盖课堂笔记与资料整理。
2. 问题同时覆盖查信息、看内容、分析结果、整理消息；不能只列提醒类问题。
3. 用“目前有哪些记录”表达覆盖，用“帮我看看”表达开放分析，避免入口承诺任意学生完整画像或全部课程历史。
4. 实测存在大量合法的空结果和未发生状态。引导应按当前数据选问题，不能为了填满五组就常驻不可回答的具体示例。
5. 本次只验证取数与内容依据；原版仍使用既有模拟 Adapter，V2 接口没有迁入原版。本报告不证明新通用问题已在原版自由对话中端到端通过。

- V2 `server/classin-test-reports.ts`：课后报告、本人笔记、AI分析存在性；读取范围没有分析全文。
