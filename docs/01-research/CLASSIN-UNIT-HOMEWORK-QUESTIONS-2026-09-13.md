## 1. 有理数综合提高（一） (草稿：等待第1讲清理范围确认)

1. 给定 −7/3、0、2.5、−4，写出全部负数，求 −4 的相反数，并指出绝对值最大的数及其绝对值。
2. 计算 (−18)+7−(−5)−9，写出减去负数时的变形。
3. 计算 (−3)²−24÷(−6)+(−2)³，分别写出乘方和除法的结果。
4. 早晨气温 −4℃，中午升高 7℃，晚上再降低 5℃。求中午、晚上气温及这三个时刻的最大温差。

**参考答案（未发布给学生）**

1. 负数为 −7/3、−4；相反数为 4；−4 的绝对值最大，为 4。
2. −18+7+5−9=−15。
3. 9、−4、−8；原式=9+4−8=5。
4. 3℃、−2℃；最大温差 7℃。

## 2. 有理数综合提高（二） (已发布)

1. 计算 (−2/3)×(9/4)÷(−3/2)，写出除法转乘法的步骤。
2. 比较 −2⁴ 与 (−2)⁴ 的值，并解释括号的作用。
3. 已知 |a|=3、|b|=2 且 a+b<0，求 a、b 的所有可能取值和对应的 ab。
4. 计算 25×(−17)+25×7，说明采用的运算律。

**参考答案（未发布给学生）**

1. (−2/3)×(9/4)×(−2/3)=1。
2. −2⁴=−16，(−2)⁴=16；前者乘方底数为 2，后者为 −2。
3. a=−3；b=2 时 ab=−6，b=−2 时 ab=6。
4. 25×(−17+7)=−250；乘法分配律。

## 3. 压轴题：数轴上的动点问题 (已发布)

1. 数轴上 A=−6、B=8，求 AB 长度和 AB 中点所表示的数。
2. P 从 −6 出发，沿数轴正方向以每秒 2 个单位运动。写出 t 秒后的位置，并求到达 8 的时间。
3. P 从 −6 以每秒 2 个单位向右运动，Q 从 8 同时以每秒 1 个单位向左运动。何时相遇，在哪个数处相遇？
4. P 从 −6 以每秒 2 个单位向右运动；B 固定在 8。求 t≥0 时 PB=4 的所有时刻。

**参考答案（未发布给学生）**

1. 长度 14，中点为 1。
2. 位置 −6+2t，t≥0；7 秒。
3. 14/3 秒，位置 10/3。
4. |−6+2t−8|=4，t=5 或 9 秒。

## 4. 整式综合提高（一） (已发布)

1. 指出单项式 −3x²y 的系数与次数；指出多项式 2x²−3x+5 的项数与次数。
2. 判断 3a²b、−5ab²、7a²b 中哪些是同类项，并说明理由。
3. 化简 4x²−3x+2−(x²+5x−6)。
4. 先化简 2(3a−b)−3(a+2b)，再求 a=−2、b=1 时的值。

**参考答案（未发布给学生）**

1. 系数 −3，次数 3；多项式有 3 项，次数 2。
2. 3a²b 和 7a²b 是同类项，字母及对应指数相同。
3. 3x²−8x+8。
4. 3a−8b，代入得 −14。

## 5. 整式综合提高（二） (已发布)

1. 已知 A=2x²−3x+1，B=−x²+4x−2，求 2A−B。
2. 多项式 (m−2)x²+(3n+6)x+5 不含 x² 项和 x 项，求 m、n。
3. 长方形的长为 2a+3、宽为 a−1（a>1），用含 a 的式子表示周长，并求 a=4 时的周长。
4. 化简 3[2x−(x−4)]−2(x+1)，并检查 x=−1 时原式与化简式是否一致。

**参考答案（未发布给学生）**

1. 5x²−10x+4。
2. m=2，n=−2。
3. 周长 6a+4；a=4 时为 28。
4. x+10；两式在 x=−1 时均为 9。

## 6. 压轴题：定义新运算与数阵图 (已发布)

1. 定义 a★b=2a−b，计算 3★(−2) 与 (3★1)★2。
2. 仍定义 a★b=2a−b，分别计算 2★5、5★2，并判断这种运算是否满足交换律。
3. 三行三列数阵按行排列为 (8,1,6)、(3,x,7)、(4,9,2)。若每行的和相等，求 x，并检验每列的和。
4. 把第 3 题数阵每个数都增加 k，新数阵每行的和用 k 表示。若行和变为 24，求 k。

**参考答案（未发布给学生）**

1. 8；(3★1)★2=5★2=8。
2. −1、8；不满足交换律，这是一组反例。
3. x=5，每行每列的和都是 15。
4. 15+3k；k=3。

## 7. 压轴题：运算类新定义问题 (已发布)

1. 定义 a△b=a+b−ab，计算 (−2)△3。
2. 定义 a△b=a+b−ab，求所有满足 x△2=5 的 x。
3. 在上述定义下，求使任意 a 都满足 a△e=a 的常数 e，并用代入检验。
4. 定义 [x]₊ 在 x≥0 时等于 x，在 x<0 时等于 0。计算 [−3]₊+[5]₊，并求 [x−2]₊=3 的 x。

**参考答案（未发布给学生）**

1. −2+3−(−2)×3=7。
2. x+2−2x=5，x=−3。
3. e=0；a△0=a。令 a=0 也可知 e 必须为 0。
4. 结果为 5；x=5。

## 8. 图形初步综合提高 (已发布)

1. 一条直线上依次有 A、B、C 三点。由这些点确定多少条不同直线、多少条线段？列出线段名称。
2. 四个点中任意三点不共线，每两点连一条直线，一共确定多少条不同直线？说明数法。
3. 点 C 在线段 AB 内，AB=12、AC=5，求 BC；若 M 为 AB 中点，求 CM。
4. 正方体有几个面、几条棱、几个顶点？若每条棱长 3 厘米，所有棱长之和是多少？

**参考答案（未发布给学生）**

1. 1 条直线、3 条线段：AB、AC、BC。
2. 6 条，每条由一对点确定，4×3÷2=6。
3. BC=7；AM=6，所以 CM=1。
4. 6 个面、12 条棱、8 个顶点；总棱长 36 厘米。

## 11. 压轴题：动射线与角度计算 (已发布)

1. OA 固定为水平向右方向，OP 从 OA 出发逆时针匀速转动，每秒 6°，0≤t≤30。写出 ∠AOP，并求 t=10 秒时的角度。
2. 仍按第 1 题条件，OP 首次转到与 OA 垂直的位置需要多少秒？
3. OA 方向为 0°，OB 方向为逆时针 120°。OP 从 OA 以 6°/秒逆时针转动，OQ 从 OB 同时以 4°/秒顺时针转动。两射线首次重合的时间和方向是多少？
4. OA 方向为 0°，OB 方向为逆时针 120°。OP 从 OA 以 6°/秒逆时针转动，0≤t≤20。求 ∠POB=30° 时的 t。

**参考答案（未发布给学生）**

1. ∠AOP=6t°，10 秒时为 60°。
2. 6t=90，t=15 秒。
3. 6t=120−4t，t=12 秒；方向为逆时针 72°。
4. 120−6t=30，t=15 秒；限定区间内只有这一解。

## 12. 一元一次方程综合提高 (已发布)

1. 解方程 3(2x−1)−2(x+4)=5，并检验。
2. 解方程 (x−1)/3−(x+2)/2=1，写出去分母步骤。
3. 若 x=2 是方程 (a−1)x+3=7 的解，求 a。
4. 有人把 2(x−3)=x+4 写成 2x−3=x+4，得到 x=7。指出错误并给出正确解。

**参考答案（未发布给学生）**

1. 4x−11=5，x=4；代入左边得 5。
2. 2(x−1)−3(x+2)=6，x=−14。
3. 2(a−1)+3=7，a=3。
4. 分配律漏乘常数项；2x−6=x+4，x=10。

## 13. 方程应用综合提高 (已发布)

1. 一本练习册售价 8 元，一支笔售价 3 元。买 5 本练习册和若干支笔共花 61 元。列方程求笔的支数。
2. 甲、乙相距 180 千米，同时相向行驶，速度分别为 40 千米/时和 50 千米/时。列方程求相遇时间。
3. 某商品按标价的八折出售，售价比成本 120 元高 20%。求标价。
4. 甲 6 天独立完成一项工作，乙 12 天独立完成。甲先做 2 天，随后两人合作，还需几天完成？

**参考答案（未发布给学生）**

1. 40+3x=61，x=7 支。
2. (40+50)t=180，t=2 小时。
3. 0.8x=120×1.2，标价 180 元。
4. 2/6+(1/6+1/12)t=1，t=8/3 天。

## 14. 压轴题：数轴与新定义问题综合 (已发布)

1. 定义数轴上的距离 d(a,b)=|a−b|，求 d(−4,3)，并求 d(x,−4)=2 的所有 x。
2. 定义 F(x)=|x+2|+|x−4|。求 F(x) 的最小值，并写出取到最小值时 x 的范围。
3. 定义到数 1 的镜像变换 R(x)=2−x。求 R(−3)、R(R(−3))，并用一般式说明连续变换两次的结果。
4. P 从 −4 出发，以每秒 2 个单位向右运动。定义 H(t)=|P 所表示的数−2|，t≥0。求 H(t)=4 的全部时刻。

**参考答案（未发布给学生）**

1. 距离为 7；x=−6 或 −2。
2. 最小值 6；−2≤x≤4。可解释为到 −2 和 4 两点的距离之和。
3. 5、−3；R(R(x))=2−(2−x)=x。
4. |−4+2t−2|=4，t=1 或 5 秒。
