## 2. 来源政策与版本基线

### 2.1 官方基线

- `OFFICIAL_VERIFIED`：教育部《2024年义务教育国家课程教学用书目录（根据2022年版课程标准修订）》列出人民教育出版社小学数学一年级上册至六年级下册，并注明均有配套教师用书。[教育部目录 PDF](https://www.moe.gov.cn/srcsite/A26/s8001/202408/W020240805496325238752.pdf)
- `OFFICIAL_VERIFIED`：人教社 2024 年“新教材简介”说明，新教材按知识逻辑与学生学习心理逻辑组织，强调整数、小数、分数中的计数单位主线及纵向衔接。[人教社新教材简介](https://www.pep.com.cn/xw/zt/hd/12/xjcjs/xx/202409/t20240920_1995566.html)
- `OFFICIAL_VERIFIED`：国家中小学智慧教育平台由教育部建设，公开报道说明平台上线电子版教材；但教材页可能要求正常登录，且自动抓取会返回 `403`。[教育部平台说明](https://www.moe.gov.cn/fbh/live/2022/54251/mtbd/202203/t20220302_603689.html) · [官方教材入口](https://basic.smartedu.cn/tchMaterial)

官方目录能确认书目体系存在，不能替代具体教材页面；人教社 2024 年新教材介绍也不能反向证明用户提供的 2022 年审定副本与后续逐年启用版本内容完全一致。

## 5. 用户人工获取建议

1. 优先使用学校已配发纸质书、教师用书，或本人有权访问的国家中小学智慧教育平台教材。
2. 在官方平台依次筛选“小学 → 数学 → 人教版 → 年级/册次”，正常登录后使用平台允许的阅读或下载能力。
3. 若平台只允许在线阅读，请记录教材封面、版权页、目录和目标章节页码；不要抓取接口、复制登录令牌、绕过 DRM 或批量下载限制。
4. 若只能取得 GitHub 候选副本，把它标为 `THIRD_PARTY_COPY`，先核对封面审定年份、版权页版次/ISBN和目录，再决定能否用于研究对照。
5. 私有或学校授权材料可以放在项目忽略目录中供本地研究，但在许可确认前不提交仓库、不上传外部服务、不作为可再分发产物。

## 7. 获取后的证据提取计划

### E1 版本验真

对每册记录书名、出版社、审定年份、版次、印次、ISBN、总页数、来源类别和文件哈希；建立教材印刷页与 PDF 页序映射。

### E2 低年级前置地图

逐页提取二下“平均分 → 两种分法 → 除法符号/意义 → 图、操作、语言与算式”的任务序列，区分教材明确要求与研究推断。必要时再回溯二上表内乘法。

### E3 高年级发展地图

逐页提取五下“单位‘1’ → 分数意义 → 分数单位 → 分数与除法 → 基本性质 → 约分/通分/比较 → 加减法”的实际编排；只在教材证据支持时保留这条顺序。

### E4 纵向对齐矩阵

以三上第一课时的概念元素为行，标记：

- 低年级已经形成什么经验；
- 三上首次命名或符号化什么；
- 三上本单元怎样立即发展；
- 五下怎样正式化与一般化；
- 六上运算怎样调用这些概念；
- 哪些高年级语言不得提前作为三上机械规则。

### E5 冲突与人工 Review

对不同版次的章节位置、术语、例题和表征差异建立冲突表，再交由用户决定项目采用版本；证据不足处继续标 `UNKNOWN`。
