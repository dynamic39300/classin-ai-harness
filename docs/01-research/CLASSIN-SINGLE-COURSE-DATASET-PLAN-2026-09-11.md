# 单课程真实数据集方案

## 结论

本次不再用多个机构、教师或课程的片段补齐活动类型。已从本机受控的 DW 原始快照中选定一条连续的中文数学课程作为唯一来源，内部引用为 `source-course-20260909-01`。其教师、班级、课程分类、单元和活动关系保持原样；源身份、标识、附件链接和学生个人信息继续只留在受限私有区。

该来源是一套 14 讲的专题课程。每讲有明确教学主题和单元顺序；已开讲的首讲已经具备课堂、课程资料、作业、课后录播，以及真实的提交与批改末态。后续讲次包含真实课程计划中的活动草稿。来源没有测验活动，测试数据集也不得为了“齐全”而把测验伪装成该课程真实组成部分。

## 已核对的真实结构

| 对象 | 源课程中的数量 | 真实性说明 |
| --- | ---: | --- |
| 教学单元 | 14 个主题单元，另有课程资料与使用说明单元 | 同一课程计划的原始目录 |
| 课堂 | 14 | 每讲一个课堂 |
| 作业 | 15 | 包含每讲作业模板及首讲的已发布作业 |
| 录播 | 16 | 包含首讲已发布的作业讲解和后续讲次的真实草稿 |
| 学习资料 | 16 | 包含首讲资料、电子讲义和课程使用说明 |
| 测验 | 0 | 该来源没有该类型，保留为缺失而非补造 |

这套数据的教学主题、单元顺序、课堂—资料—作业—录播的对应关系来自同一课程，不再把其他课程的内容、题目、活动状态或学生表现并入。

## 测试环境的映射规则

1. 在当前测试教师拥有的班级内创建一个独立课程分类，并按源目录顺序创建单元和活动。
2. 用一个统一时间偏移整体平移源课程，保留课堂、资料、作业和录播之间的相对先后；不压缩课次间隔，也不分别改写每个活动的日期。
3. 课程标题、单元主题、课堂名称、作业说明和活动配置从同一来源映射。跨机构的文件标识、云盘链接和学生身份不复制；只有在资源已重新上传到测试环境并可读时，才写入目标活动。
4. 真实学生的姓名、UID、答案和提交记录不进入测试环境。若要复现源课程的学员规模及“未交、已交待批、已批”等状态，必须先创建或指定等量的脱敏测试学员，再通过受支持的测试端操作产生相应状态；不能把 DW 的末态直接写成虚构的历史事件。
5. 当前已有的一条跨来源作业仅作为“接口写入已验证”的证据，不属于本数据集，也不参与后续验收。

## 已执行的目标环境写入

已在测试教师的既有测试班级内创建独立课程分类，并按同一来源课程的目录写入 14 讲课堂。课堂时间统一在源课程时间上平移 7 天，首讲为 2026-09-13 15:30，末讲为 2026-12-20 15:30。每个已写入课堂保留原始课长、录课开关、非公开回放、教师手动评分和可见发布状态；课程分类与主题单元保持同一课程的中文数学目录。

首次写入第 8 讲时，环境曾返回当前测试账号已经达到“当月累计创建课堂”上限；该请求未创建对象。测试机构随后将累计和每月课堂数量限制调整为不限。重试第 8 讲以及后续第 9–14 讲均收到测试环境的业务成功回执，14 个课堂已全部完成写入。

首讲的初次请求使用了接口文档中的 JSON 形式 `unitName` 示例，而测试环境将其作为普通字符串创建了自动单元。随后已将含课堂的自动单元修正为首讲主题名，并保留原先创建的空单元，改名为“课程结构”以避免重名。单元批量删除接口在此测试环境返回未部署，因此未进行非文档化删除。后续课堂使用纯文本单元名，已正确复用原有主题单元。

## 导入完成条件

- 读取接口能返回同一测试班级下的课程分类、单元、课堂、资料、作业与录播，并保持源课程的相对顺序和关联；
- 每项写入都由对应详情接口回读确认；
- 每个目标资源都在测试环境中可访问，不引用来源机构的资源标识；
- 学员名单与作业/录播进度只使用脱敏测试身份；个人状态通过真实可支持的测试操作产生；
- 导入清单、时间偏移和源—目标映射只放在 Git 忽略的受限目录，仓库不保存真实学员信息或凭证。

## 当前缺口

当前测试班级只有一个可用测试学员。已实际验证两条文档化学生创建链路：机构学生批量导入被目标环境拒绝，单个学生创建也被目标环境拒绝；两次均未创建账号。本轮进一步核对后，创建返回参数错误、机构学生读取成功但结果为空；目前尚不能据此断言教师 secret 没有创建权限，需核对机构上下文和字段契约。需要测试机构管理员会话、已批准的测试学员种子服务，或由环境管理员预先创建脱敏学员后，才能继续构造作业提交、批改、观看和测验答题等学情状态。

此外，源课程的附件和录播文件不能跨机构复制；必须先在测试环境重新上传或指定可访问的测试资源，才可创建对应学习资料和录播。源课程本身没有测验，不能为补齐字段而伪造测验活动。

课堂配额已解除，课程结构已完成导入。首讲一项已发布作业已依据源课程标题、正文和时间写入目标环境，并由教师作业详情接口回读。源课程资料和录播均带附件，测试环境尚无可绑定的测试副本；当前不能跨机构复制来源文件引用。后续仍需提供受支持的脱敏学员与资源准备链路；在此之前，数据集处于“同源课程结构和一项正文作业已导入、资源文件与学员状态未导入”的状态，不能声称已完成完整学情数据迁移。
