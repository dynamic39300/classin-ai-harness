# 三年级数学课件生成 V2 M0-B 课程标准证据包

## 1. 文档定位

本文是已通过用户 Review 的 **M0-B 课程标准证据包**。它核对《义务教育数学课程标准（2022 年版）》以及教育部、人民教育出版社一手公开资料，为目标课建立课程标准证据边界。

用户于 2026-09-05 通过 `USER_REVIEWED` Gate：接受 R-01、R-02、R-06、R-07；R-03、R-04、R-05 明确暂缓到后续 M0-C/D/F/H，不把未知项写成已决定内容。本文不替代教材内容地图、教师教学用书、真实学情或教师教学判断，也不把课程标准的学段要求直接改写成一节课必须全部完成的目标。

### 1.1 固定研究范围

- 学科与年级：小学数学三年级，属于第二学段（3～4 年级）；
- 教材坐标：人教版三年级上册《分数的初步认识》第一课时；
- 当前项目情境：40 分钟、普通公立校、中等水平班级；
- 本文只判断课程标准依据及其可支持的项目推导，不决定教材页码、例题顺序和最终课时切分。

### 1.2 结论标签

| 标签 | 本文中的含义 |
| --- | --- |
| `DIRECT_REQUIREMENT` | 正式课程标准直接规定的课程目标、内容要求、学业要求、学业质量或课程实施要求；仍需遵守其原有学段和章节范围 |
| `SUPPORTED_INFERENCE` | 由一手证据支持、但不是课标逐字规定的本项目推导；必须保留推导链和适用边界 |
| `PROJECT_DECISION` | 为首条样板课作出的产品或教学取舍；不能冒充国家课程要求 |
| `UNKNOWN` | 当前一手证据不能决定，需由教材、教师用书、课堂约束或用户 Review 关闭 |

## 3. 课程标准直接要求

### DR-01 适用学段与阶段目标

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：课程标准将 3～4 年级划为第二学段。第二学段目标要求学生经历小数和分数的形成过程、初步认识小数和分数，并在“数与运算”相关学习中形成数感、运算能力和初步推理意识。
- **原始位置**：[S-02，三、课程目标，（三）学段目标，2. 第二学段，p. 13](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=21)。
- **适用边界**：这是两学年的阶段目标，不等于第一课时同时承担分数加减运算或完整推理训练。

### DR-02 第二学段“数与运算”的内容要求

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：第二学段要求在具体情境中初步认识小数和分数、感悟分数单位，并安排同分母分数加减法。该条同时指向附录例 9。
- **原始位置**：[S-02，四、课程内容，第二学段（3～4 年级），数与代数，内容要求 1（2），pp. 20–21](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=28)；[S-03 人教社转载版，p. 21](https://www.pep.com.cn/xw/zt/rjwy/yjkb2022/202205/P020220512583134605579.pdf#page=29)。
- **适用边界**：“具体情境”和“感悟分数单位”是直接要求；课标没有规定必须使用月饼、圆片或某一教材例题，也没有规定第一课时必须出现“分数单位”术语。

### DR-03 第二学段“数与运算”的学业要求

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：学生应能结合具体实例初步认识小数和分数，比较简单小数和分数的大小，并完成简单的相关加减运算；相应学习指向数感、运算能力和初步推理意识。
- **原始位置**：[S-02，四、课程内容，第二学段，数与代数，学业要求 1. 数与运算，pp. 21–22](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=29)。
- **适用边界**：这是第二学段累计学业要求。“比较分数大小”不能据此直接判定为《几分之一》第一课时的必教内容，更不能推定第一课时必须总结一般比较法则。

### DR-04 附录例 9 对“感悟分数单位”的说明

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：正式课标用例 9 说明“感悟分数单位”：以两个同样大小的圆直观比较 `1/2` 与 `1/3`，再把二者转化到相同的六分之一单位理解大小关系，从而连接“相同单位下比较”与整数比较的一致性。
- **原始位置**：[S-02，附录 1，例 9“感悟分数单位”，p. 103](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=111)。
- **适用边界**：例 9 是正式标准中的解释性案例，说明该要求的数学方向；它不是对所有教材、所有第一课时的固定活动脚本。将两个圆都化为六等份的深度是否适合本样板课，仍需教学判断。

### DR-05 与本课相关的核心素养内涵

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：小学阶段核心素养包含数感、符号意识、几何直观、推理意识等表现。其中，数感关注对数、数量及数量关系的直观感悟；符号意识关注理解符号功能和运用符号表示数量、关系与规律；几何直观关注用图表描述和分析问题；推理意识关注依据事实和规则作出初步推断并说明合理性。
- **原始位置**：[S-02，三、课程目标，表 1，数感 p. 7、符号意识和几何直观 p. 8、推理意识 p. 9](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=15)。
- **适用边界**：课标没有指定一节分数课必须平均覆盖所有核心素养。把图形表征对应到几何直观、把分数写法对应到符号意识，是本项目的有证据推导，不是该表针对本课的逐项指令。

### DR-06 教学目标、内容组织和教学方式

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：课程实施要求教学目标体现核心素养、具有整体性和阶段性；教学内容应结构化，并处理内容主线与核心素养的联系；教学方式应从单一讲授转向启发、探究、参与和互动，让学生经历实践、探究、体验、反思、合作与交流。
- **原始位置**：[S-02，六、课程实施，（一）教学建议，1–3，pp. 84–86](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=92)。
- **适用边界**：这是全课程教学建议。它要求活动服务于数学目标，但不意味着每节课都必须同时采用合作学习、项目学习和信息技术。

### DR-07 情境与问题提出

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：教学建议要求创设真实情境，素材应贴近学生生活经验并符合年龄与认知特点；应在情境中提出能引发思考的问题，也可引导学生提出合理问题，使学生经历观察、数学思考、数学表达、概括归纳和迁移运用。
- **原始位置**：[S-02，六、课程实施，（一）教学建议，3（3）“强化情境设计与问题提出”，p. 87](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=95)。
- **适用边界**：“真实情境”不等于必须使用照片、复杂故事或跨学科项目；本课情境是否真实、简洁并能暴露“平均分”的数学需要，必须结合具体设计审查。

### DR-08 第二学段学业质量

- **标签**：`DIRECT_REQUIREMENT`
- **事实**：第二学段学业质量要求学生能结合具体情境初步认识小数和分数，形成数感、运算能力和初步推理意识；能结合现实生活描述、表达、分析和解释实际问题；并通过操作、游戏等活动形成求知欲、独立思考与合作探究习惯。
- **原始位置**：[S-02，五、学业质量，（二）学业质量描述，表 3，第二学段，pp. 81–82](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=89)。
- **适用边界**：学业质量是阶段性综合表现，不能直接变成一节课的逐题评分标准；本课只应抽取可观察、与当前内容直接相关的表现。

## 4. 有证据的项目推导

### SI-01 概念形成链应先于符号记忆

- **标签**：`SUPPORTED_INFERENCE`
- **推导**：DR-01 要求“经历形成过程”，DR-02 要求“结合具体情境”，人教社公开材料又展示了从实物或图形的平均分、取其中一份，到几分之一表象和符号的路径。因此，首课至少应保留 `具体情境 → 平均分操作/观察 → 图形表征 → 语言表达 → 分数符号` 的可观察链路，而不能只给定义、读写规则和答案。
- **证据**：[S-02 pp. 13、20–22](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=21)；[S-04 刊物页 14](https://zxxszhjx.pep.com.cn/ebook/202111/files/basic-html/page16.html)。
- **边界**：链路成立不代表必须采用披萨、月饼或数字交互工具。

### SI-02 “整体相同、平均分”应成为判断表征有效性的条件

- **标签**：`SUPPORTED_INFERENCE`
- **推导**：DR-04 的比较案例明确使用两个同样大小的圆，并以平均分和统一分数单位解释大小。由此可推导：首课中的图示、比较题和反馈不能省略整体基准与平均分条件，否则可能让学生只比较涂色面积或分母数字。
- **证据**：[S-02 附录例 9，p. 103](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=111)。
- **边界**：是否在第一课时正式讲“相同单位下比较”，仍是 `UNKNOWN`；这里只规定课件不能制造数学上不充分的比较证据。

### SI-03 核心素养应转成学生可观察行为

- **标签**：`SUPPORTED_INFERENCE`
- **推导**：结合 DR-05、DR-06 和 DR-08，本课不宜仅把“发展数感、推理意识”写成口号，而应转成可以观察的表现，例如：能说明为何必须平均分、能把操作或图形与 `1/n` 对应、能说明某个图形是否正确表示给定分数、能用图形或语言解释直观比较结果。
- **证据**：[S-02 表 1，pp. 7–9](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=15)；[S-02 表 3，pp. 81–82](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=89)。
- **边界**：具体行为数量、成功标准和题目形式属于后续 Assessment Blueprint 与教师 Review。

### SI-04 课件需要承载学生动作与反馈，而非只有讲稿

- **标签**：`SUPPORTED_INFERENCE`
- **推导**：DR-06、DR-07 和 DR-08共同支持在首课安排短而可执行的观察、分一分、折一折、涂一涂、解释或判断活动，并让教师看到学生如何作答。课件生成结果应显式记录 `学生动作 → 预期证据 → 教师追问/反馈`。
- **证据**：[S-02 教学建议 pp. 86–87](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=94)；[S-02 学业质量 pp. 81–82](https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220510531636118932.pdf#page=89)。
- **边界**：课标不要求固定活动数量，也不要求所有活动使用小组合作或信息技术。

## 7. 对后续资料包的输入约束

在用户 Review 前，M0-C 至 M0-G 可以把以下内容作为候选约束使用，但不得标记为用户已接受：
