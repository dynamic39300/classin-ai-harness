# WorkBuddy M4.1 用户端到端验收清单

## 1. 使用方式与边界

> 用户验收结论（2026-08-22）：M4.1 两条 Agent Run 主链已完成端到端验收，整体通过；AI Agent 导航调整也已完成。未提出阻塞性修改意见，本清单作为 UI Freeze 的验收证据保留。

- 入口：`http://127.0.0.1:4173/teacher/ai-agent`；如当前不在教师视角，先切换为“老师”。
- 每条主链请从“新建任务”开始；需要重做 Core Context 时使用右侧的“重新选择”。
- 在每一项前填写 `✅ 通过 / ⚠️ 有意见 / ❌ 不通过 / — 未测`，并将意见记到该项的“备注”。
- 当前验收的是**确定性 Agent Run 体验层**：页面模拟 Goal → Context → Plan → Process → Artifact → Action → Approval → Receipt 的交互与状态，不代表已接入真实 Agent、真实 Skill/Tool 或生产 ClassIn 写回。
- 不以“最终页面是否显示”为唯一通过标准；请同时检查事件顺序、运行中状态、可执行按钮、右侧区和返回/恢复行为。

## 3. B｜单个智能课件：从 Goal 到 Plan

| ID | 操作与检查点 | 预期结果 | 结果 | 备注 |
| --- | --- | --- | --- | --- |
| B-01 | 点击“创建任务” | URL 进入该 Run；任务标题、Goal、上下文计数和 Timeline 同时可见 |  |  |
| B-02 | 观察首段动态过程；完成一次课件后返回新建任务并再次创建 | 每次都先出现“正在整理任务与上下文”，再出现目标理解与补参；新任务不复用旧 Run 的过程或产物，不直接跳到完成态 |  |  |
| B-03 | 检查 Timeline 连续性 | Goal、目标理解、补参、Context、Plan 都在同一个时间线中，没有阶段页跳转 |  |  |
| B-04 | 在补参卡选择课时、时长、教材版本、课件风格 | 字段可读、顺序自然；提交前不应进入执行或生成产物 |  |  |

| B-07 | 点击“返回修改”或“取消任务”（可另开新任务验证） | 返回修改不产生假完成；取消后任务明确为已取消，开始/取消/继续及补充输入均不可再执行 |  |  |
| B-08 | 在待确认 Plan 点击“开始执行计划” | 计划确认后才开始动态执行；执行中出现“停止执行” |  |  |

## 4. C｜单个智能课件：Process、Skill/Tool 与 Artifact

前置：完成 B-01 至 B-08。

| ID | 操作与检查点 | 预期结果 | 结果 | 备注 |
| --- | --- | --- | --- | --- |
| C-01 | 观察执行中的首个能力调用 | Header 显示当前步骤和整体预计剩余时间；Composer 上方显示“正在执行 · 当前步骤”和“第 1/4 步”进度胶囊，执行语句存在克制的文字亮面扫过；活动步骤显示旋转加载、“运行中”和本步剩余时间，其他步骤为等待/队列状态；首步持续约 `3s`，不能一闪而过 |  |  |
| C-01a | 悬停、聚焦或点击进度胶囊，再按 `Escape` | 胶囊上方展开四步清单，明确显示已完成、进行中与等待状态；浮层可通过键盘访问并由 `Escape` 收起；Reduced Motion 下动画停止但状态文字完整 |  |  |
| C-02 | 展开“查看技术证据” | 可看到教师可理解的调用目的、输入摘要、Context Projection 和输出摘要 |  |  |

| C-04 | 执行中输入普通补充要求并发送 | Timeline 记录教师补充；已完成内容不被静默改写，未开始步骤可吸收该要求 |  |  |
| C-05 | 点击“停止执行” | Run 和当前过程显示已停止；出现“继续执行”；已完成步骤保持完成 |  |  |
| C-06 | 点击“继续执行” | 从停止位置继续，已完成步骤不重复运行，最终进入 Artifact |  |  |
| C-07 | 等待完成 | Timeline 依序完成过程事件并出现智能课件 Artifact；右侧“产出”可打开/自动提示 |  |  |
| C-08 | 在右侧切换“上下文 / 产出” | 两种视图均可切换；切换不丢 Timeline、Composer 内容、Context 选择或产出状态 |  |  |
| C-09 | 产出自动打开后点击“收起辅助区” | 辅助区完整退出布局，主工作区恢复单列；Composer 与产出预览不能上下错位或同时占据主区域 |  |  |
