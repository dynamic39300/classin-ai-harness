# 产品需求

## 当前校准：原工作区 + 真实读取 + 模拟补齐（D-156）

2026-09-15 用户确认：恢复 `/teacher/messages` 原系统导航、会话列表、时间线、Composer、四阶段 AI 消息助手与全部原有功能；只调整 Copilot 的数据及交付 Adapter。测试班独立加入原列表，原物理演示班继续模拟；`/teacher/classin-test` 保留数据核验用途并提供返回消息入口。

当前验收覆盖：真实教师/班级/课程/五类活动查询、当前课表和作业提醒、AI 生成/修改/审阅、教师端模拟发送与可恢复历史。未接入的实时出勤、AI 分析全文/媒体理解、测验作答/批阅、个性化学习结果和业务改期以明确标注的模拟样本支持体验；样本以课程主题为上下文，不改真实活动/学生记录。原各模块已有 Mock 功能继续可操作。

R4 替换为：教师确认后在本机当前班级消息时间线看到模拟发送及回执，刷新后可恢复；学生角色不可读取该测试 Thread，不产生送达或已读。真实 IM 的合同/学生接收不再是本阶段完成门槛。

R1/R3/R5 补充：来源为真实 API 的事实保留原值和权限；模拟补充必须独立来源并写明“模拟”，不能覆盖真实的 0、空、未提交、未生成或 API 失败。真实读取失败保留错误与重试，演示班仍可使用。完整系统框架保持；本次不扩展全站真实业务写入。

下方为上一阶段需求及真实接入后续目标；与本节冲突时以本节为准。

## 问题与目标

当前 IM Copilot 的模型可真实运行，班级、课堂、学生和发送结果仍由 Mock 提供。老师需要围绕自己测试账号的真实 ClassIn 对象生成提醒，并最终在测试客户端核验学生收到。来源于测试 API 的已构造内容标为测试数据，不能称为自然发生的线上教学记录。

以[已批准的升级方案](../../../06-architecture/CLASSIN-TEST-INTEGRATION-UPGRADE-PLAN-2026-09-14.md)为范围依据。用户将于 2026-09-15 上午整体回归；时间承诺不改变完成标准。依赖未取得、未实测的能力保留未完成状态。

## 需求与验收

| 需求 | 教师可见结果 | 验收条件 |
| --- | --- | --- |
| R1 身份与现场 | 独立的测试连接入口显示授权老师的班级、课程、单元及活动 | 上游归属与分页核对；无 Mock 数据混入；凭据仅在本机服务端 |
| R2 时间与提醒 | 真实时间下显示下一节课、课前提醒和已发布学习任务 | 课堂开始前 24 小时内可提醒；未开始、结束、取消和无近期课分开；不据课后报告声称实时全勤 |
| R3 证据与生成 | AI 回答及消息草稿引用同一现场的课题、日期、分配与状态 | 对象可追溯；缺失结果明确未知；不补造学生得分、作答和媒体 |
| R4 消息交付 | 审阅后发到正确测试群，并获可核实回执 | 需要正式普通 IM 接入合同、群身份核验、消息回读及三名学生客户端证据；缺少时明确发送未接通 |
| R5 结果扩展 | 可查询作业、测验、录播、资料、课堂结果，审阅实际提交的答题附件 | 按需读取、分清题干附件与学生答卷、名单与参与、未批与零分；不能用列表数量替代学习结果；图片显示与AI识别分开验证 |
| R6 持续使用 | 刷新、断网、鉴权失败可恢复且无串数据 | 错误分类、更新时刻、隔离会话、读取耗时、权限反例和整体回归记录 |

## 范围和授权

仅当前已授权的测试教师、目标测试班级、数学课程和三个测试学生。通过文档与实际权限发现对象；不迁移生产数据，不开发全站真实写入，不把 Mock 编辑页作为真实对象导航。既有 Demo 继续独立可用。

测试环境接入可以采用独立教师路由作为纵向入口，复用已评审的 AI 消息助手。入口显示连接状态、数据更新时间与消息通道状态，教师无需选择模型、Agent 或内部工具。待 IM 合同取得后接入普通消息生命周期；中间只读现场不能标为全链路完成。

用户授权必要的本机实现、接口读取与已限定测试对象上的验证。实际产品中的发消息仍由老师明确审阅确认；没有正式发送证据时提供草稿，不能显示发送成功。
