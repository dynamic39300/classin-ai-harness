# 边界

- B1 当前只验证已结束课堂的正式课后报告。未来课堂会被执行器拒绝，不把课后接口包装成实时成员考勤；成员级实时进入、离开和当前在线名单仍未接入。
- E1 的回放工具只给模型文件数量、状态、时长、时间和可播放版本数量，不把 FileId、播放 URL 或票据放进 Context。
- A1 按课程分别表达课堂进度，不用作业、资料和课堂的混合数量生成一个虚假百分比。
- A3 只把 identity=1 计为学生；回答人数时不输入完整成员名单。
- 开放式入口只暴露现有白名单只读工具，没有任意 URL、shell 或写工具。
