# 形成的处理原则

先回答直接问题，相关拓展必须有信息增量。不同任务的详略分别约束：课程与作业简洁、课堂知识回顾详实、聊天要点高度提炼。接口调用成功不能代替业务相关性；用户勾选候选后，以实际提出的信息需求确定是否调用该接口，不机械执行候选地址。

本次 C2 要的是姓名、截止及准时性，分别来自成员表、作业详情和 students.refTime；student/detail 的正文/评语并不是完成这些改进的必要输入。Apifox 3471069 的已保存字段文档明确 refTime 为提交时间，thTime 为批阅时间。add_time 不能作为提交时间。

本次 E2 用户审阅的是第二讲数学课堂；此前另一样本出现《白鹭》课题不匹配，不能把该异常一概套在所有课堂上。对应报告主题与数学课相关，但其生成对白仍不等于原始逐字稿。
