# ClassIn WorkBuddy V1 页面级 PRD

## 1. 共通页面契约

每个页面/Overlay 均须具备：

- 清晰的用户目的和唯一主要行动；
- 对象来源、当前组织和权限边界；
- loading、loaded、empty、partial、recoverable failure、permission denied、offline/unavailable；
- 提交防重复、成功反馈、破坏性确认、stale/conflict；
- Deep Link 与返回现场；
- Mock、真实、集成模拟和未来能力真值标签；
- 可见 Focus、键盘顺序、关闭后焦点归还和不只靠颜色的状态。

本文件只定义页面编排。业务数据、Context、能力调用、Artifact 和写回分别通过对应 Interface 获取，页面不得直接拼接底层 API 或 Skill 参数。

## 2. 全局壳与二级导航

### WB-G-P01 ClassIn 共享应用壳

**目的**：持续表达教师身份、当前组织、一级位置、全局消息和账户，并进入 Work Buddy。

**区域**：品牌/组织区、一级导航、当前一级项、顶部工具区、账户区、主内容插槽。

**规则**：

- `Work Buddy` 与首页、课程表、班级、待办、空间、教学洞察同级；
- 一级入口的导航与展开按钮相互独立：点击名称进入当前/新任务，点击箭头只展开或收起二级目录；
- 展开按钮保留独立点击热区，但视觉并入一级导航行：默认与 Hover 不增加独立卡片底色，方向表达展开状态，键盘 Focus 使用标准焦点环；
- Work Buddy 新建任务与具体 Run 隐藏通用页面标题栏，由 Work Surface 顶部任务 Tab 直接表达当前工作现场；技能市场等二级能力页隐藏任务 Tab，使用通用 Topbar 显示当前目的地名称；
- 切换一级模块保存当前 Run 草稿和页面现场，不把 Run 当成一次性聊天；
- 切换组织前说明正在运行/未保存任务的影响；确认后重建可见任务与 Context 范围；
- 全局通知与 Agent Run 内等待教师动作分别建模，不能只靠同一个红点。

**验收**：1440×900 可识别当前组织、教师身份、AI Agent 一级位置和当前页面。

### WB-G-O01 全局侧栏收起态

- 入口：侧栏收起按钮或已定义快捷键；
- 保留：一级图标、AI Agent 当前态、Tooltip、未读/等待状态；
- 恢复：展开后恢复原内部滚动和历史选中；
- 禁止：收起导致任务历史成为第二根悬浮栏。

### WB-G-O02 账户与组织菜单

字段：头像、显示名、当前组织、组织成员身份、切换组织、账户设置、退出。

切换组织时列出：当前 Run 是否仍执行、未发送输入、未应用 Context 和未保存 Artifact。无法安全迁移的内容保存为原组织草稿，不带入新组织。

### WB-N-P01 Work Buddy 二级能力目录

**区域顺序**：技能市场 → 工具连接 → 我的文件 → 定时任务 → 设置。

旧“内容资源”实现按 D-051 保留为 Dormant Module，不进入默认导航。内容生产、作品管理和市场分发的可见目的地统一为 Space 下的 TeacherIn。

二级导航直接嵌入 ClassIn 左侧栏 Work Buddy 入口下方，只承载稳定能力目的地，不承载任务现场。其缩进、图标列、字号、行高、Hover、Focus 和选中态复用 ClassIn 原生可展开目录的子项规范，不增加 WorkBuddy 私有竖线或卡片层级。展开/收起不改变当前路由和 Run；普通任务体验不要求教师先进入技能或工具页面。

### WB-N-P02 并行任务 Tab 条

任务 Tab 条仅固定在新建任务和具体 Run 的 Work Surface 顶层，位于任务对话正文上方；二级能力页不显示任务 Tab：

- 栏体和未激活 Tab 使用白色 Surface，与下方内容区通过底部细分隔线建立层级；
- 当前 Tab 再次点击打开全部任务选择器；其他 Tab 点击后直接切换；
- 每个已创建 Run 的 Tab 在右侧保留等宽的编辑与关闭操作组，两者默认隐藏，仅在对应 Tab Hover 或 Focus Within 时同时显示；图标显隐不改变标题宽度或位置；
- 当前 Tab 的全部任务选择器向下箭头同样默认隐藏，仅在对应 Tab Hover 或 Focus Within 时显示；箭头保留固定占位，显隐不改变标题宽度或位置；
- 编辑图标点击后原位重命名；Enter 保存、Esc 取消、失焦提交，空标题不覆盖原名；新建任务 Tab 仅提供关闭；触摸环境下操作图标常驻，避免无 Hover 设备丢失入口；
- 未激活 Tab 在 Hover 时显示轻量预高亮；点击切换后，当前 Tab 以品牌柔和底色、强调线和加粗标题持续高亮，键盘 Focus 保留独立可见焦点环；
- 选择未打开的历史任务时先加入 Tab，再切换对应 Run；
- `+` 打开新任务草稿，并作为 Tab 序列末项紧跟最后一个已打开 Tab，而不是固定在导航条最右侧；加号在默认、Hover、键盘 Focus 和点击后均保持不变，Hover / Focus 仅提供背景和前景色反馈；
- 同一原型会话中的未发送目标与 Context 草稿应保留；
- Tab 横向滚动，不压缩到不可识别；关闭只关闭工作区，不删除 Run；
- 关闭当前 Tab 后选择相邻 Tab，若没有可用 Tab 则回到新任务；
- 路由是当前任务的稳定定位，Tab 集合是 WorkBuddy Feature 私有的会话 UI 状态；
- 新建任务 Tab 激活时，Tab 条最右侧显示 Core Context 辅助区图标开关；收起态为默认，展开态持续高亮并通过 `aria-expanded` 表达。

### WB-N-O01 全部任务选择器与操作菜单

选择器显示搜索、新建任务和可滚动的全部任务；每项显示标题、相对时间、状态/等待指示和是否已打开。切换任务前保护未发送输入与未保存编辑。

选择器默认从当前任务 Tab 的左边缘向下展开；接近工作区右侧时向左收敛以保持完整可见，并在窗口尺寸或 Tab 横向滚动位置变化时持续跟随当前 Tab。

动作：重命名、置顶/取消置顶、删除。

- 默认位置显示相对时间；Hover、Focus、选中时显示 `…`；
- 重命名就地完成并保留原焦点；
- 删除说明不会删除已写回 ClassIn 对象；可恢复时 Toast + Undo；
- 删除当前打开 Run 后返回新任务或下一可用历史，不出现空白死页。

## 3. 新建任务与输入 Overlay

### WB-T-P01 新建任务

**目的**：从一句目标、业务对象或模板创建标准 WorkBuddyRun。

**页面区域**：

1. WorkBuddy 动态头像、欢迎标题“老师好，有什么能帮您的？”与简短价值说明；
2. Goal Composer；
3. Core Context Chip 摘要；
4. 快捷 Task Type：生成单课件、生成课程方案包、创建 Skill 及后续配置类型；
5. 最近业务入口/建议，仅建议不自动确认；
6. 高级能力：Skill、Model；
7. 当前真值标签和必要隐私说明。

**字段**：目标文本、附件/资源、任务类型、目标输出、Core Context、Skill、Model。

**辅助区结构**：新任务首页默认只显示主任务输入，Core Context 通过 Composer 内入口或任务 Tab 条最右侧图标展开为 `360px` 右栏。展开时主区缩窄但保持输入器阅读宽度与中心对齐；收起时完整回收空间。面板隐藏不清空 Context 草稿、搜索、树展开和滚动现场，紧凑窗口使用右侧 Overlay。

**欢迎身份**：动态头像只作为新建任务首页输入区上方的紧凑 WorkBuddy 身份元素，不扩展为营销 Hero，也不替代一级导航。视频静音、自动循环、行内播放；加载失败或系统开启 Reduced Motion 时显示同构静态封面，标题和任务输入始终独立可读、可操作。欢迎标题在每次进入新建任务首页或整页刷新时播放一次逐字打字效果，同一次挂载中的 Context、输入与其他状态变化不得重复触发；动画期间预留完整标题宽度，不产生布局位移，Reduced Motion 下直接显示完整标题。

**提交规则**：

- 自然语言目标或可解释的业务入口至少一个有效；
- 创建前校验附件权限、模型可用性和组织范围；
- 业务入口预填 Context Proposal，但教师仍可检查；
- 提交固化用户消息与资源引用，创建历史条目并进入 WB-T-P02；
- 创建失败保留全部输入，不产生空 Run。

**状态**：首次空白、有最近任务、由 ClassIn 对象预填、资源解析中、缺必需 Context、提交中、创建失败。

### WB-T-O01 资源与位置选择器

Tabs/来源：最近、本地/上传、我的云盘、组织云盘、TeacherIn；目标保存位置在动作语义上与输入资料分开。TeacherIn 在 Core Context 内只提供任务所需的资源搜索与引用选择，不复制完整内容市场。

每项显示名称、类型、格式、大小、更新时间、来源、权限和解析状态。支持搜索、面包屑、多选、重新授权和清除。不可访问项可解释但不可选；选择后以引用而非内容副本加入 Context Proposal。

### WB-T-O02 Skill 选择器

显示搜索、最近/推荐、已启用 Skills、作用说明、官方/机构/个人来源、适用任务、权限摘要和“技能广场”。

- 选择只表示本 Run 偏好，不等于安装/启用；
- 与当前 Context 敏感度冲突的 Skill 显示原因并不可选；
- 自动模式为默认，教师可以明确指定或移除；
- 创建 Skill 由 Skill 广场的添加入口进入，不在选择器中伪装即时完成。

### WB-T-O03 模型选择器

字段：机构默认、可用模型、能力/数据边界摘要、当前状态和自定义模型设置入口。

模型选择不改变 Task Type 或 Context；模型不可用时保留目标并提供换模型/重试。学生敏感数据准入不因教师选择模型自动放宽。

## 4. Agent Run、Context 与补参

### WB-T-P02 Agent Run 工作区

**目的**：持续表达目标、Context、计划、执行、Artifact、教师决策和恢复。

**Run Header**：任务标题、Task Type、状态、来源入口、当前组织、Context/Artifact/执行详情入口、更多菜单。

**主时间线事件**：

- 教师目标与追加约束；
- Agent 任务理解；
- 结构化补参；
- 计划与步骤更新；
- Skill/Tool/文件/远端生成摘要；
- 阶段输入输出；
- Artifact 卡；
- 等待确认、错误恢复和完成总结。

**Composer**：文字、资源、Core Context 摘要、高级 Skill/Model、发送/停止。运行中可追加约束；停止与发送有明确文案和互斥状态。

**滚动**：执行中默认跟随；教师手动上滚后停止强制跟随并显示“回到最新”。恢复历史 Run 保留最后现场。

**关键状态**：draft、needs_context、planning、awaiting_plan_confirmation、executing、awaiting_input、awaiting_approval、recoverable_failed、stopped、partially_completed、completed_pending_review、completed、terminal_failed、superseded。

**验收**：教师无需展开技术日志即可理解正在做什么、已完成什么、在等什么和下一步。

### WB-T-O04 Core Context 面板

结构与字段继承 Core Context Feature Spec：Actor/组织、教学范围、学习者、时间、资源、教学证据、Domain Knowledge。

- 每项显示来源、版本/更新时间、权限、敏感度和纳入状态；
- 学生详情默认聚合；姓名/个体证据只在明确任务需要和权限通过时选择；
- 运行前“应用更改”创建 Snapshot；
- 运行中更改主班级/课程先展示影响，确认后 Replanning；
- 切到 Artifact/执行详情不丢 Context 编辑草稿。

### WB-T-O05 结构化补参卡

字段类型：单选、多选、短文本、长文本、数字/课时、日期时间、业务对象、文件/资源、确认。

卡片显示为什么需要、已知来源和是否必需。支持一次展示相关问题组、返回修改、其他、跳过可选项、提交。已由 ClassIn 事实确定的字段预填并标来源，不重复询问。

提交后在时间线显示答案摘要；修改答案触发影响分析。未完成必需项时按钮不可提交，并逐字段说明。

### WB-T-O06 Run 更多操作

动作：重命名、置顶、创建关联任务、导出任务记录、复制链接、删除；适用时有“从当前状态重新开始”。

- 创建关联任务先选择目标 Task Type，再进入 WB-T-P01 草稿；
- 导出默认脱敏技术参数和学生信息；
- 删除保护同 WB-N-O01；
- 不提供绕过审批的“标记完成”。

## 5. Artifact、编辑与业务写回

### WB-AR-P01 Artifact 活动面板

**Header**：类型、标题、版本、状态、来源步骤、关闭、Focus。

**单 Artifact**：预览正文/占位、版本摘要、引用/验证、编辑、AI 修改、保存/下载、保存到 ClassIn。

**多 Artifact**：方案包摘要、依赖/状态、可筛选列表、选中项预览；失败项保留重试和排除动作。

**格式策略**：

- HTML/互动内容使用隔离预览；
- 文档/课件/PDF 优先只读预览，能力不足时明确占位；
- 视频使用播放器，未实现时明确未来能力；
- 预览失败不改变文件生成成功状态。

### WB-AR-P02 Artifact Focus Surface

适用于复杂课件编辑、多 Artifact 审阅、宽表格、视频或版本比较。

Topbar：返回 Run、Artifact 名称/版本、状态、比较、AI 修改、保存、业务动作。

课程方案包可显示可收起 Artifact 导航；单课件不显示空导航。编辑器未保存时返回触发保存/放弃/取消保护。返回恢复原 Run 现场。

### WB-AR-O01 AI 修改与版本比较

输入：修改范围（选区/当前页/整份）、指令、基线版本、可选 Context 引用。

过程：生成中可取消；结果显示差异、来源影响、接受/拒绝/继续修改。若基线版本已变化，进入 conflict，禁止旧结果直接覆盖新编辑。

接受创建新 Artifact 版本；拒绝保留原版本和修改记录；AI 推断不自动改变 ClassIn 业务对象。

### WB-AR-O02 ProposedAction 审批与 Receipt

**审批前**：动作、目标对象、差异、影响范围、来源 Artifact、权限、风险、可逆性、过期时间。

**动作**：逐项批准/拒绝/修改；同一风险等级和目标范围可选择批量批准，但必须可展开单项。

**执行中**：防重复、显示真实业务校验，不允许关闭后假装完成。

**Receipt**：实际对象、状态、时间、版本、失败码、安全说明、Undo 能力和“打开 ClassIn 对象”。部分成功逐项展示并允许重试失败项。

## 6. Skills

### WB-S-P01 Skill 广场

区域：Tabs（推荐/广场/我的）、搜索、分类/来源筛选、Skill 列表、添加 Skill。

卡片显示名称、作用、来源、版本、适用 Task Type、权限摘要、安装状态。主动作随 available/installing/installed/failed 变化。列表空、筛选空、部分图标失败和服务失败有独立状态。

### WB-S-P02 我的 Skills

显示 installed、enabled、update、governance 和 usage 状态，支持启停、更新、删除、详情、去使用。

- 启停不改变历史 Run；
- 删除前列出受影响定时任务与未来可用性；
- “去使用”进入 WB-T-P01 并预选 Skill，不立即执行；
- 机构强制 Skill 不允许个人删除，显示管理来源。

### WB-S-O01 Skill 详情

字段：名称、作者/来源、版本、说明、适用场景、核心功能、示例、输入/输出、所需 Context、敏感级别、Tool/网络/文件权限、变更记录、安装状态。

动作：安装、更新、去使用、启停、删除、关闭。安装前展示权限；安装失败可重试并保留原因。

### WB-S-O02 添加/上传/创建 Skill

方式：文件夹、ZIP、Markdown、GitHub URL（若机构允许）、创建 Skill。

上传路径校验结构、版本、签名/来源、同名冲突和权限；创建路径进入 Skill Creator Run。安装完成后进入 WB-S-P02 并显示真实状态。

## 7. Tools / MCP

### WB-M-P01 Tool/MCP 广场

区域：广场/我的、搜索、类别/来源筛选、Tool 卡、添加自定义。

卡片显示 Tool 作用、来源、连接类型、权限范围和安装状态。Tool 页面没有“立即运行”；详情只能安装/管理。

### WB-M-P02 我的 Tools

状态：installed disabled/enabled、connecting、connected、auth_failed、endpoint_failed、policy_blocked、update_available。

动作：启停、测试连接、编辑、删除、查看调用范围。删除/禁用前列出依赖的定时任务和 Task Type，不破坏历史事件证据。

### WB-M-O01 Tool 详情/管理

字段：名称、说明、来源、版本、接入类型、可用能力、可访问 Context 类别、可执行动作、网络/文件范围、连接状态、最近校验。

动作：安装、编辑、启停、删除、关闭。明确禁止从详情直接创建任务；“在任务中使用”仅解释使用方式或返回已有 Run。

### WB-M-O02 自定义 MCP

模式：表单/JSON。字段：名称、说明、传输/接入类型、命令或 URL、参数、环境变量、超时、权限范围。

保存前进行语法、必填、重复名、连接和策略校验。Secret 掩码且不进入日志；测试连接结果不等于保存成功。编辑时支持查看差异、取消和回滚到已保存配置。

## 8. TeacherIn 内容连接

### WB-C-P01 TeacherIn Space Surface

TeacherIn 是 Space 下唯一可见的内容市场、作品管理、授权和发布入口。`/teacher/space/teacherin` 是正式路径；历史 `/teacher/space/resource-center` 映射到同一 Surface。

### WB-C-P02 TeacherIn 资源选择

入口位于新任务 Core Context 的“资源与教师输入”。列表只显示完成当前任务所需的搜索结果、标题、学段、学科、作者、授权、权限和版本；选择后保存对象 ID 与版本引用，教师确认 ContextSnapshot 后才进入 Run。

### WB-C-O01 创建 TeacherIn 草稿

入口位于当前 Run Artifact 和“我的文件”。动作统一命名为“创建草稿到 TeacherIn”；明确点击形成 ProposedAction 和教师 Approval，Adapter 以 Artifact 版本、SpaceFileRef 与幂等键创建草稿并返回 ExecutionReceipt。

成功文案固定为“已在 TeacherIn 创建草稿。你可以前往 TeacherIn 继续编辑作品信息、设置授权并发布。”WorkBuddy 不表达提交审核、审核中、通过或驳回。

### WB-C-O02 TeacherIn 草稿定位与继续编辑

“前往 TeacherIn”深链定位到对应作品草稿，展示草稿身份、作品名称、授权方式、来源 Artifact 与发布动作。当前体验环境只能模拟保存和发布，并显示 `[模拟]` 真值；不得暗示已写入真实 TeacherIn。

### Dormant Module

旧内容广场、内容详情、我的作品和发布向导的 Surface、数据、样式和回归资产继续保留，但不进入默认导航、公开业务路径或当前发布验收。恢复必须先修订 D-051，再通过显式可见性配置启用；旧向导中的审核文案不代表当前 TeacherIn 流程。

## 9. 定时任务

### WB-AU-P01 定时任务列表

字段：名称、Task Type、状态、周期/下次运行、目标范围、最近结果、通知。动作：新建、立即运行、编辑、启停、删除、查看历史。

blocked 状态必须指出缺模型、资源、权限还是通知配置。立即运行创建标准 Run，不在列表中执行隐藏逻辑。

### WB-AU-O01 创建/编辑定时任务

字段：名称、目标模板、Task Type、触发规则、时区、生效/结束、Context 选择规则、资源位置、能力策略、通知、重叠策略、高影响动作审批策略。

保存前显示下次三次触发预览。保存 Context 规则而非未来学生数据 Snapshot。编辑已有任务展示对下一次和当前运行实例的影响。

### WB-AU-P02 定时任务历史

每次实例显示计划时间、实际触发、Run 状态、Artifact、Receipt、通知结果和耗时。支持打开关联 Run、重跑失败实例和查看错过/重叠原因。

## 10. 文件

### WB-F-P01 WorkBuddy 文件视图

复用 ClassIn Space 的存储引用和权限模型，但以“AI 协作产物回溯”组织入口，不复制传统云盘目录。该视图只收录教师与 AI 协作生成的 Artifact 及文件结果，不提供上传入口，不收录教师上传、组织共享或仅作为 Session 输入的资料。默认按最近生成时间排序，并以关联任务或教学项目分组；文件类型和收藏作为筛选条件。教师进入页面后应能在同一视野内回答：什么时间、在哪个任务/项目、生成了什么类型的文件。

字段：名称、格式、类型、所属 Run、教学项目/业务归属、生成时间、版本、大小、权限、解析/同步状态、收藏状态、引用次数和分享去向。搜索覆盖文件名、任务名、课程和项目；筛选至少覆盖类型与收藏。

每个任务/项目分组显示标题、课程/班级上下文、最近生成时间和文件数，并提供“回到任务”。文件行在 Hover 或键盘聚焦时显示低噪快捷动作，但同样动作必须在详情层常驻可达。动作：预览、下载、收藏、作为新任务 Context、创建草稿到 TeacherIn、回到来源 Run、在来源目录定位、发送到一对一聊天或班级群、复制分享链接。Work Buddy 二级目录是快捷入口，不创建第二套文件所有权。

当前体验环境使用固定、脱敏、可重置的模拟文件资产；分享、下载和引用结果必须显示 `[模拟]` 真值，不得暗示已完成真实文件传输或消息发送。

### WB-F-O01 文件预览与引用

右侧详情层显示预览/占位、元数据、来源、版本、权限、关联 Run/Artifact、生成时间、引用次数和最近分享去向。主动作是“作为上下文”，次动作是分享、下载、回到任务和定位来源。

“作为上下文”创建或补充新任务草稿并携带稳定文件引用，不复制文件正文，也不把引用转写成自然语言目标；若草稿中已有目标，必须原样保留。发送到聊天时必须选择一对一会话或班级群，并在发送前显示目标和权限范围。无权访问时不显示敏感缩略图或内容摘要，也不允许引用、分享或创建 TeacherIn 草稿。

## 11. 设置

### WB-SET-P01 Work Buddy 设置壳/通用

设置导航：通用、模型、数据与备份、消息与通知、沙箱、关于、反馈、授权与用量。

通用字段：默认 Task Type/输出偏好、语言、通知、历史保留说明、技术详情默认层级。机构锁定项显示来源且个人不可修改。

### WB-SET-P02 模型设置

Provider/Model 列表、启用、配置、测试连接、默认模型、适用 Task Type、数据边界。Key 不回显；连接测试、模型可用、敏感数据准入是三个不同状态。

### WB-SET-P03 WorkBuddy 数据与备份

说明 WorkBuddy 拥有与不拥有的数据；备份/恢复仅作用于 Run、Artifact 草稿、个人 Skill 和偏好等允许范围，不备份 ClassIn 正式业务对象。显示上次备份、范围、状态和冲突处理。

### WB-SET-P04 外部消息与通知

显示渠道、绑定身份、组织范围、触发/通知权限、状态和最近验证。外部消息创建 Run 时仍需 Actor/Tenant 校验；外部入口不能绕过审批。

### WB-SET-P05 沙箱与执行环境

显示可用性、安装进度、当前模式、文件/网络边界、危险动作策略、最近健康检查。切换模式说明对运行中任务的影响；危险命令始终经过策略和审批。

### WB-SET-P06 关于与能力真值

显示版本、更新、协议、隐私、第三方组件、Mock/Beta/未来/生产能力说明。不能用“支持”笼统暗示真实 ClassIn 集成或媒体生产已完成。

### WB-SET-P07 反馈

字段：问题类型、标题、描述、复现步骤、附件、是否同意上传脱敏诊断、联系方式。默认不上传学生 Context、Secret、私有路径或完整 Artifact；提交失败保留草稿。

## 12. 授权与用量

### WB-E-P01 授权/套餐位置

目标语义为“当前教师/机构拥有哪些 WorkBuddy 能力”，而非预设个人会员购买。显示授权主体、能力范围、有效期、管理来源和支持入口。交易闭环保持 `OPEN`。

### WB-E-P02 用量/额度与记录

显示当前周期、机构/个人归属、模型/媒体/存储等可解释用量、记录与异常。`积分` 仅作为 NineClaw 来源概念；最终 ClassIn 名称和计费规则保持 `OPEN`。用量不足不能让已生成 Artifact 消失。

## 13. 页面级验收清单

1. 当前 Active 页面 ID 均能从已定义入口到达并有明确退出路径；Dormant Module 只通过独立回归资产验证；
2. 38 个 NineClaw 来源能力无隐性删除；
3. 新增 Context、Focus、审批和 Receipt 不建立第二套 Run；
4. 所有业务写回均经过 ProposedAction；
5. 所有页面都有权限、失败、恢复和返回现场；
6. 普通教师默认不需要理解 MCP、模型或命令；
7. 高级技术证据可追溯但默认折叠、脱敏；
8. 未知商业、API 和媒体能力清楚标记，不伪装生产就绪。
