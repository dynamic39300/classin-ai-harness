# 课程目标到课程对象纵向切片

## 用户目标

林老师输入八年级英语四周叙事写作单元目标，WorkBuddy 帮她澄清范围、形成计划、生成可审教课程方案包、完成多轮审教与修订、确认最终版本、执行模拟保存并查看回执。

## 范围

包含：目标输入、范围与成功标准、上下文授权、计划、可审教课程方案包、课程/单元/活动结构草稿、来源、审教意见、版本差异、规则校验、最终确认、审批、模拟写回、冲突、部分成功、恢复和评价事件。

第一版不包含：具体 PPT 文件生产、页面级视觉排版、多媒体素材制作、真实 ClassIn API、正式发布、真实学生判断、消息外发、A2A 网络、第三方插件市场和跨天生产调度。

第二版扩展：从最终确认的课程方案包派生具体 PPT 课件 Artifact，增加页面/章节/活动级课件审教与版本迭代；第二版不改变第一版的目标、上下文、事实所有权、教师确认和写回边界。

## 一等对象

`WorkBuddyRun`、`ContextSnapshot`、`ArtifactDraft`、`CapabilityManifest`、`ProposedAction`、`Approval`、`ExecutionReceipt`、`EvaluationEvent`。

## Interface 与 Adapter

模拟 ClassIn Adapter 和未来真实 ClassIn Adapter 共享领域 Interface。Interface 至少支持读取范围、读取已有课程结构、保存草稿、报告版本冲突、部分失败和返回稳定回执。Adapter 不拥有 WorkBuddy 计划或 ArtifactDraft。

## 第一版产品交付物

第一版交付物是 `可审教课程方案包`，由以下内容组成：

- 教学目标与成功标准；
- 课程范围、年级、班级和课时；
- 单元结构；
- 课时与活动结构；
- 评价安排；
- 资源建议；
- 来源与依据；
- 审教意见及处理状态；
- 版本差异和最终确认状态。

它是 WorkBuddy 的组合 `ArtifactDraft`，不是 ClassIn 的新正式对象。最终确认后，可以通过 Adapter 保存为课程、单元和活动草稿。

## 第一版审教规则

- 范围限定为单教师、单机构、单班级课程、单次 WorkBuddy Run；
- 审教颗粒度采用整体方案、单元、活动三级；第一版不进入 PPT 单页审教；
- 每条审教意见独立记录，可人工修改、要求 AI 定向修改、接受当前内容或拒绝意见；
- AI 不自动宣告意见已解决；意见必须关联到后续版本和处理结果；
- 结束条件为教师明确最终确认、所有阻断性意见已解决且规则校验通过；
- 非阻断性意见可以保留，但必须在最终确认前显式展示。

## 验收

- 教师能从目标输入走到可审教课程方案包；
- 方案包包含目标、成功标准、课程/单元/活动结构、评价和资源建议；
- 教师能按整体方案、单元和活动进行审教，逐条处理意见并生成修订版本；
- 第一版不生成具体 PPT 文件，不能把课程方案包标记为 PPT 课件；
- 每个产物显示来源、版本和 `[模拟]` 标签；
- 教师能修改、比较差异、确认最终版本或拒绝当前版本；
- 保存动作先显示对象范围、风险和版本；
- 冲突和部分成功不会被汇报为整体成功；
- 页面关闭后可恢复 Run；
- 评价事件能关联教师修改、审教轮次、意见处理、审批和模拟回执。
