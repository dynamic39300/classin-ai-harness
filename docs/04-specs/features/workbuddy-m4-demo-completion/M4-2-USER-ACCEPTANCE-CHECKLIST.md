# M4.2 用户验收清单

## A. WB-06 群内讲题闭环

1. 老师视角进入“消息”与“高二物理 3 班”；
2. WorkBuddy 选择“单题讲解”，生成消息草稿；
3. 确认群内学生只说“今天动量守恒练习单第 5 题”和正负号卡点，没有完整抄写题干；Run 能从课程与作业上下文定位完整题目；
4. 确认审核面首先展示可编辑的最终发送话术，话术内含“查看分步讲解”文字链接；发送前点击链接可预览；
5. 确认链接内容包含 `0.20 kg / 5.0 m/s / 0.30 kg / 1.0 m/s` 的完整碰撞条件、带符号变量、动量守恒公式、代入计算和 `4.0 m/s，向右` 的答案；
6. 修改最终发送话术、题目、任一步骤标题/正文/检查点和教师版完整答案，点击“应用修改”，确认 Artifact 只增加一个版本且接收端展示修改后的内容；存在未应用修改时不得直接发送旧版本；
7. 点击“确认保存并发送”，查看成功 Receipt；
8. 定位群消息，确认显示老师审核后的最终话术及文字链接；打开链接后 Viewer 可滚动、Escape 可关闭且焦点回到链接；
9. 进入 WorkBuddy → 我的文件，确认同版本“交互讲解”可定位，界面不显示文件扩展名或 `H5`，且不能从文件库任意转发到其他对象；
10. 切换到学生视角，进入同一班级群，确认可打开同一批准版本的四步讲解与完整答案。

## B. 当前学生私聊

1. 老师视角进入与李明的私聊；
2. WorkBuddy 选择“单题讲解”；
3. 确认审核面明确显示目标为当前学生私聊（李明），并首先展示可编辑最终话术与“查看分步讲解”链接；
4. 重复 A-3～A-6 的题号定位、具体题目、公式、答案、话术与编辑验收；群聊和 1v1 的能力与审核 Surface 应完全一致；
5. 确认成功后消息只进入当前线程。

## C. PA-01 / DA-01

1. 教师或学生在班级群显式 `@物理学习助手`：应得到简短起步提示和自检问题，群成员可见；
2. 学生进入同一 Agent 私聊：无需 `@`，应得到三个连续步骤和自检追问；
3. 两条回答均不直接出现最终答案，教师看不到学生的 Agent 私聊线程。

## D. Agent 私聊目录、历史与响应

1. 分别用教师和学生视角进入“私聊”，确认默认“全部”，并可切换“班级 Agent 4”和“联系人”；
2. 在“班级 Agent”范围搜索“变量”，只出现“实验探究助手”；清空后恢复 4 个当前班级已授权 Agent，联系人不混入 Agent 范围；
3. 确认 Agent 在列表、会话 Header、每条 Agent 消息和等待占位中均显示一致名称与专属图标语义，无重复 `[模拟] AI Agent`、`[模拟] Agent` 标签，也无需依赖颜色即可与人类区分；
4. 打开任一 Agent，点击“加载更早消息”或向上滚到顶部，确认历史同时包含人类和 Agent 消息；切换其他私聊后再返回，消息和线程滚动位置保持；
5. 阅读较早历史时等待新消息到达，时间线不强制跳到底部；点击“1 条新消息”可回到最新位置；
6. 发送问题后先看到“正在理解你的问题”，随后看到“正在整理可检查的回复步骤”，最后得到回复；失败保留用户消息并可重试；
7. 教师和学生引用同一 Agent 但历史彼此隔离，任一角色都不能发现另一角色的 Thread；WorkBuddy 场景级 `[模拟] 数据` 边界仍清晰，模拟真值保留在证据与审计状态中。

## E. 异常与边界

- 没有可识别学生题目时要求补充，不生成虚构题目；
- 生成失败显示“重新生成”，执行后建立新的逻辑 Run；
- 权限拒绝不保存、不发送、无盲重试按钮；可关闭并联系管理员申请权限；
- 可恢复失败保留已批准 Artifact，可用同一幂等动作重试且只产生一次消息；
- 证据不匹配保留 Receipt，只允许关闭并人工复查；
- 同一线程连续生成两道讲题内容，必须分别产生独立 Run、Artifact、消息和回执；
- WorkBuddy Surface 保留一次清晰的 `[模拟] 数据` 边界；IM 条目不重复堆叠模拟或格式标签，Domain、Receipt、Evaluation 与审计证据中的真值不得丢失。

## F. M4.2 扩展交付

1. 最终消息按自然段、链接和纯文本语义稳定呈现；共享编辑器支持长内容编辑、焦点与 Sidecar 独立滚动；
2. WorkBuddy 入口头像、问候、动态输出、完成态 Composer、产出入口和沉浸退出引导与既有任务保持统一；
3. “生成测验并创建教学活动草稿”先以连续 Run 生成试卷，生成前不显示伪预览；老师必须打开并确认当前试卷后，才进入活动参数交互；
4. 测验 Approval 只创建教师可见草稿；老师可在班级课程详情逐题和按参数二次编辑，再通过独立命令发布；发布前学生不可见，发布后可见；
5. 试卷、Review、Action、Approval、Receipt、Evaluation、Class 草稿和发布证据在刷新恢复、幂等回放及版本冲突路径中保持关联。
