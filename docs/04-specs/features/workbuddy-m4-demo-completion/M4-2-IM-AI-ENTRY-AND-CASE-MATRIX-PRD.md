# M4.2 IM AI 入口地图与业务 Case 矩阵 PRD

## 1. 背景与目标

IM v0.19 已验证教师私密 WorkBuddy、群内公开班级 Agent、教师/学生隔离 Agent 私聊三种渠道骨架，并完成作业催交与本周课前准备通知。M4.2 要把这些入口从“渠道存在”推进到“代表性业务能力覆盖完整”，证明教师和学生能在正确的空间调用正确的 AI，并看懂可见范围、审批责任和结果去向。

本期目标是：用五个 P0 Case 覆盖 IM 中的 Insight、Creation 与有限模拟 Action；新增教师 WorkBuddy 单题讲解内容生成—审核—入库—分发闭环；让 PA-01 与 DA-01 复用同一辅导能力而保留不同渠道政策；让所有生成、发送、回执与评价保持显式状态和 `[模拟]` 真值标签。

## 2. 用户 Jobs

- 教师：学生说明作业题号与卡点后，快速生成一条可直接发送的话术，并在话术中附上可打开、按步骤学习的讲解链接；发送前既可修改最终话术，也可逐项修改题目、步骤标题、公式与推导、检查点和最终答案；批准后自动沉淀到“我的文件”，并发到当前班级群或当前学生私聊。
- 学生：群内 `@班级 Agent` 获得适合公开讨论的起步提示；私聊同一 Agent 获得更连续的分步提示和自检点；收到老师发布的讲题内容后可打开完整讲解。

## 3. P0 Case 与能力矩阵

| Case | 角色/渠道 | AI 身份 | L1 Insight | L2 Creation | L3 Action | 审批与可见性 |
| --- | --- | --- | --- | --- | --- | --- |
| WB-01 作业催交 | 教师/群侧私密 WorkBuddy | WorkBuddy | 提取未提交事实 | 生成分组提醒 | 模拟发送群消息 | 教师审批；群内只见教师消息 |
| WB-02 周课前准备 | 教师/群侧私密 WorkBuddy | WorkBuddy | 归纳周计划 | 生成准备通知 | 模拟发送群消息 | 教师审批；群内只见教师消息 |
| WB-06 单题讲解 | 教师/群或私聊侧 WorkBuddy | WorkBuddy | 理解题目与学习卡点 | 生成格式中立讲题 Artifact | 模拟入库并分发引用 | 教师审批；仅当前群或当前学生 |
| PA-01 群内答疑 | 教师/学生班级群 | 班级 Agent | 理解公开问题 | 生成简洁提示 | 回复当前群 | 显式 `@`；群成员可见；无最终答案 |
| DA-01 隔离辅导 | 教师/学生 Agent 私聊 | 同一班级 Agent | 理解个人问题与当前线程 | 生成分步辅导 | 回复当前私聊 | 无需 `@`；线程隔离；无最终答案 |

生产级业务执行不在本期。表中的 L3 是固定、可重置 Mock Adapter 返回 Receipt 的体验验证，不宣称已接真实 ClassIn API。

## 4. WB-06 核心旅程

```text
学生在群/私聊说明今天的课程/作业、题号与卡点
  → 教师打开当前会话 WorkBuddy
  → 选择“生成单题讲解”并生成
  → WorkBuddy 从课程和作业上下文定位完整题目
  → 展示可编辑的最终发送话术及其中的“查看分步讲解”链接
  → 教师点击链接预览、按需编辑话术和链接内容
  → 教师确认发送到当前班级群或当前学生
  → ProposedAction + Approval
  → Artifact 进入“我的文件”
  → MessageContentReference 写入目标线程
  → ExecutionReceipt + EvaluationEvent
  → 学生打开交互讲解并查看步骤与最终答案
```

首个 Demo 的 Presentation Adapter 为应用内交互 HTML/H5 卡片。领域对象不保存 `.mp4/.png/.html` 等格式约束；未来可投影为视频、图片、网页或其他可打开载体。“解题过程”是经过教学组织、可提供给学生的步骤说明，不记录或暴露模型隐藏推理链。

首个固定 Demo 使用一条完整、可计算、可核验的动量守恒应用题：质量 `0.20 kg` 的小球 A 以 `5.0 m/s` 向右运动，与静止的质量 `0.30 kg` 小球 B 正碰；碰后 A 以 `1.0 m/s` 向左反弹，求 B 的速度大小和方向。讲解必须明确正方向、带符号已知量、守恒公式、代入计算和 `4.0 m/s，向右` 的最终答案，不能退化为只有概念提示的泛化说明。

## 5. 产品规则

- WorkBuddy 草稿和 Run 只对教师可见；学生只看到教师批准后的消息和 Artifact 投影。
- WB-06 从当前线程最近一条学生消息提取课程/作业/题号与卡点，再通过受治理的课程和作业 Context 定位完整题目；不能唯一定位时进入“需要补充”，不猜测题干。
- 教师批准的 WB-06 可以包含完整答案；PA-01/DA-01 只给提示、过程、检查点与下一步问题。
- WB-06 审核面中的题目、每一步标题/正文/检查点和完整答案均可编辑；教师应用修改后生成新 Artifact 版本并使旧审批失效。存在未应用修改时不得批准旧版本。
- 群发目标只允许当前班级群；私聊目标只允许当前会话学生，不展示任意联系人/群选择器。
- Artifact 入库与消息分发引用同一个稳定 `artifactId + version`。
- 最终发送话术是审核主交付物，默认包含教师可直接发送的自然语言和“查看分步讲解”文字链接；话术与链接内容都可在批准前预览和修改。
- 接收端消息按普通教师消息展示最终话术及文字链接，不重复显示 `[模拟] AI Agent`、`[模拟] Agent` 或 `H5`；打开内容必须与批准版本一致。场景级 `[模拟] 数据` 边界及 Domain/Receipt/Evaluation 真值仍保留。
- PA-01 使用公开渠道策略：短答、点名回应、避免个人画像；DA-01 使用私密渠道策略：分步、可追问、只读取当前用户线程。

## 6. 状态与异常

WB-06 表达 Ready、Generating、NeedsInput、DraftReady、Saving、Saved、Sending、Sent、RecoverableFailure、PermissionDenied、EvidenceMismatch。UI 可合并相邻瞬时状态，但证据不得丢失。

- 无题目：要求补充题干或选取最近学生消息；
- 生成/入库失败：保留目标、Prompt 与草稿，不伪造成功；
- 权限拒绝：禁止分发并解释目标限制；
- 证据不匹配：保留 Receipt、进入人工复查，不盲重试；
- 重复确认：同幂等键只产生一次消息副作用。

## 7. 范围

In Scope：五 Case 地图一致；格式中立 GuidedExplanation domain、确定性模拟生成与审核；动态“我的文件”；当前群/当前学生分发；接收端交互讲解；PA/DA 渠道化回复；集成、E2E、视觉与真值标签验收。

Out of Scope：真实模型和媒体生成、生产 H5 托管、真实 ClassIn 写回、任意联系人或跨班分发、自动发送、教师读取学生 Agent 私聊、PA/DA 最终答案、M4.3–M10。

## 8. 成功与验收

- 教师可在群和学生私聊上下文分别生成、审核并分发讲题内容；
- 同版本 Artifact 可在“我的文件”定位；接收方能打开不少于 3 步的讲解；
- PA-01 与 DA-01 的表达和可见范围明显不同，但 Agent 身份与能力定义一致；
- 失败与权限路径不伪造成功，Receipt/Evaluation 与 Run、Artifact、Action、Approval 引用一致；
- 自动化、Standards Review 与 Spec Review 全部通过后交由用户验收。

## 9. 用户验收修订：Agent 私聊体验

M4.2-11 不增加新的业务 Case，而是补齐 DA-01 在教师/学生私聊中的可发现性、连续性和响应可信度：

- 当前班级授权过滤先于搜索；默认“全部”，可快速切到“班级 Agent”或“联系人”；
- 搜索覆盖 Agent 名称、课程和公开能力关键词，Agent 独立分组并显示准确数量；
- 列表、Header、Agent 消息和处理中占位均使用同一稳定名称和专属图标语义，不只依赖颜色；模拟属性由场景级边界统一说明，不逐项重复；
- 点击恢复当前 Actor 的同一隔离 Thread，支持向上加载人类与 Agent 的历史并保持滚动锚点；
- 响应经历“理解问题 → 整理回复 → 完成/可恢复失败”，不展示隐藏思维链；约 1.8 秒等待仅用于 Mock Demo，真实 Runtime 不加人工延时。

详细状态、Interface、师生矩阵与生产 Gate 见 `../workbuddy-im-collaboration/AGENT-DIRECT-CONVERSATION-EXPERIENCE-DESIGN.md`。

## 10. 用户验收修订：最终发送话术与题目定位

M4.2-12 不增加新 Case，统一 WB-06 与既有 WorkBuddy 消息草稿的教师审核心智：

- 审核区首先展示并允许编辑最终发送话术，发送结果与该话术一致；
- 话术内嵌“查看分步讲解”文字链接，教师在发送前和收件人在发送后使用同一 Viewer 预览同一批准版本；
- 题目内容来自受治理的课程/作业 Context，学生示例只描述“今天的动量守恒练习单第 5 题”及正负号卡点，不要求完整抄写题干；
- 详细讲解字段继续放在同一审核面内按需展开编辑，任意修改必须应用为新 Artifact 版本后才能批准；
- `H5` 和模拟类型仍作为 Adapter/Domain 事实保留，但不作为消息、文件或 Agent 身份旁的重复展示标签。
