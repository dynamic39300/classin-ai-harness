# Gate

消息正文仅保存在被忽略的授权私有运行目录；仓库不提交原始学生消息。实际取得多少处理多少，不制造完整分页或时间窗口。独立实时 WebSocket 会话未建立前，稳定 Reader 必须保持 `BLOCKED_EXTERNAL`。
