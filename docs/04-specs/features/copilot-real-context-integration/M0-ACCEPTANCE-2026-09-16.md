# 回退与恢复

- 配置关闭或Scene首次读取失败：不创建真实 Thread，原模拟消息工作区仍可使用；重新启用后刷新页面恢复。
- Context读取中途失败：保留老师输入，显示真实错误并允许重试，不调用Mock业务数据兜底。
- 角色切到学生：真实测试 Thread及老师端本机消息不可见。
- 本机消息存储失败：不确认发送、不推进会话版本，释放存储后可用同一请求重试。
