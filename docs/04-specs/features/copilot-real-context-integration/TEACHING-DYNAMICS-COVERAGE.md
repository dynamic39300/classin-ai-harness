# 1. 两套需求清单必须分开验收

- **21类通用问题**：老师主动发问，入口在通用提问与自由输入；验收见[21题矩阵](./ACCEPTANCE-MATRIX.md)。
- **10条阶段推荐 Prompt**：系统根据真实教学动态主动给出可点击建议，入口在`课前 / 课中 / 课后 / 总结`四阶段。

二者可以复用同一个业务工具和回答能力，但不是同一份清单。最终覆盖标准是 `21/21问题有状态 + 10/10推荐有映射`，不能用21题覆盖率替代10条推荐覆盖率。

# 2. 无任务时的空态合同

2026-09-17 用户修订：课中真空态 Tab 显示“暂无”，内容只显示下方指定提示；满勤/未知的课中事项也仅为说明，无操作徽标。只有已有成员级实时证据的未进入提醒可提供 P03 动作。没有课堂不再显示“实时出勤尚未接入”；当前课程有候选课堂但时间/考勤不足仍为未知。总结移除 `course-inventory` 数量/完整性行，保留 P08/P09/P10。

每个阶段使用三种互斥状态：

| 状态 | 数据条件 | Tab状态 | 内容区 | 是否产生Prompt |
| --- | --- | --- | --- | --- |
| 真空态 `empty` | 读取成功，当前阶段没有事项 | `已核` | 阶段专属空提示 | 否 |
| 已核对无动作 `confirmed` | 有值得呈现的业务事实，但无需老师操作 | `已核` | 一条事实卡，尾部`无需处理` | 否 |
| 数据未知 `unknown` | 相关能力未接入、读取失败或证据不足 | `待核` | 说明未知内容和恢复方式 | 否；不得用通用Prompt填满 |

四个真空态文案固定为：

| 阶段 | 空提示 |
| --- | --- |
| 课前 | `当前没有需要处理的课前事项` |
| 课中 | `当前没有正在上课的课堂` |
| 课后 | `当前没有待提醒或待处理的课后任务` |
| 总结 | `当前没有可生成的课堂或阶段总结` |

规则：

1. 空态不创建假的 `TeachingDynamicItem`，不计入顶部`N项建议`；
2. “24小时内暂无课堂”“全员到齐”“任务均已提交”等真实事实可以用 `confirmed` 卡表达，但没有按钮；
3. “实时出勤尚未接入”“学情报告读取失败”属于 `unknown`，不能显示绿色完成语义；
4. 某阶段为空不影响其他阶段；Tab始终保留，老师可以看到四阶段完整框架；
5. 顶部 `N项建议` 只统计有 `action` 的项目，不统计空态、确认卡和未知卡；
6. 空态文案是稳定产品文案，业务名称、人数和时间只出现在事实卡中。

# 4. 不重不漏规则

1. 每条动态有稳定 `recommendationKey=P01…P10`，不能用标题文字作为身份；
2. 一个业务对象可以生成多条事实卡，但同一个 `recommendationKey + objectRef + contextVersion` 最多产生一个动作；
3. P02只负责下一课提醒，P04负责课后任务，避免同一活动同时以“课前安排”和“课后任务”重复；
4. P05与P06按活动类型互斥，不能把测验作为作业重复提醒；
5. P08是单课内容回顾，P09是班级周期总结，P10是单生周期总结，范围必须不同；
6. P07只整理高频错题事实和可核验解析，不恢复已退出范围的个体错因诊断；
7. 当触发事实为0或空时，先判断它是有效的“无人未交/无人迟到”还是未知字段；有效0转为确认卡，未知转为 `unknown`；
8. 顶部计数等于10条清单中本次实际触发且可执行的数量，不固定显示10；
9. 排序固定为阶段顺序，再按业务紧急度和时间；相同优先级按稳定Key排序；
10. Context刷新后用 `contextVersion` 去重；业务状态变化可以删除旧建议或新增建议，但不能保留过期人数和截止时间。

# 5. 100%覆盖的定义

“10条推荐100%覆盖”不是指任何时刻都显示10条，而是：

- P01–P10每条都有明确触发事实、工具/API、对象、Prompt模板、空/0/未知处理、里程碑和验收用例；
- 满足触发条件时能生成唯一建议；不满足时正确隐藏或显示无动作事实；
- 10条均完成正例、空态、0值、未知、失败、状态变化和重复抑制测试；
- 本文最终状态表示内部严格工程 Gate；整体用户验收完成后，计划状态再升级为 `COMPLETE_USER_ACCEPTED`。

最终状态为 `7 PASS + 2 CONDITIONAL_PASS + 1 BLOCKED_EXTERNAL`，10/10 均有明确状态。P01、P04、P08 在 M6 补齐真实动态投影并通过真实 Context 路由核验；P03 因测试环境缺少成员级实时样本保持安全阻塞；P09/P10 使用受限活动聚合，页面明确不是正式学情报告。当前真实时钟实际触发 P01、P04、P05、P07、P08、P09、P10；P02/P06 因触发条件不满足正确隐藏。
