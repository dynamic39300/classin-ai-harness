# 范围与实现口径

实施 D1、D2、D5、E4 和 P09/P10。当前没有已验证的正式学情报告接口，M4 使用教师授权班级中真实课堂出勤、作业、测验、录播和未来排课做受限聚合，并明确活动覆盖和缺口。

| Ticket | 交付 | 完成条件 |
| --- | --- | --- |
| RC-400 | 周期与学生对象合同 | Asia/Shanghai 自然周；学生必须由当前班级 identity=1 唯一解析，每次重核 |
| RC-401 | 跨活动学习聚合 | 五类活动分别定义状态；已完成、当前未完成、已逾期、未来安排不混淆 |
| RC-402 | D1/D2 | 指定学生、课程、周期、覆盖活动和缺口可见；不评价成长或推断错因 |
| RC-403 | D5 | 只改写 D1 已确认事实为家长草稿；不增加建议、承诺或送达状态 |
| RC-404 | E4 | 班级周报给出学生覆盖率和活动覆盖；未来排课单列，不写成已完成 |
| RC-405 | P09/P10 | 仅在周报/学情聚合可核验时显示；无正式报告时明确“受限活动聚合” |
| RC-406 | 严格验证 | 真实 API、DeepSeek、浏览器、负例、全量回归和验收记录通过 |

# Gate

姓名不能从群聊代词猜测；个人事实不进入班级消息草稿；不同活动完成规则可解释；D5 不增加进步、错因、改进建议；E4 不以部分学生外推全班。
