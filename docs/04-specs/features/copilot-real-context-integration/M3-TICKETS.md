# M3 范围

实施 C5“最近作业测验哪些题错得多”、E3“把学习资料里的方法整理成三点”和 E5“把刚才内容整理成消息”，并补齐 P06 测验提醒与 P07 高频错题推荐。真实测试 Thread 仍只使用真实 API 和当前 Session 已确认内容。

# 已冻结口径

- C5 只聚合已经结束、已发布且逐题判定可完整核验的测验；未参与、未作答、待批阅均不进入有效分母。
- “未完全正确”由`错误 + 部分正确`构成，必须同时给出有效分母、正确/错误/部分正确人数；不得推断错因。
- 没有结构化逐题判定的作业只记录为排除项，不能从总分、图片或自由文本反推逐题正确率。
- E3 只基于真实资料正文；文本 PDF 可提炼，扫描件、图片和不支持格式明确说明正文不足。
- E5 只复用当前对话中已经确认的事实与产物，不调用新的业务接口，不添加新的日期、对象、成绩或承诺。
