# WorkBuddy 能力与资源页面高保真规格

## 共通页面

- 页面标题、短说明、搜索/筛选区、主列表或网格、详情抽屉/弹窗、状态反馈。
- 页面宽度优先把空间留给内容；左侧 WorkBuddy 二级导航只表达位置。
- 状态必须可见：加载、空结果、部分数据、服务失败、权限拒绝、策略阻断、操作成功。
- 所有操作都有键盘 Focus、Escape 关闭、关闭后焦点回归和 `role=status` 反馈。

## 技能市场

- 顶部 Tabs：推荐、技能广场、我的 Skills。
- 推荐/广场：搜索、来源、适用任务筛选；Skill 卡片展示名称、说明、来源、版本、适用任务、权限摘要、安装状态。
- 我的 Skills：已安装列表，状态为已启用、已停用、更新可用、安装失败；行尾操作为启停、更新、详情、去使用、删除。
- 详情侧抽屉：说明、示例、输入/输出、Context 范围、敏感级别、Tool/网络/文件权限、版本记录。
- 安装确认对话框展示权限；安装完成后按钮变为“去使用”和“停用”。创建 Skill 进入新任务草稿。
- “添加技能”紧邻搜索框，点击后打开“查找技能 / 上传技能 / 创建技能”菜单；菜单支持键盘访问和 Escape 关闭。
- 查找和创建分别进入新任务草稿，预填对应目标文案并显示可移除 Skill 标签；不自动执行 Run。
- 上传弹窗支持拖入文件夹、`.zip`、`.md`，或输入 GitHub/ZIP URL；本阶段只做可恢复校验和模拟导入，成功后进入“我的 Skills”。
- 新任务输入区提供可选 Skill 选择器：支持搜索已安装 Skill、选择、替换、移除，并提供返回技能市场的入口；普通任务无需选择 Skill。

## 工具连接

- 顶部 Tabs：工具广场、我的 Tools。
- Tool 卡片展示连接类型、来源、可用能力、权限范围和状态。
- 状态：已连接、待连接、连接中、认证失败、端点失败、策略阻断、更新可用。
- 详情侧抽屉提供连接测试、编辑、启停和删除；明确没有“立即运行任务”。
- 自定义 Tool 对话框提供名称、连接类型、Endpoint、超时、权限范围；Secret 使用掩码。

## 内容资源

- 当前 WorkBuddy 内容广场转为 Dormant Module，不进入默认导航和公开业务路径。
- TeacherIn 是 Space 下唯一可见的内容市场、作品管理、授权和发布入口。
- WorkBuddy 在 Core Context 提供 TeacherIn 资源选择，在 Artifact/“我的文件”提供“创建草稿到 TeacherIn”。
- 完整行为和兼容迁移见 `CONTENT-RESOURCE-ARCHITECTURE-UPGRADE.md`。

## 我的文件

- 只展示教师与 AI 协作生成的 Artifact 及文件结果；不提供上传入口，不混入教师上传、组织共享或仅作为 Session 输入的资料。
- 顶部提供文件类型、收藏和搜索筛选，不提供来源筛选。
- 默认按最近生成时间排序，并以任务 / Session 聚合文件。任务标题、教学范围与文件数构成归属锚点；文件行只保留名称、类型、生成时间和大小，其中时间是稳定列但不作为主视觉轴。
- 任务 / Session 使用独立的块级分组标题：标题加粗、教学上下文换行；所属文件整体缩进，文件名降低字重，任务图标与文件类型图标不得复用同一种底座。正文不重复标准 Topbar 已呈现的页面标题和说明。
- 文件详情展示版本、解析状态、权限、复用 / 分享记录和关联 Run；动作是预览、作为 Context、分享、下载与定位来源。
- 可发布类型增加“创建草稿到 TeacherIn”；成功后持久显示草稿关联和“前往 TeacherIn”。
- 不复制 ClassIn Space 的文件所有权；无权文件显示可解释的不可用状态。

## 定时任务

- 列表字段：名称、Task Type、状态、周期、下次运行、目标范围、最近结果、通知。
- 操作：新建、编辑、启停、立即运行、历史、删除。
- 创建/编辑弹窗字段：名称、目标模板、Task Type、周期、时区、生效区间、Context 规则、资源、通知、重叠策略、审批策略。
- 保存前显示未来三次触发预览；立即运行只创建标准 Run 入口，不绕过审批。
- 历史抽屉显示计划时间、实际时间、Run、Artifact、Receipt 和失败原因。
- 任务列表使用独立实体卡片，不以无边界白块连续堆叠。每张卡包含状态侧边轨道、任务图标、标题与说明、启停控件，以及由细分隔线承接的计划信息和更多操作。
- 启用卡片采用克制的 ClassIn 蓝状态轨道，停用卡片使用中性灰；卡片本体保持白色 Surface，仅以边界、同色轻阴影和 Hover/Focus Within 强化层级，避免形成高饱和卡片墙。

## 设置

- 内部左侧设置分组：通用、模型、数据与备份、消息与通知、沙箱、关于与能力真值、反馈。
- 通用：默认任务偏好、语言、通知、历史保留、技术详情默认层级。
- 模型：Provider/Model、启用、连接测试、默认模型、适用任务、数据边界。
- 数据与备份：可备份范围、上次备份、恢复、冲突提示；不涉及 ClassIn 正式对象。
- 消息与通知：渠道、绑定、组织范围、权限、验证状态。
- 沙箱：运行模式、文件/网络范围、危险动作策略、健康检查。
- 关于：版本、更新、协议、隐私、Mock/Beta/未来/生产能力说明。
- 反馈：问题类型、标题、描述、复现步骤、附件、脱敏诊断同意、联系方式。

## Responsive and Accessibility

- 1440×900：主列表与详情可同屏；详情抽屉不遮挡主要操作。
- 1000×768：详情改为 Overlay，列表仍可滚动，搜索和主操作保持可见。
- 所有 IconButton 有 accessible name；Tabs 使用 tab semantics；状态不只靠颜色表达。
- `prefers-reduced-motion` 下保留状态顺序，不依赖动画完成业务转换。
