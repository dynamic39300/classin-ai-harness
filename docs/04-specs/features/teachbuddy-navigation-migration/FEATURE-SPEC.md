# TeachBuddy 六入口导航与 AgentIn 市场

## Problem Statement

当前 TeachBuddy 一级入口同时承担进入工作台与展开能力导航，缺少与班级入口一致的“我的任务”入口。参考工程已迭代导航与 AgentIn 市场，但其中隐藏工具连接、定时任务及更换品牌等变化不符合本项目当前范围。迁移必须保留真实 Harness 会话与 Session 文件库，不得回退为参考工程的模拟首页。

## Solution

ClassIn 教师主导航的 TeachBuddy 整行只展开或收起二级导航，不改变当前页面。六个入口按“我的任务、技能市场、AgentIn、我的文件、工具连接、定时任务”排序。我的任务承载现有工作台；AgentIn 提供可浏览、搜索的固定智能体目录。班级启动的独立 TeachBuddy 同步六个入口，继续保留来源与返回班级。工具和定时任务保留现有 Demo 功能，不新增生产集成。

## User Stories

1. 作为教师，我希望点击 TeachBuddy 只展开目录，以便在不离开当前页面的情况下选择功能。
2. 作为教师，我希望点击我的任务进入现有对话工作台，以便继续使用真实 Harness。
3. 作为教师，我希望查看真实 Session 时高亮我的任务，以便知道当前所在位置。
4. 作为教师，我希望收起目录时不切换页面或清空草稿，以便保留工作现场。
5. 作为教师，我希望六个入口顺序固定，以便形成一致的操作习惯。
6. 作为教师，我希望继续使用技能市场，以便寻找教学能力。
7. 作为教师，我希望浏览 AgentIn 推荐、收藏与目录，以便了解可用的智能体形态。
8. 作为教师，我希望搜索智能体名称、描述与作者，以便快速定位固定目录中的条目。
9. 作为教师，我希望搜索无结果时能清空重试，以便恢复浏览。
10. 作为教师，我希望智能体不可用或未开放的操作有明确反馈，以便不会误以为已经安装或连接。
11. 作为教师，我希望工具连接与定时任务继续可达，以便演示现有配置和操作流程。
12. 作为教师，我希望我的文件仍能查看会话产物并返回来源会话，以便保留对话与资料的关联。
13. 作为班级教师，我希望独立 TeachBuddy 有相同的六个入口，以便无需学习另一套能力目录。
14. 作为班级教师，我希望切换能力后仍保留课程查询参数和返回班级链接，以便回到原业务现场。
15. 作为教师，我希望不同 Product Profile 的私有历史与文件保持隔离，以便不混淆演示数据。
16. 作为键盘用户，我希望展开状态、当前页和图标命令有可读名称，以便无鼠标操作。
17. 作为窄屏用户，我希望导航和 AgentIn 内容不重叠或横向溢出，以便访问所有入口。
18. 作为独立产品或学生用户，我希望此次迁移不改变我的产品导航与权限边界。

## Implementation Decisions

- 复用 Experience Profile Interface，区分 Capability 路由许可与有序导航配置；两套 ClassIn Product Module 保持各自不可变配置，不互相代理。
- 复用 Shell 的 navigation extension，增加明确的 disclosure 行为；Shell 只知道展开状态，不获得 WorkBuddy 私有任务状态。
- 我的任务继续使用原 new 路由和真实 Session 深链；不新增 ClassIn 待办、任务总览或新的任务数据模型。
- 我的任务在新建与真实 Session 中保留常驻“新建任务”“历史任务”命令；选择器只读取当前 Profile 的真实对话 Session。旧课程 Run 与课程工作流产品表面按 D-114 删除，旧 URL 只兼容重定向到真实 `/new`。详细行为见 [删除旧 Mock Task 产品表面](REMOVE-LEGACY-MOCK-TASKS.md)；NAV-04 阶段记录见 [任务历史入口恢复](TASK-HISTORY-RECOVERY.md)。
- AgentIn Market 是独立 Feature Module，公开 Workspace 与纯目录查询 Interface。固定快照及头像保存在项目内，无网络服务依赖。
- AgentIn 本期支持本地搜索、推荐轮换、侧栏收起、清空搜索、不可用和未开放反馈；不伪造智能体详情、安装、创建或接入成功。
- 工具连接和定时任务复用当前 Demo Surface 与状态模型。生成、审批、业务写回的既有边界不改变。
- 保留 TeachBuddy 品牌、班级独立 Shell、Launch Context、course 参数、返回链接及 Session Namespace。
- Settings 继续在两套 ClassIn Profile 中隐藏并对深链关闭；独立产品配置和学生路由不扩展。
- 不修改 Harness 协议、SessionFileLibrary Interface、存储格式或迁移已有文件。

## Testing Decisions

- Profile 契约测试检查有序目录、允许路由和独立配置；不以 CSS 类名等内部细节代替用户行为。
- AgentIn 查询单元测试与 Workspace 交互测试覆盖搜索、空态、不可用、推荐及未开放反馈。
- 浏览器测试覆盖一级展开不导航、六项顺序、我的任务真实工作台、能力往返、班级参数/返回和不允许的路由。
- 删除旧 Demo 工作流的产品测试，以真实 Session、旧 URL 回退和能力动作预填 Composer 的行为测试取代。
- 回归 Session 文件库与已有 Harness 浏览器契约；使用确定性测试服务，不因导航测试调用付费模型。
- 桌面与窄屏截图检查头像加载、文字/控件边界、可达性与滚动；记录未验证项目，不宣称生产就绪。

## Out of Scope

TeacherIn 品牌迁移；新版技能/智能体任务组装首页；真实 AgentIn API、智能体执行、安装、创建、权限和发布；生产 MCP/OAuth 与定时调度服务；学生端和独立 C 端导航改版；ClassIn 正式业务 API；已有存储重构；无关页面视觉重做。
