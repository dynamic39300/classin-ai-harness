### 3.2 学习目标

M1 使用以下可观察目标，不得用泛化口号替代：

1. 学生能指出一个整体，并判断某种分法是否为平均分；
2. 学生能用动作、图形或语言说明：把一个整体平均分成 `n` 份，其中一份可表示为 `1/n`；
3. 学生能在图/操作、语言和简单分数符号之间至少完成一次双向转换；
4. 学生能在不同外形或分割方向中识别相同的单位分数关系；
5. 学生能辨析至少一个“有 n 块但没有等分”的反例；
6. `SHOULD_IF_READY`：在同样大小整体和图示支持下比较一组单位分数，并说明理由。

### 3.3 内容优先级与红线

| 优先级 | 内容 |
| --- | --- |
| `MUST` | 整体、平均分、其中一份、`1/n` 意义、学生生成表征、跨外形迁移、非等分反例、退出证据 |
| `MUST` | 意义形成后再整理分数线、分母、分子和读法，并把名称连回意义 |
| `SHOULD_IF_READY` | 一次同样大小整体、图示支持的单位分数比较；核心诊断未通过或超时则后移 |
| `TEACHER_SIDE_ONLY` | 单位“1”、分数单位、后续“几个这样的一个”的纵向接口 |
| `NOT_IN_FIRST_LESSON` | 集合作为整体、分数与除法公式、几分之几主线、等值分数、基本性质、通分、约分、真/假分数和分数运算 |
| `PROHIBITED` | 无条件比较口诀；把教材出现过等同于学生已掌握；把研究发生率写成目标班学情 |

### 3.4 40 分钟默认 LessonFlow

| 环节 | 时间 | 必须留下的学习证据 |
| --- | ---: | --- |
| 前置诊断与表达需要 | 4 分钟 | 能判断“每份同样多”，发现不足一个整体需要新数表达 |
| 操作与概念形成 | 14 分钟 | 至少一次 `整体—平均分—其中一份—1/n` 的动作/图/语言证据 |
| 符号整理与跨表征 | 8 分钟 | 读写简单单位分数并跨两种外形/方向迁移 |
| 反例、受限比较与反馈 | 9 分钟 | 非等分辨析；准备度足够时做一次共同整体基准比较 |
| 总结与退出证据 | 5 分钟 | 新图形判断与一句理由；教师得到下一步分流依据 |

每个活动必须包含 `participants / duration_minutes / materials / student_action / expected_evidence / teacher_response / fallback`。课件页数不是时间估算。

### 3.5 评价输入

- M1 固定题型至少覆盖：平均分判断、图到符号、符号到图、跨外形、共同整体下比较、不同整体辨析、线性迁移与由一份反推整体；
- [G-Q01 至 G-Q08](../../../01-research/COURSEWARE-V2-GRADE3-MATH-M0-F-G-I-PRIMARY-RESEARCH-PACK.md#43-八道可独立验证的样板题)作为原创候选，M1 必须固定参数并独立复算答案；
- 每个构念至少 2 个受控变式；一次错误只记录原始回答或 `OBSERVED_ERROR`；
- 正确选择但没有理由只算部分证据；AI 不得从一次答题推断长期能力或心理原因；
- M1 将建立 Rubric、评分说明与人工试评；M0 不宣称题目难度、区分度或真实错误分布已校准。

### 3.6 资源输入

默认可进入后续制作候选的资源只有：

- 项目原创、参数可核验的单位分数 SVG/HTML 图；
- 无品牌图案的普通方纸、纸带、圆片等操作材料；
- 本项目原创题目与独立复算答案；
- 项目原创代码，或逐项核验许可证并保留 NOTICE 的第三方代码/图形。

以下内容默认不得进入模型上下文、仓库资产或成品：目标教材/教师用书扫描件、国家平台视频与截图、公开课照片和学习单、网络搜索图片、无来源 PPT/题库、真实学生作业/音视频。`公开可访问`、`平台已审核`、`课堂教学可少量使用` 均不等于获得商业模型输入、改编或再分发授权。

## 4. 已接受的关键项目决策

- 首版教学主线采用“公平分享产生新数需要”与“多种 `1/4` 作品比较共同结构”的组合，不复制任何单一课例脚本；
- 单位分数比较纳入首课，但只出现一次并以共同整体和图示为前提；核心概念未过或超时时后移；
- “分数单位”不作为首课学生必背/必考术语；
- “一组物体作为整体”不进入首课主流程；
- 面积/操作表征承担等分与部分—整体，线性表征作受控迁移或纠错，不把任一表征绝对化；
- 评价按构念与证据分层，不由一次选择给学生贴误区标签；
- 素材用途使用逐字段治理，`allowed_model_input` 与 `allowed_redistribute` 必须分开。
