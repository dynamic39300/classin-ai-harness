## 3. 进度算法

每个子里程碑统一包含四个 Gate，每关闭一个 Gate，子里程碑增加 25%：

1. `SOURCE_INVENTORY`：候选来源清单完整，来源类型和获取状态可见；
2. `EVIDENCE_EXTRACTED`：关键事实已形成证据卡，并能回到原始位置；
3. `BOUNDARY_RECONCILED`：版本、冲突、适用范围、未知项和许可边界已记录；
4. `USER_REVIEWED`：用户审阅需要人判断的结论，明确接受、修订或保留未知。

整体完成度按“子里程碑权重 × 子里程碑 Gate 完成度”求和。找到链接、下载文件或模型生成摘要本身都不等于完成；只有可复核 Gate 才计入进度。

## 4. 子里程碑定义

### M0-A 范围与教材身份

**研究问题**：为谁、使用哪一版教材、教什么、教到哪里、用多长时间。  
**已核验**：2022 年 8 月第 2 版，ISBN `978-7-107-36924-7`；第八单元自教材页 89 起，“几分之一”位于教材页 90-91。  
**完成 Gate**：任何参与者都能使用同一输入准确复述任务，且教材身份可追溯。  
**状态**：四个 Gate 全部关闭。

### M0-B 课程标准证据

**研究问题**：国家课程标准对第二学段分数学习、核心素养、学习活动和学业质量提出什么要求。  
**重点来源**：教育部课程标准、课程标准解读、正式教材目录。  
**产物内容**：课标原始位置、结构化要求、对本课影响、不可由课标直接推出的内容。  
**完成 Gate**：每项本课目标都能回链课标或明确标为项目教学决策。  
**当前状态**：四个 Gate 已全部关闭。用户接受学段与单课边界、概念形成链、可观察核心素养和版本边界；单位分数比较、比较深度与“分数单位”术语明确转交 M0-C/D/F/H。

### M0-C 教材内容地图

**研究问题**：本单元与本课的知识位置、概念顺序、表征、例题、练习层次及前后知识关系是什么。  
**重点来源**：当前教材目录、目标页面、相邻单元和总复习；必要时对照官方数字资源。  
**产物内容**：`前置知识 → 本课核心 → 后续知识`、页面级功能、概念与表征映射、教材事实与课时决策边界。  
**完成 Gate**：不阅读教材原页，也能从地图准确理解本课内容结构；所有页码和教材事实可回查。  
**当前状态**：四个 Gate 已全部关闭。M0-C-01 与 M0-C-02 均通过用户 Review；二下、三上、五下的固定教材证据、纵向边界和内容倒灌红线已合并。

### M0-D 教师用书与编写意图

**研究问题**：教材编写者怎样解释教学目标、重难点、内容取舍和教学建议。  
**重点来源**：配套教师教学用书、人教社教材解析和教师培训资料。  
**产物内容**：编写意图、建议教学路径、与教材页面的对应关系、可采用与需审慎采用的建议。  
**完成 Gate**：教材事实和教学解释不混写；缺少正式教师用书时明确降级证据等级。

**当前状态**：四个 Gate 已关闭。正式同版教师用书正文未取得，状态保留 `LIMITED_SOURCE`；项目路径由教材事实、课标、人教社公开解析和认知研究组合支持，不使用低信任教案补洞。

### M0-E 学生认知与典型误区

**研究问题**：三年级学生理解分数时依赖哪些前置经验，会出现哪些稳定误解，如何观察和诊断。  
**重点来源**：数学教育研究、公开教研资料、课堂观察、学生作业和教师访谈。  
**产物内容**：误区、可能原因、可观察表现、诊断问题、纠正表征和证据强度。  
**完成 Gate**：每个关键误区都有证据或明确的测试假设，不能把模型常识当作真实学情。

**当前状态**：四个 Gate 已关闭。误区只作为可测试假设；一次错误不形成长期标签，跨国或四年级研究的发生率不写入目标班画像。

### M0-F 优秀课例与教学模式

**研究问题**：高质量常态课如何组织概念形成、关键问题、学生动作、教师回应和时间分配。  
**重点来源**：国家平台、人教社、省市教研机构、许可清楚的公开课和用户认可案例。  
**产物内容**：逐课例证据卡、共性模式、分歧、适用课堂、不可直接迁移部分。  
**完成 Gate**：至少覆盖不同教学路径，不以名气、奖项或 GitHub Star 直接代替教学证据。

**当前状态**：四个 Gate 已关闭。市级教研的“分享冲突—反例辨析—变式抽象”和人教社的“参数化交互—多表征对比”两条路径已形成证据卡与 40 分钟适配。

### M0-G 题目、练习与评价

**研究问题**：哪些任务分别检查平均分、单位分数意义、表征转换、读写、比较和误区辨析。  
**重点来源**：教材练习、教师用书、公开评价研究及许可明确的题目资源。  
**产物内容**：目标—题型映射、难度梯度、答案与解释要求、干扰项意图、课堂反馈方式。  
**完成 Gate**：每道样板题知道“检查什么、为什么这样出、错误意味着什么”，答案可独立验证。

**当前状态**：四个 Gate 已关闭。六项目标、四级梯度、八道原创样板题、独立复算和错误—反馈规则已建立；真实难度与区分度转交 M1 校准。

### M0-H 课堂情境与实施约束

**研究问题**：课件在怎样的真实课堂中使用，哪些互动和时间安排可执行。  
**重点来源**：用户判断、样板教师访谈、公开课堂实录和学校条件。  
**产物内容**：班额、时长、设备、学生基础、教师操作负担、常态课与展示课边界。  
**完成 Gate**：所有教学活动都能说明人数、时间、材料、教师动作和反馈方式。

**当前状态**：四个 Gate 已关闭。38 人、40 分钟、教师电脑与大屏、离线核心流程、活动字段和失败回退已经锁定为脱敏测试画像。

### M0-I 素材资源与使用治理

**研究问题**：教材、教案、题目、图片、操作材料和代码资源可否获取、保存、改编、输入模型或再分发。  
**重点来源**：官方使用规则、开源许可证、用户合法持有材料的用途确认。  
**产物内容**：`Resource Manifest`，逐项记录来源、版本、许可、允许用途、保存位置和禁用动作。  
**完成 Gate**：没有来源不明材料进入仓库或默认生产语料，方法参考和内容复用被明确区分。

**当前状态**：四个 Gate 已关闭。15 类资源已登记；原创参数化图形、操作材料与原创题目为首选，教材/平台/无来源材料在许可未明时默认阻断。

### M0-J 输入完整性与 M0 Gate

**研究问题**：进入 M1 前还缺什么，哪些是事实、行业经验、项目决策、用户偏好或未知。  
**产物内容**：M0 Readiness Report、已接受结论、争议项、未知项、后续输入契约。  
**完成 Gate**：用户可以逐项确认 M0 交付；后续 Agent 不需要从聊天猜测课程事实或资料权限。

**当前状态**：四个 Gate 已关闭。[M0 Readiness Report](./M0-READINESS-REPORT.md) 已把固定课程合同、评价输入、资源规则和未知项汇总为 M1 唯一基线。

## 5. 来源与证据分级

| 等级 | 来源类型 | 可以支持什么 | 不能自动支持什么 |
| --- | --- | --- | --- |
| E1 | 教育部、正式课程标准、出版社正式资料 | 课程与教材事实 | 单一课堂的最佳教法 |
| E2 | 同行评审研究、权威教研机构、正式教师用书 | 学习规律、编写意图、教学建议 | 当前样板班真实学情 |
| E3 | 可核验优秀课例、课堂实录、教师反思 | 教学模式与可执行经验 | 普遍有效性或唯一正确路径 |
| E4 | GitHub、开放数据集、社区资源 | 资源发现、数据结构、技术方法和待验证假设 | 教学质量、教材一致性或版权授权 |
| E5 | 用户判断、样板教师反馈、授权课堂材料 | 产品目标、实际约束和课堂接受度 | 未经验证的普遍教育结论 |

一条结论可以组合多个等级，但必须保留各自来源。社区材料即使公开可访问，也要单独核验原始出处与许可证。

## 6. 资料协作流程

每个子里程碑按以下小循环推进：

1. **研究简报**：我先明确问题、范围、检索式和完成 Gate；
2. **先导调研**：我搜索官方、行业、论文和 GitHub，给出带用途说明的候选链接，而不是无差别链接堆积；
3. **获取清单**：按 `必需 / 推荐 / 候选` 排序，标出是否需要用户登录、下载或确认使用权；
4. **人工获取**：用户下载无法由公开工具稳定取得或需要账号授权的材料，并放入约定的本地临时目录；
5. **证据提取**：我建立证据卡、交叉核验版本和冲突，形成结构化产物；
6. **联合 Review**：我只把需要教学判断的结论和分歧交给用户，不要求用户重复阅读所有材料；
7. **关闭 Gate**：结论写回唯一事实源，更新子里程碑和总进度。

本地原始材料默认进入已忽略的 `.scratch/m0-sources/<source-id>/`，不提交 Git。仓库只保存允许留存的结构化事实、必要短引用、链接、哈希和审阅结论。
