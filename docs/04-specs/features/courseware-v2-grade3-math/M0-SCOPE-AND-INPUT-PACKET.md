## 2. 一句话任务

> 为普通公立小学三年级中等水平班级设计一节 40 分钟的新授课，让学生从熟悉的平均分活动出发，初步认识几分之一，能够用图形、语言和简单分数符号表达“一个整体被平均分后的一份”，并通过课堂活动和基础练习检查理解。

这句话是后续 V1 基线、V2 Workflow 和外部案例对比的共同任务，不允许为某一种实现临时改变。

## 3. 首轮教学范围

### 3.1 期望学生获得的理解

以下是依据课程标准和公开教研资料形成的 M0-A 工作假设，需在 M0-B 至 M0-H 经教材、教师用书、研究、优秀课例和用户 Review 复核后，才能作为 M1 的稳定输入：

1. 理解“平均分”是当前份数定义情境中的必要条件；
2. 能把一个物体或简单图形平均分成若干份，并把其中一份与几分之一联系起来；
3. 能结合图形或操作活动识别、读写二分之一、三分之一、四分之一等简单单位分数；
4. 能说明分数符号中的数字与“平均分成几份、取其中几份”的关系，第一课时重点是一份；
5. 能通过折、涂、说、辨等活动表达理解，并识别至少一类“没有平均分却用分数表示”的错误。
6. `CANDIDATE`：能借助同一整体的直观平均分图比较简单单位分数；是否纳入第一课时、是否形成一般化结论，由 M0-B/D/F/H 的证据和用户审阅决定。

### 3.2 首轮非目标

- 不系统教学几分之几；
- 不教学同分母分数加减法；
- 不教学通分、约分和分数基本性质；
- 不把分数定义扩展到除法商、比或有理数体系；
- 不强制在第一课时完成单位“1”由单个物体到多个物体集合的抽象；
- 不把教材小节边界直接等同于所有学校统一采用的课时边界；
- 不用复杂动画、主题模板或 PPTX 导出掩盖内容质量问题。

## 5. 课堂约束

M0-A 使用以下时间预算作为工作假设，M0-D/F/H 可根据教师用书、优秀课例和课堂约束证据调整：

| 环节 | 工作预算 | 目标 |
| --- | ---: | --- |
| 情境与问题导入 | 4 分钟 | 从公平分物或“一半”经验引出无法只用整数表达的问题 |
| 操作与概念形成 | 14 分钟 | 经历平均分、取一份、图形表征和语言表达 |
| 符号认识与迁移 | 8 分钟 | 连接二分之一与其他几分之一，变换图形与分法 |
| 辨析与基础练习 | 9 分钟 | 识别是否平均分，完成表示、读写和解释；单位分数比较待 M0 Review 决定 |
| 总结与反馈 | 5 分钟 | 学生说明本课理解，教师检查核心误区 |

时间预算不是 UI 进度，也不是固定脚本。后续生成的 `LessonFlow` 必须解释每段时间与学习目标的关系。

## 6. 固定教师输入包 v0.1

以下输入将作为 M1 的第一条完整输入 Case：

```text
请为人教版小学数学三年级上册《分数的初步认识》第一课时设计一份正式课堂课件。

班级为普通公立小学三年级中等水平班级，共 38 人，课堂时长 40 分钟。学生第一次正式学习分数，已有生活中的“一半”、公平分物、简单图形和基础除法经验。

课件要帮助学生从平均分活动出发，初步认识几分之一，能够结合图形读写简单分数，并能辨析“没有平均分却用分数表示”的错误。课堂需要包含教师讲解、学生操作或表达、关键提问、基础练习、答案与解释、总结和即时反馈。

先输出教学内容与页面级教学目的，再生成简洁、适合课堂投屏的课件。不要扩展到分数加减法、通分、约分或分数基本性质；不确定的教材例题和编号不要自行编造。
```

所有候选实现必须保留原始输入，并把系统补全的课程依据、规则和假设单独记录，不能把隐式补全改写成教师原话。

## 7. 后续固定任务的变化轴

M1 将在同一任务事实基础上建立 5-8 个 Case，至少覆盖：

1. 完整输入；
2. 缺少课堂时长；
3. 缺少班级水平；
4. 教师要求与第一课时范围冲突；
5. 教师提供一份有问题的旧课件要求改编；
6. 教师要求加强操作活动；
7. 教师要求增加练习但课堂时长不变；
8. 教材版本或课题信息不明确。

这些变化用于检验需求补全、边界保持和冲突处理，不用于在 M0 提前比较模型。

## 8. 材料与授权边界

### 8.1 当前可直接使用

- 教育部公开的课程标准、教材目录和政策页面；
- 人民教育出版社公开发布的教材介绍与教研文章；
- 公开项目的 README、论文与许可证允许的代码或方法；
- 本项目自行形成的结构化摘要、评价表和脱敏测试数据。

### 8.2 取得授权或核验后使用

- 用户拥有合法使用权的教材页面、教师用书、教案和课件；
- 国家中小学智慧教育平台等页面在其使用规则允许范围内形成的引用和事实摘要；
- 第三方公开课、题库或教案中许可明确的内容。

### 8.3 不进入仓库

- 来源不明或许可不清的整本教材、教师用书扫描件；
- 批量复制的付费题库和教案正文；
- 真实学生姓名、成绩、画像或其他个人信息；
- 由模型生成但无法核验来源的教材版本、例题编号和课程事实。
