# PRD

用户指出输入框上方的常驻帮助横条浪费聊天高度，授权改成小巧、不遮挡正文的文字入口。本次取消独占横条，将“可以问什么”放到输入框已有工具栏右侧，与发送共用一行；中性文字胶囊保持可发现性。

用户补充：展开后的“试着问我”与入口含义重复，去掉整行标题，让分类直接位于面板顶部，进一步收紧高度。

# Feature Spec

- 使用 `WorkspaceComposer.secondaryActions` 已有插槽，不修改共享输入框的尺寸、自动增高、键盘发送或工具栏规则。
- 入口不占聊天区，不覆盖输入文字；24px 以上点击高度，保留文字、问号图标、Hover 和键盘焦点。
- 问题帮助仍向上展开，以整个输入框为定位基准，宽度不超侧栏；展开不覆盖输入框与发送/停止。
- 展开面不再显示“试着问我”标题，关闭按钮与分类导航共用一行；导航可独立横向滚动，关闭按钮保持可达。默认最大高度从 300px 降为 252px，最低 180px 与现有可用高度保护不变；切换分类不跳高。
- 沿用已有问题目录、加载/失败/重试、分类切换、Escape/点击外部关闭、草稿与附件保护。
- 不改 API、模型路由、问答内容、历史、推荐加载和三问引导；两个教师 IM 入口使用同一实现。
- 本补充取代旧详细设计中“输入框外侧独立入口行”的位置约定，其余交互合同继续适用。
