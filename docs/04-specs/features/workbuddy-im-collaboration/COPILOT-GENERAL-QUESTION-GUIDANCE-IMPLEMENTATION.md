# 通用提问引导实施合同

用户已确认详细设计及六组21条问题；F组名称为“对群聊的内容提问”。本文件承接确认进入开发。内容/交互事实源仍为详细设计与内容清单，原18条数据核查不改写成生产接入结论。

## PRD

| ID | 要求 | 验收 |
| --- | --- | --- |
| GQ-01 | 真正无历史时显示已确认开场及至多3个可用问题 | 隐藏旧历史、恢复中、读取失败不冒充首次 |
| GQ-02 | 输入框外侧常驻“可以问什么”，六组分类紧凑横排，单次展示一组问题 | 不进入二级页、不展示长板；键盘、Escape、外点关闭可用 |
| GQ-03 | 空闲空草稿一击即问；已有文字/图片/运行/审阅时加入输入 | 不覆盖、不暗发附件、不并发；4000字校验；发送中禁止激活 |
| GQ-04 | 同一对话自动携带本班证据，问题与自由输入走同一链路 | 查询不出现群发送；家长话术不得误发本班 |
| GQ-05 | 可用内容决定推荐，21条保留ID可追溯 | 缺正文/逐题判分/观看进度不主动承诺；空记录不冒充错误 |
| GQ-06 | 群聊按教师请求取最新授权内容；支持引用给AI | 引用不自动发送；按消息日期定位题目；不猜题 |
| GQ-07 | 回复交付前复核原消息与后续上下文 | 改动/撤回保留草稿、提示重新核对；教师决定最终发送 |
| GQ-08 | 两个班级IM入口共用实现 | 切班不带入旧引用或旧对象；导航/历史行为不变 |

## Tech Spec

- `general-question-guidance` 领域Module保留21条内容目录，通过 `LearningContextCatalog.questionGuidance` 接收Adapter确认可用的问法和对象refs；无能力声明不默认全开放。推荐与帮助共用投影和点击决策。
- `GeneralQuestionGuidance` Feature提供首次问题行与原位帮助；帮助本身只拥有开合/焦点/阅读位置。Composer仍由现有WorkspaceComposer管理。
- 共享`ImSidecarAgentSurface`负责提交、草稿、运行互斥和上下文。增加从取数开始的同步提交锁，避免点击两次在runtime开始前产生两次请求。
- 现有固定BusinessContext Adapter增加可注入的本地群消息读取函数，每次capture读取当前store（包括olderEntries），不依赖打开窗口时的6条消息。仍为fixed-demo，不声称生产IM已接入。
- 上下文包含消息ID/时间/引用/撤回/媒体未读标记与覆盖信息。模型窗口有容量上限时明确部分覆盖，不宣称全量。完整题面与资料不默默截成240字；使用有界上下文并标识截断。
- 现有物理班固定数据支撑安排、作业和资料等第一条纵向闭环，其他问题只有所需证据具备才推荐。自由问到缺数据的内容时在回答中说明缺口。未接业务API不增加凭据或读取V2私有数据。
- “引用给AI”通过共享Provider传递目标消息；引用属于输入草稿，不改变当前运行，切班隔离。消息正文作为不可信数据，不赋予其工具指令权限。
- 家长话术保留文字草稿与复制能力；没有家长关系和明确渠道时不提供班级群发送。普通问题及题解默认只回答。

## 接入与验收边界

本轮目标是原版项目可操作的产品切片；真实业务API按同一Adapter后续替换。此前209次接口读取和DW样本是研究证据，没有自动成为线上接口。逐条模型正确率、生产IM分页权限、课堂逐字稿、非空逐题判分及完整个人周期报告仍需独立验收；不得用前端或Mock测试结果声称这些均已通过。
