# Feature Spec

- 复用共享 Sidecar，两个教师 IM 入口一致；不修改学生页面、API 字段、Skill 或模型路由。
- 提取推荐请求生命周期至 `useTeachingDynamics`：初始 loading、ready、refreshing、failed；保存同作用域最近成功快照。请求期间不重复发起；超时及卸载忽略晚返回；scope/Adapter 变化隔离旧请求。
- 每次推荐读取限 55 秒（真实 HTTP 已有 50 秒超时），6 秒显示读取较慢提示。首次无快照失败时自动重试一次，间隔 1.5 秒；仍失败进入紧凑失败态并停止自动轮询，用户手动重试可恢复。成功后以完成时刻起计一小时刷新；页面不可见时取消自动刷新计时，恢复可见/窗口 focus 时只在已到期且无请求进行中才刷新。读取失败停止自动刷新，保留手动重试；后台更新保留旧结果且不自动重新展开。
- 教学推荐错误与问题目录错误分开。问题目录加载中或失败时，提问帮助保留 A1/A2/A3 与准确状态；目录支持手动重试。
- 顶部骨架只在无快照时出现；阶段名称固定，数量用占位。折叠后标题仍有加载标记。失败显示“教学建议暂不可用 / 您仍可直接提问 / 重试”；旧结果失败显示“更新失败”，保持用户展开偏好。
- 三问文字/ID来自 `GENERAL_QUESTION_TEXT`，全为无具体对象依赖的已支持问题，不制造班级事实。真实答案仍经 Context Adapter 获取；基础连接未就绪时沿用只填入输入框的保护规则。
- 三问入场位移为现有小间距 Token，时长约 340ms，延迟 0/180/360ms，单次播放，总计约 700ms；占位提前保留，不引起逐条布局跳动；聚焦时立即可见，减少动态效果时关闭动画。
- 引导不存入 Session，不清历史、不新建会话；已有输入/引用/附件/草稿、重复点击与生成互斥沿用已验收规则。
- 引导展示按可见会话内容及历史展开状态判断，不按 Session 是否保存过消息判断。恢复完成后旧消息仍默认隐藏；展开历史或产生本轮新消息后立即移除引导；刷新重新建立展示边界，并按本节推荐交接规则决定是否入场。
- EL-T6 的推荐交接条件取当前展开阶段的真实投影：快照成功可用、至少一个 action 未因连接或对象目录缺失而禁用。其他阶段的推荐、只读确认和未知占位不作为交接依据。复用现有阶段投影与禁用条件，不增加接口调用。
- 入场前等待 180ms，若推荐已可用则直接展示推荐，三问不闪现；已经入场至少保留 900ms；推荐可用后另留 900ms（500ms 内容渐显/高度调整 + 400ms 稳定阅读），随后 450ms 淡出并折叠高度。三个问题内容始终固定。减少动态效果时取消视觉位移和过渡。
- 悬停三问区域或键盘焦点在其中时暂缓推荐交接；移开/移出后继续退出。退出阶段立即从可聚焦和可访问树中移除，避免不可见按钮被点击。历史展开或新消息优先于悬停保护，继续聚焦实际对话。
- 三问的 waiting / visible / leaving / dismissed 状态由共享引导 Module 拥有；父级只提供展示资格与推荐是否可操作，不将动效时序写入业务 Adapter。状态只存在当前挂载中，作用域切换沿用 Sidecar 的身份隔离。
- EL-T7 只调整局部布局和历史展开后的焦点策略：展开 Header 最小高度从 72px 收紧至 56px，下内边距 8px，内容上内边距 4px（均复用现有 Token）。折叠 Header、阶段圆点、推荐卡片内容及业务 API 不变。历史滚动锚点与是否需键盘焦点转移一起记录；鼠标点击/滚轮不执行程序化 focus，键盘激活继续支持。保留 `tabIndex` 与 `:focus-visible`，不全局取消无障碍焦点。

## EL-T8～EL-T10 增量技术合同

- 推荐计时只属于 `useTeachingDynamics`。提问的 `businessContext.capture` 与发送校验不改变，不将推荐缓存用于替代实际问题取数。初次失败仍只自动重试一次，超时与旧作用域隔离继续有效；手动成功重新开始一小时周期。
- 推荐首次由骨架变为快照时，局部容器以 500ms 从实测旧高度过渡到内容高度，并渐显。后台刷新不重播入场，不抢焦点、不改变展开状态。减少动态效果时跳过动画；动画结束/取消后回到自然高度。
- 三问离场仍保护鼠标悬停及键盘焦点；推荐尚未稳定或变为不可用时不启动离场。历史展开/新提问仍优先结束引导。
- 三问完成交接后不产生其他 UI 提示；“可以问什么”保持原按钮、原目录与键盘操作。删除上一轮 hint 事件、展示状态、定时器和 CSS 动画，不仅隐藏 DOM。
- 顶部成功状态的数量与说明合并一行；加载/更新失败标记与对应恢复入口保留。窄栏自然换行、不裁切或缩小字号，实际浏览器验证常规宽度一行。

## EL-T11～EL-T12 增量技术合同

- 从真实 `projectDynamics` 的源投影删除 `course-inventory` 行，不在 UI 依标题文字隐藏；总结只保留有业务触发的 P08/P09/P10，空总结继续用现有空态。
- 删除无课时固定添加的 `realtime-attendance-unavailable` 事项。依据成功读取的当前课程排课、发布/取消/结束状态及读取时刻，当前无课投影为空，由共享阶段空态显示指定一句提示。课前区间不含开课时刻，课中从开课时刻起至结束时刻前；接口已结束的课不进入课中。
- 发布未取消且未结束课堂缺失/无效时间时，不能宣称无课，保持“课堂时间信息不完整，暂时无法确认是否正在上课”的未知提示。排定上课时间内但成员实时考勤未知时，显示该课堂与未确认说明，不以汇总人数/课后报告判定满勤或缺席。
- 课中无动作事项以普通提示呈现，移除“仅供查看/无需处理”徽标及任务卡强调；已核验未进入名单的提醒仍沿用 P03 动作；已核验满勤只提示，不生成消息。真实测试环境 P03 仍为 BLOCKED_EXTERNAL，本次不接入新的实时 Reader 或注入模拟数据。
- 课中真空态 Tab 为“暂无”，未知为“待核”；原演示班及两教师入口复用同一显示规则。其他阶段布局、21题目录、取数与交付保持不变。

# 验收

延迟推荐与目录时三问短暂等待后出现且可独立提交；目录回来不换题；原文和附件受保护；历史默认收起可展示，展开后隐藏；可用展开卡片交接、悬停/焦点保护及快速加载不闪现均有回归。浏览器验证入场/退出、动画不重播、减少动态效果、键盘可用、无横向溢出、输入区可达。自动化使用隔离 fixture 验证 UI 状态，不注入真实 Demo 业务；真实页面仅核验现有状态，不清空用户历史。

最终验证结果另写验收记录，不以本合同的批准状态代表测试已通过。
