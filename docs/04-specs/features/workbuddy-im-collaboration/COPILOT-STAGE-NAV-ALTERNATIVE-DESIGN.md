# TeachBuddy 教学阶段导航方案（二）

## 1. 方案目标

在 TeachBuddy 顶部提供一个稳定、明显的教学协作入口。老师通过`课前 / 课中 / 课后 / 总结`四个阶段快速理解当前班级有哪些课程、学生和事项，并用一次点击把明确要求提交给 AI。

本方案与方案一复用同一个`TeachingDynamicsAdapter`、业务事实、Prompt 动作和对话闭环，只替换顶部信息组织和本地呈现状态，便于对比评审。

## 2. 页面结构

```text
教学动态                                                [收起]

 [课前]────[课中]────[课后]────[总结]
  建议1条   建议1条   建议2条   建议2条

┌──────────────────────────────────────────────────┐
│ 高二物理3班 · 动量守恒模型 · 在线课堂              │
│ 已开课10分钟，3人迟到                  [提醒学生]   │
│ 李明、周然、陈晨尚未进入课堂                       │
├──────────────────────────────────────────────────┤
│ 高二物理3班 · 动量守恒模型 · 在线课堂              │
│ 全班已完成2次随堂互动                  [已了解]     │
└──────────────────────────────────────────────────┘
```

顶部固定四个 Tab。放大的圆形入口内直接显示`课前 / 课中 / 课后 / 总结`，不再使用`1 / 2 / 3 / 4`步骤编号，也不在圆圈下重复阶段名称。圆点和连线表达教学阶段位置，不表达同一任务的完成流程。当前业务阶段以绿色轮廓标识，当前选中阶段以绿色实心圆标识。

Tab 已经说明内容所在阶段，因此下方内容卡不再重复显示阶段名称和“当前班级的课程、学生与任务”解释行，直接从具体事项开始。

## 3. 内容规则

每个阶段卡片显示当前班级中属于该阶段的全部有效事项。不同课程可以同时落在不同阶段，例如动量守恒课正在进行，电磁感应课仍处于课前准备，上一讲作业处于催交与错题分析阶段。

每项依次表达：

1. 班级、课程和业务载体；
2. 当前人数、截止时间或完成事实；
3. 已知学生范围和必要边界；
4. 一个明确动作。

推荐动作使用教师语言：`提醒预习`、`提醒学生`、`提醒交作业`、`查看错题`、`制作解析`、`生成总结`。点击后直接进入现有 TeachBuddy 对话；缺少信息时由 AI 补问。

## 4. 切换与收起

- 首次打开默认选中当前业务阶段。
- 阶段不自动轮播，也不显示播放或暂停控制；老师手动选择后保持该阶段。
- 键盘支持左右方向键、Home 和 End 切换 Tab。
- 模块每次进入当前聊天时默认展开。老师可以点击顶部箭头主动收起；向下滚动下方 TeachBuddy 对话区域时也自动收起。
- 收起后常驻为`教学动态｜N 项建议`一行，点击后原位展开；业务更新只刷新摘要和`有更新`提示，不强制展开。

## 5. 业务与 AI 状态边界

Tab 数字只统计当前业务阶段内可以发起的建议，不表示 AI 任务数量。卡片随课程开始、结束、作业截止和正式回执自然更新。AI 的补问、生成、修改、审阅、发送和失败恢复全部保留在下方对话中。

## 6. 验收重点

- 四个 Tab、圆点和连线在 Sidecar 默认宽度下完整可见；
- 每个 Tab 的`建议 X 条 / 已核对 / 待核对`可直接理解；
- 切换阶段只替换一张内容卡，不跳页、不出现返回；
- 手动切换、收起与恢复互不改变业务事实；
- 事项点击一次进入 AI 对话，无表单和二次提交；
- 内容卡在 900×720 与 1440×900 下无横向溢出；
- 相关组件、领域投影、Adapter、Sidecar 与 Chromium 闭环测试通过。
