# Copilot 页面级历史展示验收

日期：2026-09-15

## 实现

进入或刷新时仅隐藏旧回合、旧产物及其交付按钮，保留原 Session 和上下文。页面首次恢复时记录显示边界，新回合正常显示。存在历史时显示“↑ 查看历史”，点击或在聊天区顶部向上滚动可原位恢复；导航区域滚动不触发。恢复历史时保持阅读位置。刷新后重新隐藏，不持久化历史展开状态。

旧演示参数 resetCopilotOnReload 不再清除绑定。正在执行的任务仍可停止，即使其旧回合暂时隐藏，老师主动停止后的反馈也可见。没有修改业务写回、V2 或服务配置。

## 验证

- 8 项历史呈现与 Sidecar 组件测试、类型检查、Lint、diff 检查通过。
- 17 项浏览器场景分批通过，包括两个入口默认空白、点击和滚轮查看、刷新再隐藏、新请求继续相同 Session、旧演示 URL、图片失败恢复、停止后继续及交付。
- 历史入口的空白状态通过 axe 检查；1280×720 空白和展开截图已检查，无溢出遮挡。
- 通用模拟回答中的 GFM 复选框存在既有无名称问题，本次未扩大修改共享 Markdown 渲染，不宣称所有历史回答内容均已通过 axe。

浏览器使用协议模拟验证原 Session 继续被调用，不调用真实业务消息写回。历史显示切换本身不调用模型。

规格见 [交互 Feature Spec](./COPILOT-CONVERSATION-RUN-UX-FEATURE-SPEC.md) 的“页面级历史隐藏”。


## 新消息分界补充

查看历史后，在首个本次新回合前显示红字“以下为新消息”和两侧淡红细线。仅显示一次；无历史、无新回合或历史仍隐藏时不出现。移除紧邻分界前的灰色回复尾线，避免双线。沿用IM的颜色与字号Token，间距适配紧凑侧栏。

2项历史边界测试、两个入口浏览器测试、类型/Lint/diff检查通过；验证刷新后边界重置、追加新回合不移动边界、分界前后分别为旧回答和新提问。截图已检查，正文与会话保持不变。
