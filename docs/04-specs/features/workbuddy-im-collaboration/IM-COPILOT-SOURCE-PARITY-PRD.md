# 产品结果

教师打开 `/teacher/messages?category=class&thread=class-physics-3` 时，看到并操作的 IM Copilot 与 `classin-ai-harness` 2026-09-15 冻结工作树一致。当前产品只使用固定、去标识、可重置的模拟班级和教学数据；真实 ClassIn 测试班不进入默认会话列表或 Copilot 上下文。

# 需求

- PAR-01：顶部协作面文案、淡蓝灰视觉、四阶段导航、整栏折叠与源项目一致。
- PAR-02：首屏三条问题和完整 21 个“可以问什么”问题可按当前模拟上下文使用。
- PAR-03：班级消息可引用给 AI，引用读取、更新与撤回按当前 Thread 校验。
- PAR-04：进入或刷新默认隐藏旧 AI 回合；查看后显示一次“以下为新消息”分界，Runtime Session 不清空。
- PAR-05：可发送正文直接预览，支持修改、直接发送、失败重试、私聊插入和家长草稿边界。
- PAR-06：草稿结构、密度、`@所有人`/成员提及及 AI 自我介绍与源项目一致。
- PAR-07：保留 V2 图片产物与所属回合的时间顺序和 Runtime 恢复能力。
- PAR-08：真实 ClassIn 测试 Module、合同、研究与核验页不删除，但退出默认消息组合根。
- PAR-09：相同浏览器、视口、角色、URL、Mock 数据和空存储下完成 DOM、交互与视觉对齐。

# 非范围

本轮不调用真实 ClassIn 业务接口，不修改测试环境数据，不接入真实 IM，不让学生端接收模拟消息，也不重新设计已审阅的源页面。

# 完成标准

源项目与 V2 的模拟消息入口在首屏、折叠、问题面板、历史、回答、草稿、编辑、失败和发送状态下保持相同文案、顺序、交互与样式；V2 专有保留项只有不可见的图片排序和恢复修复，并有自动化证明。
