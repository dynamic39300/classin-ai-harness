# ClassIn IM 通讯录与对象发现 Feature Spec

## Problem Statement

当前消息页只在“发起私聊”弹窗中列出少量固定联系人和班级 Agent；用户无法按新好友、班级、好友和组织浏览关系，也不能用联系人账号/手机号、班级号或公开课 ID 做对象发现。会话管理中的“联系人资料”只返回占位反馈，找到人、班级或公开课后缺少最小资料与进入动作。

这使通讯录入口、全网搜索和现有消息/班级/公开课路由彼此割裂。用户已经确认本阶段只需补齐目录、最小结果资料和“进入已有会话/班级”的闭环；扩展资料和生产关系请求可继续保留边界。

## Solution

在消息页的私聊区域提供统一“通讯录”Focus Dialog，复用现有 Thread、Class 与 Open Course 路由。它包含四类关系目录和一个按对象类型筛选的发现搜索：

- 新好友按时间和待处理/已同意状态组织；好友按首字母分组并提供快捷索引和总数。
- 班级目录显示当前角色可见班级、班级号和成员摘要；点击进入既有班级或班级群。
- 组织目录使用可展开层级和面包屑；人员可打开最小资料，并在本地演示“申请添加好友”。
- 搜索支持联系人账号/手机号/邮箱、班级号和公开课 ID/名称；结果显示对象类型、核心资料和可执行下一步。
- 联系人资料提供关系、组织、脱敏联系方式、备注、好友设置入口、发消息与身份分享；生产关系、扩展资料与真实 QR 解码保留 Adapter Gate。

## User Stories

1. 作为教师或学生，我希望从消息页直接打开通讯录，以便先找到对象再决定是否发消息。
2. 作为用户，我希望按“新好友 / 班级 / 好友 / 组织架构”浏览，避免把不同关系混成一张列表。
3. 作为用户，我希望新好友按日期和“待处理/已同意”展示，以理解关系事件状态。
4. 作为用户，我希望好友按字母分组、显示总数并可用字母索引定位。
5. 作为用户，我希望逐级浏览机构和教研组，并通过面包屑回到上级。
6. 作为用户，我希望打开联系人最小资料，看到身份、关系、组织、脱敏联系方式和备注。
7. 作为用户，我希望从资料直接进入已有私聊；没有会话时能发起本地好友申请并得到明确结果。
8. 作为用户，我希望查看推荐好友和好友设置入口，但未知设置项不应被产品自行补造。
9. 作为用户，我希望从组织人员资料发起好友申请。
10. 作为用户，我希望搜索姓名、ClassIn 号、手机号或邮箱，并识别联系人结果。
11. 作为用户，我希望用班级号找到班级资料，并进入已有班级或加入入口。
12. 作为用户，我希望用公开课 ID 或名称找到公开课，并进入现有公开课详情。
13. 作为用户，我希望分享自己的固定 Demo 身份二维码和 In 口令，并清楚知道没有发布真实身份信息。
14. 作为评审者，我希望目录数据、关系请求和身份分享均有真值标记，不把固定数据写成生产通讯录。

## Requirements

| ID | Feature | 可观察验收结果 |
| --- | --- | --- |
| `IM-DIR-001` | 通讯录入口 | 私聊列表工具区提供“通讯录”，打开临时 Dialog；关闭/Escape 后焦点恢复。 |
| `IM-DIR-002` | 四类目录 | 新好友、班级、好友、组织架构四个 Tab 可切换，当前 Tab、数量和空态可读。 |
| `IM-DIR-003` | 新好友状态 | 条目按日期倒序分组，显示待处理/已同意；本地接受或忽略只更新当前可重置会话。 |
| `IM-DIR-004` | 好友分组 | 好友按 A–Z/中文首字母分组，显示总数和快捷索引；无结果时说明原因。 |
| `IM-DIR-005` | 组织树 | 组织节点可逐级进入，面包屑可返回；人员与部门明确区分。 |
| `IM-DIR-006` | 最小资料 | 资料显示名称、身份、关系、组织路径、脱敏账号/手机号/邮箱、备注与关系状态。 |
| `IM-DIR-007` | 资料动作 | 已有 Thread 的对象可直接发消息；非好友可发起本地模拟申请；备注可保存；好友设置只显示已知入口和未知边界。 |
| `IM-DIR-008` | 推荐好友 | 固定推荐项显示推荐原因，可进入资料并发起模拟关系请求。 |
| `IM-DIR-009` | 三类搜索 | 发现搜索可筛选联系人、班级和公开课；同时支持统一结果视图，不新增消息分类。 |
| `IM-DIR-010` | 联系人搜索 | 姓名、ClassIn 号、手机号和邮箱能命中固定联系人，结果打开同一资料面。 |
| `IM-DIR-011` | 班级搜索 | 班级名或班级号能命中固定班级；可进入现有班级详情/群聊，非成员进入既有加入路径。 |
| `IM-DIR-012` | 公开课搜索 | 公开课名、学科、教师或公开课 ID 能命中现有 Open Course Record，并进入现有详情。 |
| `IM-DIR-013` | 身份分享 | 最小资料提供固定 Demo QR 表达和 In 口令复制反馈；不访问真实身份、相机或生产分享服务。 |
| `IM-DIR-014` | 隔离与恢复 | 教师/学生只看到各自可见对象；搜索、Tab、组织路径和资料可返回；切换到消息或业务详情后原消息草稿仍保留。 |

## Implementation Decisions

- `MessageDirectoryModule` 是本阶段 Deep Module。页面只发送“打开目录、搜索、进入节点、选择结果、执行动作”等命令，筛选、分组、角色可见性和结果动作由 Domain Projection 决定。
- `MessageDirectoryAdapter` 是未来 ClassIn 关系、组织和对象搜索的 Seam。当前 Memory Adapter 使用固定、去标识、可重置 Snapshot，并记录本地备注和好友申请命令。
- 通讯录使用 Focus Dialog，不增加 AppShell 一级导航，也不形成沉浸三栏之外的常驻第四栏。
- 班级和公开课不在 Message Domain 复制对象：目录只持有稳定引用和可展示 Snapshot，进入动作复用现有路由。
- “好友设置”线上证据只确认入口存在，因此当前只显示入口和“更多设置需生产证据”的边界。
- 联系方式使用明显的 Demo 标识与脱敏值。身份二维码是视觉占位，In 口令为固定演示值；不声称真实可扫描或可跨设备解析。
- 生产关系请求、通讯录同步、反滥用、黑名单、隐私授权和真实组织权限不在页面本地规则中推断。

## Testing Decisions

- Domain 测试覆盖角色过滤、好友字母分组、新好友时间排序、组织面包屑、三类搜索和稳定结果动作。
- Adapter 契约测试覆盖备注保存、好友请求幂等、接受/忽略状态、角色隔离与 Reset。
- Integration 从消息页打开通讯录，覆盖四类目录、资料→私聊、班级号→班级、公开课 ID→详情和焦点恢复。
- E2E 覆盖教师联系人搜索到既有私聊、学生班级/公开课结果进入和范围内 Axe。
- 视觉验收覆盖 1440×900、900×720 和 390×844；Dialog 不产生页面溢出或遮住关闭/返回动作。

## Out of Scope

- 真实 ClassIn 联系人、手机号、邮箱、组织、关系请求和黑名单服务。
- 通讯录导入、跨机构管理员搜索、生产隐私授权、反垃圾和风控。
- 未在截图中展示的好友设置项、独立全屏资料页和扩展个人档案。
- 真实二维码生成/解析、相机访问和外部分享渠道。
- 公开课业务通知与官方内容流；它们由下一阶段处理。
- 联系人名片消息；它属于“名片与临时教室”阶段。
